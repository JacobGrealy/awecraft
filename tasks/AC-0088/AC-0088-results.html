2. Rebind decision: replace-within-class (stated, and consistent UI + arm)

Binding is a list; the decision: a captured input replaces the action's current binding of the captured class (the first one when the action has several of that class) and adds the class when the action has none. Other classes of the action and the protected stick motions are untouched. The merge rule generalises it: a saved token of class C for action A suppresses all of A's default C bindings; classes without saved tokens keep their full defaults; no tokens at all → the full default map.

Why replace and not add: with add, the UI has no way to remove a binding, so a mistaken capture is permanently sticky; replace gives the press-to-capture flow one obvious effect per press, and the pad co-bindings (e.g. jump = Space + A) survive because only the captured class moves.

The H case is a live demo of the builtin co-existence: plain H also matches the ui_filedialog_show_hidden builtin (the engine stores it without modifier flags, so it is identity-identical to plain H) — the arm records it in free_builtin and the UI would show the "menus only" note. Modifier-qualified stored events are otherwise excluded from conflicts (a plain-key binding can never fire a Ctrl+X).

4. The invariant: every action the game uses stays bound (safe-fallback rule)

Stated rule — corrupt/partial stored maps fail safe toward the defaults and can never empty an action: the stored format is a flat per-entry token list in which absence = default — an action cannot be represented as empty at all. Per-entry validation drops corrupt entries only; an action with no surviving tokens keeps its full default set; a belt-and-braces net restores the defaults if a merged list ever comes out empty; apply_controls() refuses to run before the defaults are captured (pre-capture apply would erase actions). Decision basis: the UI only ever replaces, never clears, so emptiness is unreachable by design; hostile hand-edited cfg is filtered entry-wise. The arm asserts the rule rather than assuming it — including the net itself.
