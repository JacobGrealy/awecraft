AC-0109 frustum-culling-chunks — Run-1 results

Task: per-frame frustum test so built-but-behind-camera chunk slabs stop being drawn. Per-slab AABB vs active-camera frustum (margin-expanded), set mesh/fluid/flora instances visible=false outside / true back inside. Data + mesh stay resident — not the distance-candidate path (no queue entry, no unbuild, no recenter). Radial candidate logic byte-for-byte unchanged. No pop-in (32 m margin), no per-frame allocations growing with chunk count, no new per-chunk state.

Implementation

  • godot/world/world.gd: FRUSTUM_CULL_MARGIN = 32.0 (2× slab width). _frustum_cull_pass() at the top of _process (before the all-queues-empty early return): early-outs on kill-switch / no camera / unchanged camera global_transform; otherwise rebuilds 6 frustum planes from camera basis+origin, fov 75, viewport aspect, near 0.05 / far 4000 (12 world corners, per-plane inward normal via cross, degenerate guard, flip-vs-centroid). Per chunk: column-AABB test (culled ⇒ all 5 slabs hidden; definitely-in ⇒ all shown); otherwise per slab with the column distance reused via dy·n.y (dy = y0−32). Cull test is a single crisp symmetric predicate: slab culled ⇔ ∃ plane d + span < −M (d = plane distance to slab center, span = r·|n| precomputed per plane) — no hysteresis, deterministic per pose. _cull_set_vis writes visible only on change.
  • World-level fixed-size scratch only: 6 Plane, 4 PackedFloat32Array(6), 1 scratch Vector3, last-camera Transform3D, enabled flag. No new arrays in chunk/Slab structures; no per-frame O(chunk²); no per-frame allocations (planes/spans allocated once lazily).
  • Kill switch: AWECRAFT_FRUSTUM_CULL=0 (default on); also disabled when AWECRAFT_ONLY is set (keeps that probe's static visibility filter authoritative).
  • godot/scenes/main.gd: new AWECRAFT_LOGIC=spin probe (120-step 360° yaw spin of the player camera at captured eye, 1280×720 forced aspect, seed 44, r4; per-step vert/visibility sampling from a one-shot vert cache; flicker counter = V→I edge with a prior V→I edge within 8 steps; bottom look pitch −90; return to start pose) + world.invalidate_cull_cache() probe hook + gated AWECRAFT_SPINDBG debug (prints nothing unless set).

Findings

Mesh structure (pinned)

chunk = 5 vertical slabs 16×16×16 (y0 = 0/16/32/48/64; chunk.gd:32 slabs: Array, chunk.gd:46 Slab class with mesh_instance / fluid_instance / flora_instance: MeshInstance3D, built, col_dirty). Chunk at (cx·16, 0, cz·16); slab world AABB (cx·16, y0, cz·16)+(16,16,16). Column AABB center (cx·16+8, 40, cz·16+8), r=(8,40,8) [Data.HEIGHT=80]; slab center (cx·16+8, y0+8, cz·16+8), r=(8,8,8). Culling is per-slab (5 instances × up to 3 sub-meshes per chunk), column-level early-out in both directions.

In-repo culling audit

No per-frame frustum culling existed anywhere before this task. Existing visible writers: (1) AWECRAFT_ONLY probe-only static filter (main.gd:1110–1122; mesh+fluid only — kept authoritative via the AWECRAFT_ONLY guard on _cull_enabled); (2) distance-candidate r+1 path (kills meshes — different mechanism, untouched); (3) AC-0133 star field = world-root parent, not a chunk child (untouched). Single world per game (no second world) → no coordinate-space risk.

Engine audit (Godot 4.7.1, verified empirically — no web refs)

  • No extra_culling_margin on MeshInstance3D (parse-verified) → no engine cull-margin knob → a GDScript per-frame test is the only path (this task).
  • No get_camera_frustum(); Plane(normal, point) 2-arg ctor OK, method is distance_to(point) (not distance_to_point).
  • Performance named constants unavailable headless: PERFORMANCE_RENDER_TOTAL_OBJECTS_IN_FRAME / _VISIBLE_LIGHTS / _TOTAL_LIGHTS all parse-error ("Cannot find member … in base Performance"); reflection routes (Performance.new(), get_constant_list(), get_global_constant()) also fail → the SPINPERF renderer-internal audit was removed. Renderer-internal culling counts are not observable headless; the deliverable is the scene-level visible state (which is what drives draw submission).

Deviations (honest)

  1. G2 MINFO — pre-existing baseline drift, A/B'd. 120/121 lines byte-identical to .scratch/AC-0129-gates/gate_minfo.txt. One delta: chunk [16,48] verts 2012 vs 2020 (−8), reproduced across 3 runs; with AWECRAFT_FRUSTUM_CULL=0 (this task's code fully inert) the same delta persists plus a second one ([32,−16], −12) appears. Culling writes only instance.visible; MINFO dumps mesh arrays — provably unaffected. This is the documented threaded-greedy-merge reshuffle flake class (AC-0136: "−48 verts merge-reshuffle flake") — the 2026-08-27 baseline no longer reproduces byte-for-byte on the current tree. Not a mesh/geometry change from this task.
  2. Spin probe bounded settle (pre-existing stall). _nd_settle(60000) hits its 120 s cap whenever a player is present (reproduced with the known-good viewlight probe: 120.2 s, same symptom) while the no-player perf probe builds 81/81 in 9.85 s. Root cause is the AC-0137-class handoff transient dropping 2–7 chunks' builds with no requeue (queue flat at 40 afterwards) — pre-existing, tracked as AC-0137. The probe now uses a bounded 2400-frame settle and proceeds with whatever is built (reported as built_chunks); wall time 41.4 s ≤ 60 s. All gates are intra-run, so the missing chunks don't affect them.
  3. Probe bugs fixed in-run (would have broken the gates otherwise): stale cull-cache latch before chunks existed (fix: invalidate_cull_cache() probe hook); one-frame sampling lag from the physics_frame-landing first transform set (fix: phase-sync await at step 0); flicker-counter sentinel −1 counted every first-ever edge ≤ step 8 as a flicker (fix: −9999). The 29 "transitions" seen mid-debug were entirely the sentinel bug; the pass itself is a pure per-pose geometric test.
  4. Render path note: AWECRAFT_SNAPSHOT relative paths resolve under godot/ (due to --path godot) — the first render attempt saved nothing; reran with an absolute path (same single render). G5 counts as 1 render.
