AC-0182 — LOD transition: retain + hysteresis + cache both (no hole/flicker at the 12/13 line, instant switch)

Status: DONE + PUSHED · Built on: AC-0181 (0-12 full, 13+ coarse uniform) · Date: 2026-09-01

User story: As a player walking across the 12/13 block ring, I want no hole and no flicker when the detail changes, and if I step back and forth it should switch instantly instead of rebuilding each time.

What changed

Three coupled pieces, all at the reband site:

  • Hysteresis (dead band) — LOD_HYS_FULL_MAX=11 / LOD_HYS_COARSE_MIN=14: a committed-FULL chunk flips coarse only at taxi ≥ 14; a committed-COARSE chunk flips full only at taxi ≤ 11; taxi 12/13 is a dead band that keeps the current LOD, so a chunk straddling the line never flips per frame. (Stateless ±1-taxi margin in _rec_want_step.)
  • Retain-until-ready (no hole) — on a fidelity reband the old mesh is not killed; c.lod_pending re-enters the existing light_pending flush (1/frame), the worker builds the new LOD while the old stays visible, and the handoff does capture→apply_accs as one atomic main-thread swap. Same-fidelity 0↔1 reband just moves collision bodies (no rebuild). The stale-band BANDBREAK now routes through _tm_retrigger (not _enqueue_build) so a mid-flight re-reband can't strand a lod_pending chunk.
  • Cache both for taxi 11-14 — per-chunk alt slot (alt_slabs per-slab [mesh/fluid/flora] + alt_lod kind + alt_data/alt_fl + alt_atlas). Stored when a fidelity build lands in-ring; on re-crossing swap_to_cached() is a 0 ms instance-mesh toggle (demoted LOD becomes the new alt). Staleness guarded by data/fl native equality + atlas identity.

Files: godot/world/world.gd (consts, _rec_want_step dead-band + _reband, threadmesh_handoff capture/store, BANDBREAK reroute, _enter_candidate clear), godot/world/chunk.gd (alt-cache vars + capture_lod/store_lod_cache/lod_cache_valid/swap_to_cached/clear_lod_cache/drop_slab_bodies), godot/scenes/main.gd (new AWECRAFT_LOGIC=lodswap probe + _lodband_test updated for the dead band).
