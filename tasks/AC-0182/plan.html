AC-0182 — LOD transition: retain + hysteresis + cache both

Goal

Walking across the 12/13 LOD line shows no hole (old LOD stays visible until the new build_accs lands, then atomic swap), no flicker (±1-taxi dead band: full→coarse commits only at taxi ≥ 14, coarse→full only at taxi ≤ 11, so a chunk straddling the line never flips per frame), and a 0 ms re-crossing (both LODs resident in the taxi 11–14 ring, so the second crossing is a visible mesh toggle, not a rebuild).

Design (three coupled pieces, all at the reband site)

  1. Hysteresis (dead band). Stateless ±1-taxi margin evaluated in the recenter walk (_rec_want_step): a committed-FULL chunk flips coarse only at taxi ≥ 14; a committed-COARSE chunk flips full only at taxi ≤ 11; taxi 12/13 is a dead band that keeps the current LOD. A straddling chunk (target oscillating 1↔2) therefore never flips — matching the task's "2 frames / ±1 taxi" either-or; the cand_since ≥ 2 free-candidate style stays untouched at world.gd:2576.
  2. Retain-until-ready. On a fidelity reband (full↔coarse, or 0↔1 which share the identical builder path) the old mesh is NOT killed. Same-fidelity 0↔1 reband just updates band/collision_enabled + moves collision bodies (no rebuild at all). Fidelity rebands set c.lod_pending and re-enter the existing light_pending flush (1/frame, defer-on-cap, _build_ready-gated) — the worker builds the new LOD while the old one stays visible; the handoff captures the outgoing LOD's meshes, apply_accs does the free+assemble in one main-thread step = the atomic swap. mesh_built stays true through the whole window (the drain's meshed-skip is never an issue: the flush dispatches directly).
  3. Cache both for taxi 11–14. Per-chunk alt slot (alt_slabs per-slab [mesh/fluid/flora ArrayMesh] + alt_lod kind + alt_data/alt_fl snapshots + alt_atlas identity). Stored when a fidelity build lands while the chunk is inside the ring; freed on ring exit (recenter walk), candidate entry, or stale data. At commit, if the alt cache holds the needed kind and is valid (data/fl equality + atlas identity + no pending light/fluid/tex dirty) → swap_to_cached(): 0 ms instance-mesh toggle on the main thread, demoted LOD becomes the new alt cache (while still in ring). Otherwise retain + worker build.

Handoff safety: the stale-band drop path (BANDBREAK) now routes through _tm_retrigger (meshed → light_pending) instead of _enqueue_build (early-returns for meshed chunks) — a re-reband mid-flight can no longer strand a lod_pending chunk.

Risks

  • Alt-cache staleness (edit/bucket/texture-swap after cache): guarded by data/fl native equality + atlas identity + pending-dirty checks; on miss the retain+build path refreshes the cache on landing.
  • Stranded lod_pending on mid-flight re-reband: closed by the BANDBREAK → _tm_retrigger change (meshed chunks re-enter light_pending, which is never skipped for meshed chunks).
  • Boundary p95 standing value: reband now does a main-thread instant swap (≈ ms) or defers to the worker (was kill+requeue) — expect small, possibly better, per-frame cost; coordinator's heavy run confirms.
  • RAM: ring chunks (taxi 11–14, ≤ ~208 at r50) hold a second LOD: ≈ 0.2–0.4 MB data snapshots + one extra chunk-mesh each (AC-0184 anticipated "+~400 slabs").
  • Headless probe wall: r15 path-region build ≈ 30–90 s (drain streams ahead of the walk); probe is condition-waited, not fixed-wall.
