AC-0384 r6 — the cloud layer: make it read like No Man’s Sky (thick, banded, volumetric) without regressing the r5 anti-aliasing fix

Goal

One sentence: make the cloud deck a thick, occluding, banded layer with visible depth (darker undersides) from both orbit and low altitude, while the disc grain at every ladder altitude stays at or below the round-2 baseline (2600 m: ≤ 2.09 tight / ≤ 4.87 canonical).

Current look (established before any change)

  • Frames of record (current tree, byte-identical to r5’s): rd5-fix-d{2600,1600,700,300,120}.png, viewed at the five ladder altitudes. Pre-fix grain measured from them this round (same boxes as r5): 2600 m 4.87 / 2.09, 1600 m 3.66 / 0.71, 700 m 2.92 / 0.70, 300 m 2.38 / 0.96, 120 m 9.86 / 16.70 (canonical / tight) — identical to r5’s published numbers.
  • Orbit (2600 m): clouds are faint, thin white mottling — sparse, low opacity, isotropic blobs, no banded structure, no depth. The deck does not occlude the surface.
  • From underneath (120 m): the sky is a flat white wash — the cloud deck is invisible from below. Code cause: graze = smoothstep(0.02, 0.18, max(dot(n,V),0)); viewed from below, dot(n,V) ≈ −1 → graze 0 → alpha 0. The fade was tuned for the orbit silhouette (where it is correct) but it zeros the entire underside.

Changes (all in core/cloud_layer.gdshader, fragment stage; the r5 per-band distance-LOD clamp and u_cpxrad are untouched)

New uniforms are shader-side defaults, never pushed — scenes/main.gd (still fenced, another session’s in-flight work) is not touched at all. The weather pattern (base/mid/fine/band) stays a function of world direction + time-of-day only; the only view-dependent term is the geometric graze fade (same class as before, corrected to handle the underside). No-pop argument survives: nothing new keys on player distance.

Ruled out: (a) a 4th shell — the 3 shells already provide the altitude spread; the problem is they read as separate thin veils, so opacity + depth cues fix that without a new draw call / mesh; (b) limb-thickening — view-dependent alpha would fight the graze fade and risk a hard white rim at the orbit silhouette; (c) raising CLOUD_AMOUNT_DAY (0.75) — shared AeroLib constant, would move the night deck too; u_boost does the job locally.
