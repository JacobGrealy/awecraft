5.2 The fix — billboarding without rotating the field (star.gdshader vertex)

With the field orientation fixed at identity, the local-XY quads no longer face the camera (a star on the sphere's −X side would be edge-on / invisible). Billboarding must come from the SHADER, applied in the camera's world basis, leaving the world-space centers untouched. Replacing vertex :13-15 (render_mode :8, uniforms :10-11, fragment :17-20 unchanged):

void vertex() {
	vec3 w = (MODEL_MATRIX * vec4(VERTEX, 1.0)).xyz;          // star center, world space
	mat3 v = mat3(VIEW_MATRIX);
	vec3 cam_right = transpose(v) * vec3(1.0, 0.0, 0.0);       // row 0 of the view rotation = camera right (world)
	vec3 cam_up = transpose(v) * vec3(0.0, 1.0, 0.0);          // row 1 = camera up (world)
	vec3 off = (cam_right * (UV.x - 0.5) + cam_up * (UV.y - 0.5)) * quad_size;
	VERTEX = w + off - vec3(MODEL_MATRIX[3]);                  // back to node-local (node basis = identity, origin = eye)
}

Derivation / why it is exact: VIEW_MATRIX (world→view) = [Rᵀ | −RᵀC] where R = camera world basis (columns: right, up, −forward). So row 0/row 1 of mat3(VIEW_MATRIX) = camera right/up in world space; the quad corner = world center + (right·(u−0.5) + up·(v−0.5))·0.70 — the same screen-aligned quad the web's PointsMaterial draws (sizeAttenuation:false, :727), with the same UV.x→right / UV.y→up mapping the shipped local-space shader already proved in the G6 render. MODEL_MATRIX here is translation-only (origin = eye, identity basis) so vec3(MODEL_MATRIX[3]) = the eye and the returned local offset composes exactly. Depth behavior is unchanged: at any instant the world-space star set is still the r=320 sphere centered on the eye (320 > all visible geometry, fog_disabled, depth test on — identical to today). MODEL_MATRIX in the vertex stage is PROVEN in this tree (the AC-0035 player-light v_world_pos = (MODEL_MATRIX*vec4(VERTEX,1)).xyz varying shipped + rendered, 4.7.1, llvmpipe); VIEW_MATRIX is the same documented family. Fallback if transpose() is unavailable in the shading language: vec3 cam_right = vec3(v[0].x, v[1].x, v[2].x); vec3 cam_up = vec3(v[0].y, v[1].y, v[2].y); (§7 row 1). Update header :1-6 to describe the fixed design (world-fixed field, camera-basis billboards).
