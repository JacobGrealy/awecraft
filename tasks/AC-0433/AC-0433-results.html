F2The raw-ring drop was a live wall. parse_nbs dict-only check (pre-AC-0433) silently dropped every bare PBA ring — face home edges, face window/sector/absent edges, AND the home-lane past-patch edges (_patch_edge_ring stores PBAs too) — so the neighbour read as air and the build emitted full-height boundary walls. Fixed in parse_nbs (one branch); the home-lane past-patch edges are fixed by the same branch (their walls pointed face-ward — behind the landing row — invisible to the crossface walk, which is why the arm never caught it).
F3The home-edge extension is ring-state-gated (the face re-bake gap). A face chunk's home ring is a snapshot at face-build time; the home straddler's data normally lands AFTER the face build (this run: straddler queued "build" from frame 300, still unbuilt at 2400 — the documented jump-band stall, §F4). Built against an air ring, the home edge extends nothing (measured: r6 initial [0,0]). There is no re-bake hook for home data landing later — the "act requires tn ≥ 0" contract. Closing the ordering = P0.5/P2 of the plan (the re-bake read in the probe shows the mechanism works once the ring is live: [−0.47, −0.008]).

It stays "build"-queued forever in the headless probe. How it passes in the live game remains open (the crossface C4 proves the 196 sliver builds there). Not this round's blocker; note for P0.5.
