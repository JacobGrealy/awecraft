3. The measurement

3.1 What is compared. Both models place a surface point from the same chart direction; they differ in HOW. So compare, at identical chart coordinates and identical heights, the position each model produces:

  • Canonical: P_c = (R+h)·normalize(SM.uv_to_world(face, u, v, R)) − (0,R,0).
  • Legacy, non-home charts: P_l = SM.face_chunk_transform(face, ccx, ccz, R) · local, where local is the cell's local centre in the legacy 1024-grid chunk that contains (u,v) — compute iu = floor(u·1024), iv = floor(v·1024), ccx = iu>>4, ccz = iv>>4, local.x = SM.face_local_x(face, iu, ccx) + 0.5 (the mirror-aware slot), local.z = (iv & 15) + 0.5, local.y = h.
  • Legacy, home pair (faces 0/1): P_l = SM.column_transform(cx, cz, R) · (x−cx·16, h, z−cz·16), where the flat coords come from SM.world_to_flat of the canonical point's direction — or equivalently from the flat (x,z) that correspond to (u,v) on the home pair via hw = face_width(R)/2, x = (u − (face==0 ? 0 : 1))·hw, z = hw·(2v−1).

Report |P_c − P_l| — the distance the ground would move at that point.

3.2 Sample sites (all at R = Game.planet_R if available without the game tree, else 4000 — state which in the RESULT). For each of these groups, sample at h = 0 and h = 140:

  • G1 interior non-home chart: for faces 4..11, chart coords (u,v) at the centre of 3 cells along each axis, sampled from {0.25, 0.5, 0.75} — interior only.
  • G2 home/face seam: the crossing sites — for faces 4..11, the cells adjacent to the home edge (the same class as the arms' F audit): take v (or u) at the last cell next to the home boundary, several positions along the edge.
  • G3 home pair interior: flat points near spawn and 500 m out, both faces.
  • G4 the documented corner site: face 4 at the site the harness arm uses (iv = 1000), if reachable by the same construction.

3.3 Report per group: count, max displacement, mean displacement, and the worst site (face, u, v, h). Plus the overall max. All distances in metres, rounded to 6 dp.

3.4 Sanity guards (these are also findings, not failures to hide). If a legacy transform cannot be built for a site (out of the legacy grid), count it as skipped and report the count rather than inventing a value. If a displacement exceeds 1000 m, report it plainly — that is information about the legacy model, not an error in the probe.

3.5 Output. ONE RESULT {…} JSON line (this time JSON, not key=value), including: ok, R, h_values, groups {G1..G4: {n, max_m, mean_m, worst}}, overall_max_m, overall_worst, skipped, fails. Exit 0 always unless the probe itself errors; this is a measurement, so a large displacement is a RESULT, not a failure.

5. Acceptance

6. Risks

The legacy side is easy to get subtly wrong (mirror-aware local x, the 16-cell chunking, the home flat mapping) — if a group's numbers look implausibly uniform or implausibly huge, say so in the deviations rather than massaging the code to look right. A broken instrument that reports small numbers is worse than no instrument.
