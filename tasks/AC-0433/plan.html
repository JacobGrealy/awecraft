3. Edit shape

3.1 The lattice fact. Read off the shipped vertex_key (planet_grid.gd:52-71) — every chart cell covers exactly one unit square of the cube lattice, because each face maps its cell index to a lattice corner by adding only an integer offset. Encode (plane, sign, a, b), plane = the even face id of a cube plane (0,2,4,6,8,10), sign = +1 even / -1 odd, a and b in-plane lattice cell indices in [-N, N):

facea =b =
0, 2, 8, 10ij - N
1, 3, 9, 11i - Nj - N
4, 6i - Nj
5, 7i - Nj - N

3.2 Two new public statics (append after address_key, same sentinel style as P2a):

  1. cell_lattice(face:int,i:int,j:int,R:float) -> Dictionary — {ok:true, plane:int, sign:int, a:int, b:int} for a valid cell (half-open i,j domain from grid_shape), else {ok:false}. plane = face - (face % 2); sign = +1 if face even else -1; a,b from the table.
  2. cell_owner(plane:int, sign:int, a:int, b:int, R:float) -> Dictionary — exact inverse, {ok:true, face:int, i:int, j:int} or {ok:false}. plane must be 0,2,4,6,8,10, sign +1/-1, a,b in [-N,N). face = plane + (0 if sign > 0 else 1). Non-X planes (0,2,8,10): i = a + (N if sign < 0 else 0), j = b + N. X planes (4,6): i = a + N, j = b + (N if sign < 0 else 0).

3.3 The probe — two tests, one RESULT line, exit 1 on any failure.

  • T1 round trip + collisions. All 12 faces, i,j from {0, 1, 15, N/2, Nu-2, Nu-1} clamped to each face's domain and de-duplicated: cell_lattice -> cell_owner returns the identical (face,i,j); cell_owner -> cell_lattice returns the identical (plane,sign,a,b). Collect identities in a set keyed "plane:sign:a:b"; require set size == distinct cells tested (identity_collisions 0).
  • T2 corner agreement with vertex_key. For each tested cell, Q00=vertex_key(face,i,j), Q10=vertex_key(face,i+1,j), Q01=vertex_key(face,i,j+1), Q11=vertex_key(face,i+1,j+1). Rebuild the same four corners from the lattice identity with a plane table (normal axis coordinate sign*N; the two in-plane axes carry a,b, and +1 for the opposite corner). Require exact integer equality and that Q10-Q00 and Q01-Q00 are single unit axis steps. corner_mismatches must be 0 — this is the "one cell size on every chart" proof.
  • Negative control. Corrupt one identity (b+1 on a fixed cell) and assert T2 then fails on it (negative_detected=true), so a green run cannot be vacuous.

RESULT keys: ok, cells, round_trip_mismatches, identity_collisions, corner_mismatches, negative_detected, fails.

5. Acceptance

Identity and inverse agree both ways on every sampled cell, no two cells share an identity, the corners rebuilt from the identity match vertex_key exactly, and nothing built on the API has a caller.

6. Risks

The table must come from vertex_key, not intuition — T2 is the check. A cell that maps outside [-N,N) is a plan bug: report it, do not shift the range.
