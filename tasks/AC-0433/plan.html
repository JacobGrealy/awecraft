3. Edit shape — no unresolved forks

  1. Grid under test. R=4000 is the stated fixture, not a replacement production constant. H=SphereMath.face_width(R)/2; N=16*ceil(H/16). Nu,Nv=(2N,N) for faces 4–7; (N,2N) otherwise. Expected N=3152; full=6304. Report slots=12*(N/16)*(2N/16), midline step H/N, measured edge-length min/max over the sample grid. Mark formulas/predictions separately from measured extrema.
  2. Canonical vertex coordinates. Integer cube triple Q at grid vertex (i,j): f0=(i,N,j−N), f1=(i−N,N,j−N), f2=(i,−N,j−N), f3=(i−N,−N,j−N); f4=(N,i−N,j), f5=(N,i−N,j−N), f6=(−N,i−N,j), f7=(−N,i−N,j−N); f8=(i,j−N,N), f9=(i−N,j−N,N), f10=(i,j−N,−N), f11=(i−N,j−N,−N). Use Vector3i keys or exact string triples, never rounded world positions. Canonical direction = SphereMath.uv_to_world evaluated at a deterministic owning face (the face_for_dir tie order on raw Q, then chart inverse formulas from source lines 129–144 applied to Q/N; NOT world_to_face(Q), because Q is unwarped cube coordinates). Then P=(R+h)*n−(0,R,0). Direct chart samples must agree with this direction within 0.001m in world space.
  3. Sample all classes. Each face boundary: edge endpoints plus t=k/32 for k=0..32, and one-cell neighbours where useful. Counts are multiples of 16, so these are integer vertices. Group identical Q across charts; compare positions for all incident faces at h=0,140,168. Also sample an interior chunk's edges (chunk coordinates 1,1 and adjacent) on each face. Expected shared-edge gap≤0.001m. This is equal-height embedding proof only, not mesh watertightness.
  4. Inverse. For each face, sample interior cell-centre coordinates at fractions 0.125/0.375/0.625/0.875 of each dimension, heights 0/140/168. Forward via shipped uv_to_world; inverse via shipped world_to_face on planet-centred P and radial h=length−R; multiply u/v by shape of returned face; forward again. Record max world round-trip error≤0.001m and owning face consistency for strictly interior points.
  5. Negative control. On a fixed f0 boundary vertex at t=0.5 and h=168, compare correct P against a deliberately one-cell-shifted endpoint on that chart. Must produce gap>0.001m, and negative_detected=true. Never count an intentionally removed geometry region as a mapping pass.
  6. Old controls. Copy only control-site selection from existing _ac0433probe_test, calling production transforms. Reproduce home/home ds0≈0.002m (±0.01), lean≈0.004/m (±0.00005); face/face u≈0.02454/m and v≈0.01227/m (±0.00005); home/face f4 iv1000 ds0≈3.732m (±0.01). Use source control coordinates from the arm, not guessed ones. Emit actual values and control_ok fields. If mismatch, report failure, do not alter tolerances/model.
  7. Output. One RESULT JSON with ok, R, N, grid dimensions/slot count, heights, sample/group counts, max shared gap, max direct-vs-canonical error, inverse error, negative gap/detected, old controls and measured edge-length range. If an assertion fails: ok=false, exit nonzero, concise HONEST DEVIATION; stop, do not redesign. Log to .scratch/AC-0433-gates/p1-probe.log.
