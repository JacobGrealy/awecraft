3. Edit shape and exact contract

  1. Module. New pure static RefCounted PlanetGrid, const SM=preload("res://core/sphere_math.gd"), CHUNK_WIDTH=16. No mutable cache, allocations proportional only to one query (no planet enumeration). grid_shape(face:int,R:float)->Vector2i: N=16*ceil(SM.face_width(R)/2/16), faces4..7=(2N,N), other faces0..11=(N,2N). Invalid face or nonfinite/nonpositive R returns ZERO.
  2. vertex_key(face:int,i:int,j:int,R:float)->Vector3i. Closed vertex domain 0≤i≤Nu,0≤j≤Nv. Exact integer cube formulas from P1 _vertex_q (not float-position rounding). Invalid returns Vector3i.ZERO, impossible for valid surface vertices. Identical keys at chart joins/cube edges/corners. Do not use string or flat legacy keys.
  3. vertex_to_world(face:int,i:int,j:int,h:float,R:float)->Vector3. Validate key/finite h and R+h>0; invalid returns Vector3(INF,INF,INF). Canonical owning face=SM.face_for_dir(Vector3(Q)), uv from Q/N using P1 _canon_uv exact affine formulas, then n=SM.uv_to_world(owner,u,v,R).normalized(). P=(R+h)*n−Vector3(0,R,0). Every incident chart uses canonical evaluation, giving bit-identical coordinates for the same key/h.
  4. cell_to_world(face:int,i:int,j:int,k:int,local:Vector3,R:float)->Vector3. Cell bounds 0≤i<Nu,0≤j<Nv; local=(fraction_i,fraction_height,fraction_j), each finite in [0,1]. h=k+local.y (one-metre radial heights), require R+h>0. Invalid returns INF vector. Let gx=i+local.x,gz=j+local.z. When gx,gz are both exact integers, call vertex_to_world so shared cell corners agree bitwise; otherwise call SM.uv_to_world(face,gx/Nu,gz/Nv,R).normalized() and same radial formula. No mirror/local-X reversal: this API uses chart-index order, mesher winding adapter is later.
  5. world_to_cell(pos:Vector3,R:float)->Dictionary. Invalid finite/radius/planet-centre input returns {valid:false}; reject planet-centred length≤1e-6. Add origin shift (0,R,0); h=length−R; use SM.world_to_face on planet-centred point. Clamp u,v to [0,1] for roundoff; gx=u*Nu,gz=v*Nv; i=clampi(floor(gx),0,Nu−1), j likewise, k=floor(h), local=(gx−i,h−k,gz−j). Return {valid:true,face,i,j,k,local}. At owned upper boundary i=Nu−1,local.x=1 is intentional, not a wrap. Face ownership uses shipped tie order; do not invent an epsilon that changes neighbours. Exact seam/corner byte behaviour is tested via forward vertex API, not claimed for float inverse ownership.
  6. address_key(face:int,i:int,j:int,k:int,R:float)->String. For valid cell indices and radius return "%d:%d:%d:%d" of face,i,j,k; invalid returns "". Planet ID/storage/chunk-key version belong to later persistence stage; this pure intra-planet key is NOT an activated save format. Validate i/j as above; integer k has no artificial legacy height limit. This method only defines cell identity; does not replace runtime keys.
