AC-0433 P2c-1 — chunk addressing and chunk-level adjacency

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Cells became total last unit; this lifts the same identity one level to the 16×16 chunk, which is the unit storage and streaming will use. Dormant: no caller, no save key.

1. Goal

Address a chunk by (face, cx, cz), prove chunk boundaries never straddle a chart edge, and resolve chunk neighbours — including across cube edges — so streaming can walk the world at chunk granularity.

3. Edit shape

3.1 Three statics (append after cell_neighbour; same sentinel style):

  1. chunk_of(face:int, i:int, j:int, R:float) -> Vector2i — the chunk holding cell (i,j): integer division of i and j by CHUNK_WIDTH. Invalid face/radius/cell -> Vector2i(-1, -1) (never a valid chunk, since real cx/cz are >= 0).
  2. chunk_cell_origin(face:int, cx:int, cz:int, R:float) -> Vector2i — the chunk's cell-min corner (cx*16, cz*16); invalid chunk (outside that face's chunk grid) -> Vector2i(-1, -1).
  3. chunk_neighbour(face:int, cx:int, cz:int, dir:int, R:float) -> Dictionary — the neighbouring chunk in dir (0 = -i, 1 = +i, 2 = -j, 3 = +j), {ok:true, face, cx, cz} or {ok:false}. Implement it as: take the chunk's cell origin, pick the crossing cell (dir 1 -> i0+15, dir 0 -> i0, dir 3 -> j0+15, dir 2 -> j0), call cell_neighbour on it, and return chunk_of of the result. Do not invent a second fold rule.

3.2 Why that is exact — and what the probe must prove rather than assume. Every face's cell dimensions are multiples of 16 (N = 16·ceil(…), long axis 2N), so no chunk straddles a face edge; and a fold rotates a 16-wide strip onto a 16-wide strip, so the far chunk is well defined.

3.3 Probe (new p2c1_probe.gd; one RESULT line; exit 1 on any failure).

  • T1 chunk grid exactness. For all 12 faces: grid_shape divisible by 16 on both axes (exactness_failures 0), and chunk_of(chunk_cell_origin(c)) returns c for every sampled chunk (cx, cz from {0, 1, last-1, last} within the face's chunk grid).
  • T2 chunk neighbour is one chunk wide. For every sampled chunk and dir: call chunk_neighbour, then for ALL 16 crossing cells of the source chunk, chunk_of(cell_neighbour(cell, dir)) must equal the returned chunk. A cell landing anywhere else is a straddle. Report chunks_checked, crossing_cells, straddle_failures (0).
  • T3 reciprocity. For each neighbour found, the far chunk must have SOME dir whose chunk_neighbour returns the source chunk — search all four, do not mirror (folds rotate the return dir, measured last unit). Report pairs and reciprocal (must equal pairs).
  • T4 invalid. face -1/12, R 0/negative/INF, negative and out-of-range cx/cz, dir -1/4 -> the documented sentinels, no SCRIPT ERROR. Report invalid_cases, invalid_failures (0).
  • Negative control. Take one valid T2 result, shift the far chunk's cz by 1, and confirm the crossing-cell check then fails (negative_detected true).

RESULT keys: ok, faces, exactness_failures, chunks_checked, crossing_cells, straddle_failures, pairs, reciprocal, invalid_cases, invalid_failures, negative_detected, fails.

5. Acceptance

Chunks tile each face exactly, a chunk neighbour is one chunk wide with no straddle, reciprocity holds, and the module still has no caller and no save key.

6. Risks

Deriving chunk folds independently instead of through cell_neighbour is the failure mode — reuse it. An off-by-one on the crossing cell (i0 vs i0+15) shows up as a straddle failure.
