Item 2 — what changed for the limb, and why per-material

The defect (pre-fix fragment, the only limb term in any near-tier path):

// godot/core/lod_avg.gdshader (PRE-FIX, removed): float taxi = abs(v_world_pos.x) + abs(v_world_pos.z); // Manhattan distance from the WORLD ORIGIN float w = 1.0 - smoothstep(336.0, 384.0, taxi); float haz = mix(1.0, fog_f, w); // outer 48 m of the annulus: FORCED 100% air

The fix (post-fix fragment — fog only, nothing else):

// godot/core/lod_avg.gdshader (POST-FIX): float fog_f = clamp((d - u_fog_near) / max(u_fog_far - u_fog_near, 1.0), 0.0, 1.0); float haz = fog_f; // the engine depth-fog model, as in band A ALBEDO = mix(ALBEDO, u_air, haz);

Per-material, not gated: the term is gone from the path — there is no uniform, no smoothstep, no condition a later change could flip back. At the fog wall (d = u_fog_far) fog_f = 1.0, so the annulus ends in exactly u_air where the body's haz_d rim begins — the AC-0400 single-source seam (one u_air, AeroLib.fog_display, pushed to body + sky + annulus) holds at every view distance.

What the removed term did in the user's state (player at taxi 400 from the origin, the w=0 side of the annulus) — deterministic evaluation, R24/F83 (fog 100→332 m):

The pre-fix annulus showed a hard 100%-air ring 336–384 m from the origin at any altitude — the "rim around the low LOD" — with fog applied only inside 336 m. The post-fix annulus fogs exactly like the high tier does at the same distance, and the two tiers are indistinguishable at the wall.

The missed case — measured now. The rim on near terrain seen from a gate-open altitude: the 700 m rung (S = 0.132, gate open) is that altitude. The near tiers draw 0 px there (body-off vs world-off frames: 0 differing pixels, before and after) because the fog wall (332 m view distance) discards them before the gate opens (500 m radial). The rim visible at 700 m is the satellite body's own haz_a rim (42.31% of the frame) plus the gated background glow (S = 13.2%) — the limb is the body's alone, exactly as the ticket demands. In the user's own state (gate closed, near tiers drawn), the w-band is what painted the rim — and it is now gone (deterministic table above + probe frames below).
