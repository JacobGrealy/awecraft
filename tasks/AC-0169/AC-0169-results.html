Deviations / honest-value notes

Godot 4.7.1 has none of OS.get_cpu_usage() / OS.get_process_memory_usage() / OS.get_total_memory() / OS.get_free_memory() (verified against 4.7 class docs; 4.7.1-stable source tree). Overlay uses the closest honest real APIs, each labeled in the text:
  • FPS = Performance.get_monitor(Performance.TIME_FPS) (frames in last second; 4.7 renamed the old MONITOR_* names).
  • CPU (process %) = ΔPerformance.TIME_PROCESS (s/frame) over the 0.25 s tick → % of 1 core consumed by the process callback, labeled "of 1 core" in the text (multi-core totals are not exposed to GDScript).
  • RAM (system) = OS.get_memory_info() → physical/free bytes; displayed used/total + %.
  • RAM (process) = OS.get_static_memory_usage() (engine static memory; debug builds only — reads 0 in release exports), labeled "engine static" in the text. No process-RSS API exists in 4.7.
  • VRAM = Performance.get_monitor(Performance.RENDER_VIDEO_MEM_USED) — the renderer (RenderingServer) video-memory stat in bytes; a real number, no n/a needed. Headless shows 0 (no GPU) — honest.
Menu CheckBox created programmatically in menu.gd _ready (no menu.tscn edit) — avoids .tscn parsing pitfalls per task; positioned after HungerCheck via child-scan + Node.move_child (Godot 4.7 has no reorder_child).
