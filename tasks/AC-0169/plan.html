AC-0169 — plan: debug stats overlay (CPU/RAM/VRAM/FPS)

Goal

Options-menu toggle debug_stats (default false, bool-clamped, persisted in user://awecraft.cfg via Settings) that keeps a top-left overlay of FPS / CPU(process) / RAM(process+system) / VRAM visible during gameplay, refreshed ~4×/s, still updating while the pause/Options menu is open. Harness probe AWECRAFT_LOGIC=debugstats proves on/off visibility + field labels + cross-restart persistence (two godot runs, one HOME).

Files to touch

  • godot/autoload/settings.gd — debug_stats: false in DEFAULTS + bool case in _clamp.
  • godot/ui/menu.gd — programmatic CheckBox "Show debug stats (CPU/RAM/VRAM/FPS)" inserted after HungerCheck in Layer/OptionsBox/Center/VBox (no .tscn edit); wired to Settings.set_value("debug_stats",…); synced in _sync_controls(); OPTSYNC print gains stats=.
  • godot/scenes/main.gd — stats_overlay (CanvasLayer layer 25 + Label "StatsLabel", top-left) created in _create_game_nodes() (idempotent: frees any previous), freed in _free_game_nodes(); 0.25 s tick in _process → _refresh_stats() (visibility from Settings + text from APIs); AWECRAFT_LOGIC=debugstats arm (save phase via AWECRAFT_DSSTATS_SAVE=1, probe phase asserts persisted + visible_when_on/off + text_has_fields, RESULT JSON); render hooks AWECRAFT_DSSTATS=1 (force overlay on in harness runs) + AWECRAFT_OPTS_SNAP=path (second snap of the Options panel inside the existing snapshot finish).

Godot 4.7.1 API reality (verified against 4.7 docs + source tags, not the task's map)

  • FPS: Performance.get_monitor(Performance.TIME_FPS) (4.7 renamed MONITOR_FPS→TIME_FPS).
  • VRAM: Performance.get_monitor(Performance.RENDER_VIDEO_MEM_USED) — renderer (RenderingServer) video-mem bytes; this IS the public VRAM stat, so no "n/a" needed.
  • System RAM: OS.get_memory_info() → physical/free bytes (no get_total_memory/get_free_memory in 4.7).
  • CPU(process): no OS.get_cpu_usage() in 4.7 → sample Performance.TIME_PROCESS (s/frame) deltas over the 0.25 s window → % of 1 core consumed by the process callback; labeled honestly in the text.
  • Process RAM: no process-RSS API in 4.7 → closest honest value OS.get_static_memory_usage() (engine static mem; debug builds only, 0 in release) — labeled as such + deviation note.

Harness gates

     run B  AWECRAFT_LOGIC=debugstats  (fresh process, same HOME: persisted_after_restart,

SMOKE: 'AWECRAFT_BATTERY=player;interact;light;fluids;genhash' all ok:true, genhash 25/25 (world/* untouched)
RENDER: xvfb gl_compatibility, AWECRAFT_SNAPSHOT + AWECRAFT_DSSTATS=1 + AWECRAFT_OPTS_SNAP (2 PNGs, 1 run)

Risks

  • API drift vs task map — mitigated by the verified-4.7 names above; any bad call dies loudly as SCRIPT ERROR at G0/P1.
  • Battery double-calls _create_game_nodes() per mode (pre-existing) → overlay creation frees any prior instance first (no leak growth).
  • Godot one-at-a-time: every run checks ps + .godot_busy first; long arms in background jobs.
  • xvfb GL-init hang → timeout -k 15 480, retry once, else record "render skipped — headless probe carries".
