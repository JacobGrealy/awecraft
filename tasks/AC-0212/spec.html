Goal

AC-0212 (subagent, 2026-09-04)

Remove the per-frame CPU of the AC-0109 manual frustum-cull pass (world.gd _frustum_cull_pass) by making the engine's automatic per-MeshInstance3D frustum culling the DEFAULT; the manual pass is kept intact behind a toggle for A/B + fallback. No pop-in (transitions at the view edge are normal rendering; the spin probe's on-screen-flicker gate stays 0), probe counters updated, and R16 (16-radius build + moving inside a chunk) shows no 5 fps drop in the moving phase.

Task-specific requirements

AC-0212 (subagent, 2026-09-04)
  • Toggle (world.gd): new AWECRAFT_FRUSTUM — manual|1|on = the AC-0109 per-frame pass (legacy behavior); engine|0|off|"" (or unset, with no legacy opt-in) = engine cull (NEW DEFAULT). Legacy AWECRAFT_FRUSTUM_CULL=0 still disables the manual pass when AWECRAFT_FRUSTUM is unset; AWECRAFT_ONLY (probe-only visibility filter) always wins (manual pass defers, as at AC-0109). world.cull_mode exposes the active lane.
  • Zero-cost engine lane: in engine mode _process does one bool check and never calls _frustum_cull_pass — the render server culls each MeshInstance3D by its mesh AABB vs the camera frustum automatically. .visible is never written by script.
  • Margin: the engine cull has no margin (exact AABB-vs-frustum); a slab entering the frustum appears exactly at the view edge — that is normal rendering, not a pop-in. The 32 m off-screen margin lives on the manual lane only (FRUSTUM_CULL_MARGIN unchanged). No per-frame GDScript pass is kept for the margin (that would re-add the removed cost).
  • Probe counters: new world counters perf_cull_passes (manual-pass re-evaluations) + perf_cull_flips (visibility writes), reported by both probe arms. Engine lane reads 0/0 = the per-frame cull cost is gone.
  • Spin probe (AC-0109 G1) updated to the engine lane: instead of reading .visible it replicates the render server's exact per-instance test (instance world AABB fully outside any of the 6 frustum planes → culled; supporting-point test, no margin). All legacy counters keep their meaning (transitions, vis_*, verts_*, queue_flat); new fields: cull_mode, manual_pass, perf_cull_passes, perf_cull_flips, instances_total, instances_hidden.
  • New R16 arm (AWECRAFT_LOGIC=r16): 16-radius build (all band≤2 chunks in the 33×33 square, 25-min in-arm cap, proceeds on partial build) then two per-frame CPU phases — static (600 physics frames, camera parked) and moving (900 frames, camera on a 12 m circle inside the spawn chunk, frustum changes every frame = the manual pass's worst case). Reports frame-ms percentiles → effective fps + the cull counters over the whole arm. Run with --fixed-fps 600 (uncapped ticks → true per-frame CPU, the breakspike convention).
