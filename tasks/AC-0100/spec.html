Task-specific requirements

(1) ./build_windows.sh computes STAMP=$(date +%Y%m%d-%H%M) (LOCAL time) once per run. (2) The godot exports write the STAMPED paths: exports/windows/AweCraft-$STAMP.exe (release, preset "Windows") and exports/windows/AweCraft-$STAMP_debug_console.exe (debug, preset "Windows (console debug)" — Godot's wrapper lands as AweCraft-$STAMP_debug_console.console.exe). (3) AFTER the existing verification block (PE checks, sha256-distinct, wrapper-template cross-check — all re-pointed at the stamped files) the script copies each stamped artifact byte-identical over the un-stamped names: AweCraft.exe, AweCraft_debug_console.exe, AweCraft_debug_console.console.exe. (4) Retention: after a successful build, delete stamped artifacts older than the newest 3 stamped pairs (a pair = the 3 files sharing one STAMP); the un-stamped copies are never deleted. (5) BUILD.txt gains the stamped file names + stamp + the un-stamped-latest note. (6) print_urls prints the un-stamped URLs (unchanged) AND the stamped release URL (localhost + LAN). (7) --no-serve behavior and the daemon mechanics (find_our_server / start_server / port fallback / pidfile) are UNCHANGED.
