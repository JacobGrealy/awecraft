Task-specific requirements

  • godot/autoload/settings.gd — new Settings: dithering_enabled (bool, default true), dithering_start_pct (int 0-100, default 45 = the shipped AC-0227 0.45 coefficient), fog_start_pct (int 0-100, default 87 ~= the shipped AC-0226 0.875 coefficient, kept at/under it so the full-fog boundary stays ahead of the worst-case pop-in face at every R >= 7). Clamped 0-100, persisted in user://awecraft.cfg like every other setting.
  • Percent semantics: percent of the render edge (render_dist + 1) * 16 blocks — the same base the AC-0226/AC-0227 formulas scale from, so the defaults reproduce the shipped tuned behavior exactly (fog 87% is 1.6 m inside the shipped 0.875 at R16).
  • godot/core/daynight.gd — fog_far(R, pct=87.5) + dither_start(R, pct=45.0) take the percent; single-arg calls (harness arms) are no-behavior-change.
  • godot/scenes/main.gd — _update_sky pushes the dither band from the settings every frame (toggle off = 0/0 = the shaders' off state = hard pop); _update_fog pushes fog_depth_end from fog_start_pct every frame; harness preloads AWECRAFT_DITHER_TOGGLE/AWECRAFT_DITHER_PCT/AWECRAFT_FOG_PCT (the AWECRAFT_TM_HO pattern: no save); the R16 RESULT gains a dither evidence block; new fast arm dithersettings reads back the pushed uniforms + fog.
  • godot/scenes/menu.tscn + godot/ui/menu.gd — Options: DitherCheck checkbox + DitherStartRow (0-100 slider) + FogStartRow (0-100 slider), saved via Settings.set_value; the per-frame reads make the apply live (AC-0225 pattern — no extra apply call).
