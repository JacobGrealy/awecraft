What was built

  • Settings (godot/autoload/settings.gd): dithering_enabled (bool, default true), dithering_start_pct + fog_start_pct (int, clamped 0-100; defaults 45 = the shipped AC-0227 0.45 coefficient, 87 ~= the shipped AC-0226 0.875 coefficient kept at/under it so the full-fog boundary stays ahead of the worst-case pop-in face at every R >= 7). Persisted in user://awecraft.cfg with every other setting.
  • Options UI (godot/scenes/menu.tscn + godot/ui/menu.gd): checkbox “Distant dither fade (off = hard pop hidden by fog)” + two 0-100 sliders “Dither fade start %” / “Fog start %” (percent of the render edge, (render_dist + 1) * 16 blocks), synced from Settings on open, saved on change (AC-0225 pattern — the per-frame reads in main.gd make the apply live, no extra call).
  • Wiring (godot/core/daynight.gd + godot/scenes/main.gd): DayNight.dither_start(R, pct) / DayNight.fog_far(R, pct) take the percent (single-arg calls unchanged for the harness arms). _update_sky pushes u_dither_start/u_dither_end to every cached chunk + fluid ShaderMaterial every frame (toggle off = 0/0 = the shaders' off state = hard pop); _update_fog pushes fog_depth_end every frame. Harness preloads AWECRAFT_DITHER_TOGGLE/AWECRAFT_DITHER_PCT/AWECRAFT_FOG_PCT (AWECRAFT_TM_HO pattern, no save); the existing AWECRAFT_DITHER/AWECRAFT_NO_DITHER A/B hooks still win. New fast arm dithersettings reads the pushed values back.
