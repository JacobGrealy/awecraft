AC-0447 — the night is readable but still too dark, measured at true midnight

Status: done (light gates green; heavy gates are the coordinator's). The midnight floor was measured, the ceiling proved to be the tone mapper's dead zone, and the fix belongs to the chunk shaders — a night-only, hue-preserving toe on the predecoded ALBEDO, shipped behind a new night_lift switch (default OFF, AWECRAFT_NIGHTLIFT=0|1 boot env, menu row).

Live uniform dump (t=0.0): u_day=0.0, u_moon=0.25, u_moon_dir=(0, 0.9285, 0.3714), u_amb=0.35, atlas sampled without sRGB decode (runtime format RGB16), so the shader's pow(2.2) predecode is the sRGB→linear step and the ALBEDO that enters the mapper is the predecoded (linear) value. The input has structure and the output is zero — the problem is the mapping. The game's own G-channel transfer curve, measured in-game (unshaded probe quads on the real ground; verified: the g=0.0172 probe point returns byte 18 — the night grass top byte — exactly):

Dead zone below ~0.005; steep rise after. Full-intensity red (1,0,0) → (255,0,0) uncrushed — the environment does not crush highlights, it crushes the dark end. An exposure change can't fix this: the floor needs ×~30 at night and would blow out the day. The honest conclusion: the fix belongs in the per-chunk light model (the shaders), not the engine tone mapper — implemented exactly that way, as the ticket allows.

3. The fix

Eight chunk_lit_*.gdshader (opaque/cutout/flower/fluid + the four _fade variants): after the AC-0242 predecode,

float ac47_lum = dot(ALBEDO, vec3(0.2126, 0.7152, 0.0722));
ALBEDO *= 1.0 + u_night_lift * 42.5 * pow(0.00175 / (ac47_lum + 0.00175), 1.5);

a luma-scaled, hue-preserving gain f = 1 + w·A·(d/(g+d))^p with A=42.5, d=0.00175, p=1.5, fitted against the measured curve: the midnight floor (g≈0.0004) gains ×31.7 (byte 0 → ~12), the moonlit grass top (g≈0.0172) ×2.19 (byte 18 → ~45), the moon-facing side ×~17 (→ ~30); g=0 stays 0; g·f(g) monotone. w = u_night_lift = (1 − day)·switch, pushed per-frame, value-gated from world.gd _ac0401_push to the chunk and fluid materials. At day or with the switch OFF, w=0.0 and f is exactly 1.0 (IEEE: 0·x=0, 1+0=1, x·1=x) — bit-identical. New switch: Settings "night_lift" default false (conservative — AC-0446 far_seam OFF precedent under identical ticket wording), sanitize_bool, menu row "Night: lift the floor (readable midnight)", AWECRAFT_NIGHTLIFT=0|1 boot env (the AWECRAFT_MOON pattern, written WITHOUT save). ARCHITECTURE.md updated in-task (Settings row).
