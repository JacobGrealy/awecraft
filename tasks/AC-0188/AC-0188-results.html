What was ported (the design)

Per the 2026-09-03 user decision, the (cancelled) AC-0198 GDScript sketch was ported directly to C++ instead of a GDScript throwaway. The coarse 3D density replaces the per-column 3D-noise hot path (5x _fbm2chunk 17oct + 3x _fbm3col + 2x _vnoise3col per 98k-cell column):

Spline surface (MC 1.18 style)Per cell: d = ramp((s + 0.5 - y)/6) + 1.8*(cave(x,y,z) - 0.5), solid where d > 0. The ramp is a clamped quintic (same polynomial as _fade, C2 at the clamps). Since |1.8*(cave-0.5)| < 1, d is +1 for y ≤ s-6 and -1 for y ≥ s+7 — only the 14-block band around the surface needs the trilinear (the rest is free). The zero crossing is the surface: cheese/noodle 3D-connected caves (the cave field is 3D-continuous, not a per-column threshold carve).
Effective surfaceh_eff = topmost solid y in [s-6, s+6] per column (pad columns keep the exact pad height — the spawn contract). Surface block / 3-dirt band / ocean fill (h_eff+1..sea) / sand-shore rules use h_eff (the old world used s because s WAS the surface).
Deep zone (replaces 2x _vnoise3col)y < 16 (non-pad columns): cave < 0.42 carves; y < 8 fills lava (MC-style deep lakes) instead of air.
Ores (replace 3x _fbm3col)Same bands/thresholds as before (diamond y<16 >0.78, iron y<42 >0.8, coal y<60 >0.82) read from the coarse ore fields; obsidian keeps the EXACT old per-cell hash3i(x,y,z,seed+333) < 0.02 (y<10).
Trees + flowersExact old hash logic (hash2i seed+55/66, 0.14/0.14/0.02 densities, 20x20 neighborhood, same leaf/skip rules), but the tree base is h_eff (the effective surface) instead of s; margin columns (2-ring) get the same surface scan from the extended fields. Flowers use the same hash gates on the h_eff grass tops.

Face handling (the "face" arg of the task title): the C++ API is generate_flat/slabs/resl(cx, cz, seed, h, sea); the face is applied by the CALLER exactly as GDScript does it — generate_face passes face*64+cx, face*64+cz, seed ^ face*1000003 into generate_args, which now delegates to C++, so face columns get the identical salted-domain treatment.

  • AC-0206 caveat not hit: the .so loaded and ran fine in this (subagent) env for every gate; no coordinator-env crash encountered here.
