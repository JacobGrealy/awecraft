Notes. (a) The after static phase carries the remesh-wave tail: with handoffs spreading 1/frame the E2 light wave's ~1300 remeshes drain ~2.5x slower, so the tail overlaps the static window (before: the wave closed during the build/early-static window and the static phase ran idle). Per-frame cost is the same work (1 handoff + 1 flush dispatch, a few ms) — p50 moves 5→6 ms, p95 stays in the ~480-500 ms periodic-event band (501; AC-0212's own A/B showed 478-507 on the same phase), the 993 ms max is a one-off in 600 frames, and the moving phase — the actual "moving forward" measurement — is identical. (b) The before run carried AWECRAFT_TIMING=1 (extra print overhead), so the after numbers are if anything conservative. (c) The build-phase wall grows ~3x at r16 (9.9 s → 29.4 s) — the intended trade: the initial r16 fill spreads over ~30 s of 1-mesh frames instead of ~10 s of bursts; steady-state walking is unaffected (the TM pool is only 3-6 deep, so 1/frame handoff ≈ the workers' own rate). (d) Env flake (not task-related): the first before-run attempt hit the AC-0206 known non-repro signal-11 .so segfault (mid threadmesh_poll, 12.6 s in); retry clean.
