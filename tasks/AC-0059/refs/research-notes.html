Facts settled

  • Armor column: LEFT in vanilla (measured x15-47 col, 4 slots). Spec's right-side assumption corrected per reference.
  • Table GUI has NO armor column and NO model area (verified from crafting_table.png: only 3x3 + output + 4x9 rows).
  • Tooltip: MC classic style yellow text.
  • Recipe-click root cause: (1) RecipeRow._gui_input required Input.mouse_mode==VISIBLE but table GUI opened via RMB-use keeps CAPTURED; (2) _recipe_click FABRICATED grid items without consuming inventory ingredients.
