AC-0409 — is unbodied_built_final = 8 stale, or a real leak?

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Diagnosis first, then one of two changes — and the ticket names both, with the reasoning that decides between them.

1. What is known (from AC-0408 — do not re-derive)

  • unbodied_built_final reads EIGHT; the requirement that it be zero comes from AC-0077's G5b.
  • AC-0408 established the eight is TREE STATE, NOT DAMAGE: a pristine-library A/B pair reads the same eight, and the immediate-footprint fence reads zero. So it is reproducible and not caused by recent work.
  • What is NOT established: whether the "must be zero" requirement is STALE — written when the world and its lanes were smaller, before the carve work changed the far lane's behaviour by an order of magnitude (the same era that made the staging counter's ceiling stale, see AC-0408) — or whether it is a REAL GAP where eight objects per build are created without a body registered, unnoticed because the requirement was never re-examined.

2. The decision this ticket must make, and the standard for making it

  1. 2.1 Find what unbodied_built_final actually counts: which lane creates what, what "unbodied" means for that object, and why exactly eight. Eight is a suspiciously small and specific number — explain it as a mechanism (e.g. "the far lane's 8 surrounding slabs per build"), not as a number that happens to appear.
  2. 2.2 Decide with evidence: expected for the current world, or a real gap.
  3. 2.3a If EXPECTED: re-base the requirement with the reasoning stated in the gate — and add a TRIPWIRE THAT CATCHES A RISING COUNT rather than any non-zero one. The ticket says why and it is the whole point: "a bare 'must be zero' that is quietly allowed to be eight is exactly how a real leak becomes invisible." A re-based threshold of "eight is fine" would retire the gate's ability to catch a ninth.
  4. 2.3b If a REAL GAP: find where the eight come from and say which eight objects per build lack a registered body.
