2. What the record actually was, and why the key was missing

The low-lane worker (_tm_worker_run, world.gd:7300+) returns one of three shapes:

shapewhenkeys
full emitthe C++ low_emit_avg/h_avg_emit ranv i n c mh (+ water wv…); mesh.cpp always sets these together
all-airthe sample grid is all air{"empty": true} only
pre-start early-outthe live band tier moved while the task sat in the worker queue (world.gd:7307-7311 — the tier check runs at worker START, after the dispatch captured its tier){"skipped": true} only — no v, no empty: no emit ran

The stale-tier branch of _low_handoff (world.gd:2949, pre-fix) — taken when the live tier differs from the dispatch tier at handoff — cached the result into c.low_cache[si] guarded only by res.get("empty", false), i.e. it assumed every non-empty result was a full emit, and indexed res["v"] (the error, reported on the Dictionary literal's first line 2952; the failing access is at 2956). A {"skipped": true} record has neither key — the tier record that "does not carry the same fields as the full tier" (the ticket's candidate, exactly). The sequence: dispatch at tier T → tier moves while queued (a recenter) → worker start sees the moved tier → no emit → {"skipped": true} → handoff still sees the moved tier → stale branch → res["v"] → error. Rare, because it needs a queued task to straddle a boundary move and the tier to still differ a few ms later at handoff: the low queue caps at 64 in-flight tasks (LOW_TASK_CAP) and the drain paces dispatches (~300-480/s, LOW_WAVE_PACE_MS/FRAME_CAP) against an idle 4-thread pool, so the queue is nearly always empty — the r16 fly50 phase only ever hits it because the continuous crossing stream keeps the pool backlogged (1 in the coordinator's run).

What was "not handed off": a skipped emit produced no mesh — there was nothing to attach or cache. The slab was never stamped, so it stays PENDING against its live tier and the drain re-picks it (the non-stale path already treats a skipped record exactly this way, world.gd:2971). The error aborted the handoff mid-bookkeeping; the re-pick recovered the slab — but the moment carried no low placeholder for that slab (the hole/gap class the ticket warns about), and every occurrence leaves a script error the arm's verdict cannot see.

3. Reproduction at will

The natural arm is too rare to loop usefully (one fire in the coordinator's full run; the skip window is sub-millisecond under an idle pool). So the condition was constructed deliberately with a temporary measurement arm (ac0442repro in harness.gd — added for this repro and removed in this same task per the pristine rule; zero references remain). It uses the real lanes end to end (the r16 pin: render 16 / med 5 / low 10 / sim 4; the real drain, worker pool, and handoff) and holds the one thing the game's streaming does in flight: a backlogged pool. Construction: flood the shared WorkerThreadPool (the SAME pool the low emits ride, HIGH priority) with 40 × 100 ms harness-owned dummy tasks (~1 s of full-thread busy on this 4-thread box) while the tier knob low_start flips 6↔15 every ~15 ms (the wide range re-pends the whole boundary ring, so the drain's dispatch supply never runs dry). The low queue saturates at 64 behind the dummies; when the dummies finish, the backlog's tasks START after the last flips — every one of them straddles a tier change and the worker's pre-start early-out fires on it.

4. The fix

One condition, godot/world/world.gd, _low_handoff, the stale-tier branch:

# pre-fix:
if not bool(res.get("empty", false)):
    c.low_cache[si] = { …, "v": res["v"], "i": res["i"], "n": res["n"], "c": res["c"], … }

# post-fix:
if not bool(res.get("empty", false)) and res.has("v"):
    c.low_cache[si] = { … }   # unchanged

Only a result that actually carries a mesh is cacheable — the four indexed keys are set together by both C++ emitters, so res.has("v") is the exact precondition. A skipped record (dropped, counted in low_drop_stale_n as before) means no emit ran: there is nothing to cache, and the slab — never stamped — stays PENDING against its live tier, exactly like the non-stale path's treatment of the same record (world.gd:2971). The drain re-picks it at the live tier. No other code path indexes a low result without a guard: the non-stale path checks empty/skipped before touching v/i/n/c, and the flip-back cache consumer (_low_attach_cached) only ever sees entries built with all four keys. No C++ change, no format change, no new switch — the pre-fix behaviour of every non-skipped shape is untouched (byte-for-byte the same cache decision, the same counters).

  • WorkerThreadPool (engine singleton) exposes no thread-count API to GDScript in this 4.7.1 build (thread_count/set_thread_count absent — probed) — future harness work that wants to throttle the pool must flood it with its own tasks instead.
