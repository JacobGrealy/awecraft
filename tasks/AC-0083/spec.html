AC-0083 — Item drop shows the broken block's texture

Status: open (top priority) · Source: user report 2026-08-23 · Project: AweCraft (Godot port, live work) · Spec reference: frozen web ../index.html (build 20260816-r12) — source of truth for ALL behavior/data.

User report (verbatim): "when you break blocks, the small block that you can then pickup should have the texture of the block you broke, but currently they just have a solid color."

Requirement

When a block is broken, the world drop entity (the small pickup item that spawns and can be walked up to and collected) must render with the same UV-mapped block-face texture as the block it drops — not a flat solid color. It should look like a small version of the broken block.

Known location

  • godot/entities/drop.gd — the drop item entity (0.3 box + Area3D r1.1, attract <2.5, pickup <1.1, 120 s life). This is where the solid-color box is created. REPLACE the solid material with a per-face block texture.
  • godot/core/held_mesh.gd — reference implementation: already produces a per-face-UV 1×1×1 box (Data.block_rect top/side/bottom + Data.atlas_tex + block_tint vertex colors). Mirror this approach for the drop.
  • godot/world/world.gd spawn_drop(...) — creates the drop; keep its size/area/life behavior unchanged.

Derive the texture id from the drop's block id via Data.block(id) (same mapping the held block uses). Check the frozen web spec for how it represents a dropped/pickup item (size/proportions) and match it where the web differs from a plain cube.

Scope

  • Change ONLY the drop's mesh/material (solid → textured). Keep box size (0.3), Area3D, attract/pickup radii, and 120 s life unchanged.
  • Do NOT change block data, terrain, fluids, or held/viewmodel code.

Verification gates (hard)

G1 Headless load: ~/tools/godot/godot --headless --path godot --quit → zero script errors.
G2 Full logic battery 0 script errors, no regression: AWECRAFT_LOGIC=player|interact|light|fluids|buckets each exits 0 with a sane RESULT {...} (fluids/sea must match the known-stable numbers).
G3 Render proof: an xvfb-run gl_compatibility screenshot (R=1–2) showing a broken block's drop carrying the block's texture (not a solid color). Save PNG into tasks/AC-0083/.
G4 Web rebuild so the user can retest in the browser (coordinator runs ./build_web.sh + ./build_windows.sh after the subagent).

Deliverables

  • Code change in godot/entities/drop.gd (textured drop).
  • Screenshot(s) in tasks/AC-0083/ + a self-contained tasks/AC-0083/AC-0083-results.html (what changed, gates, embedded screenshot).
