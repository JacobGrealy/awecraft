**Deviations (all mechanical, none a design change):**

1. **`gate_run.py` g0 arm carries `--quit`.** The plan's per-arm shape is the generic arm command; the canonical G0 recipe (`godot/HARNESS.md` §4) is `timeout 300 $S --headless --path godot --quit` — a bare load has no arm to exit the process, so without `--quit` the g0 arm would ride out the timeout (rc 124) and could never show the plan's expected `rc=0`. `--quit` is added for the bare g0 arm only; every `AWECRAFT_LOGIC` arm keeps the plan's exact shape (the arms own their exit — the `gates_run.sh` precedent runs them bare).

2. **`builder_stats.py` default session root = this workspace's dir under `~/.dsh/sessions/`** (matched by the mangled repo path), not the plan's literal all-workspace glob. The plan's own acceptance (R² ≥ 0.9, ~15 tok/s on the current logs) reproduces only on the AweCraft builder population: all-workspace depth>0 fits R²=0.837 (other workspaces dilute it); the AweCraft population fits R²=0.924, ~15.5 tok/s (see the law line in fixtures-r2.log). `--sessions GLOB` targets any other population; the per-session schema, fit and law line are exactly as planned.

3. **`context_pack.py` harness mode rows are field-capped at 500 chars** with a pointer back to `tasks/harness_data.yaml`. The plan's fixture requires the pack to hold its 12k cap AND contain anchor excerpts; without a cap, the six AC-0433 §4 mode rows (~27 KB, one 11.4 KB `notes` field) eat the budget and the cap logic drops the anchors. Rows stay lookups (the yaml remains the machine source — link, don't restate); the cap is the one degree of freedom the plan leaves open.

4. **`context_pack.py` resolves inline `file:line` anchors** in the plan body, in addition to the §2 file-table anchors. The AC-0433 fixture's plan is prose (no file table) and carries its anchors inline (`world.gd:3889`, …) — the fixture's "contains an anchor excerpt with file:line" clause requires inline resolution. Table-anchor behaviour is as planned (symbol → literal search, `grep -n "X"` → run, `NEW` → skipped).
