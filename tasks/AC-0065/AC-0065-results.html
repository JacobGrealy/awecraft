Changes

  • godot/ui/inventory.gd: class FoodBar (red gradient bar, frac) removed entirely → class FoodRow: 9×9 meat bitmask + 9×9 bone bitmask → 3 NEAREST ImageTextures (full amber meat + beige bone / half = left-color right-dark / empty = dark silhouette), hunger var, same _draw loop as HeartRow (v = hunger − i·2). Construction (~:396) + positioning (~:860) reuse HeartRow.CELL/GAP so both rows share cell size, pitch and centering; row kept in its slot (above hearts, above hotbar).
  • godot/scenes/main.gd: AWECRAFT_HUNGER added to HARNESS_ENVS + sets player.hunger (clamped 0–20) pre-snapshot, analogous to the AC-0064 AWECRAFT_HP hook (kept for future shots).

Scope / deviations

  • Hearts (AC-0064), hotbar, eating/food logic, menu, and the AC-0063 setting all untouched — only the hunger HUD render path changed. hunger_enabled=false still pins p.hunger=20 in player.gd, so the row renders all-full exactly as before (same input as hearts).
  • Empty-silhouette gray (96,80,80 + 44,33,33 edge) deliberately matches the HeartRow empty color for row consistency; MC vanilla shows the half/empty as darker tinted meat — a documented style choice shared with the heart row.
  • No deviations from spec gates.
