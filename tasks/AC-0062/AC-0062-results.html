Scope / deviations

  • No mob save — mobs are AC-0037 (not landed); saves omit mobs (documented per spec).
  • Save = deltas only — edit map keyed by chunk (cx,cz)→{cell index→{b,f}}; continue regenerates the seed-deterministic base (GENHASH-gated) then re-applies deltas. No whole-world dump.
  • Fluid edits are part of the delta — the fluid sim records settled water-flow cells (the natural sea is stable ⇒ no churn; only actively-flowing cells are recorded). E.g. slot edits count 624–844 on a water-adjacent spawn = the real water shape, restored on continue.
  • New World slot assignment: picks first empty slot; New World overwrites nothing (empty→0,1,2 then falls back to slot 0 per spec “overwrite-prompt-free overwrite of slot 0”). Play button auto-continues the first occupied slot, else starts a fresh world in the first empty slot.
  • Auto-save on quit (Quit to Menu) writes the active slot; New World / Play also save on boot. Manual in-pause Save not added (nice-to-have, not required).
  • Desktop ERR_CANT_OPEN on render = audio device falling back to dummy (no audio on box); pre-existing, not a script error.
