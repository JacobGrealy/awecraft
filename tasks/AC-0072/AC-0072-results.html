PERF expectation (flag, not a defect)

The new default render radius 50 (≈101×101 ≈ 10,000 resident chunks) is HEAVY on the current progressive, not-yet-true-streaming engine: expect slow pop-in + large memory, especially in the browser. This is exactly what the AC-0071 chunk-streaming plan (awaiting user review; gates AC-0034) is designed to fix. AC-0072 only wires slider + clamp + default; it does NOT make radius 96 smooth. Verified: high radii can be set + applied + persisted without a hard crash; G3 headless clamp proof is the authoritative behavior evidence.
