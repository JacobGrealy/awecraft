What ships (math + save shape ONLY — no visuals, no gameplay change)

  • 1. New godot/core/sphere_math.gd — class_name SphereMath, pure static (no nodes, no per-frame state; a plain GDScript class file). API:
    • face_for_dir(d: Vector3) -> int — 12-way.
    • uv_to_world(face: int, u: float, v: float, R: float) -> Vector3 — face-local (u,v)∈[0,1] → point on the sphere (radius R).
    • world_to_face(pos: Vector3, R: float) -> Dictionary — inverse; returns {face, u, v}; deterministic with a documented tie-break at edge/corner ties.
    • neighbor_key(face: int, cx: int, cz: int, dir: Vector2i) -> Dictionary|null — the 12-edge table, 1↔1 with u↔v swap+flip; stepping off a face grid edge returns the neighboring face's chunk key; the 8 corners (3 faces meet) get an explicit deterministic owner rule.
    • Pre-warp invariant: adjacent faces must compute bitwise-identical edge points (this is the gapless guarantee from plan §3 — the probe asserts it).
    • Face convention: 12 faces = 6 axes × 2 sectors per plan §3. Coordinator ruling: face 0 = the home face = the current flat world (the face the player lives on). Define the deterministic index→(axis,sector) mapping once in the file header (a comment table) and nowhere else.
  • 2. godot/world/world.gd — chunk key becomes (face, cx, cz) (internal key representation is the builder's choice but must be stable + hashable; the face dimension participates everywhere the old (cx,cz) key was used). Recenter/band_buckets are per-face. get_block/set_block resolve through world_to_face as the single position→key resolver. Neighbor lookup (streaming adjacency) uses the table (1↔1 — no 1→4, no shell doubling). The player's face (home, face 0) streams exactly as today; other faces exist at data level only (generated + addressable + saved; meshing/lighting of non-home faces is OUT of P1a — that is AC-0144+).
  • 3. godot/world/generator.gd — 2D per-face noise for P1a (3D sphere noise = later upgrade, do not build it). Home face (face 0) must reproduce AC-0091 terrain byte-identically (spawn + smoke-battery continuity depend on it). Other faces: seeded per-face (document the salt derivation); no cross-face continuity required in P1a (terrain seams at face borders are acceptable + documented; surface geometry is gapless via pre-warp, terrain need not be).
  • 4. godot/autoload/save.gd — new shape: planets:[{id, R, orbit}] (P1a stores home only: id=0, R=4000 exactly; the R∈[2000,8000] per-seed clamp + other planets land with AC-0147, but the field + clamp must be in the parser now) + edits keyed planet_id:face:cx:cz:local. Old saves (no planets / old edit keys) → soft-fail: discard edits, fresh world, clear log line (AC-0091 precedent). Keep the height-stamp soft-fail from AC-0091.
  • 5. godot/scenes/main.gd — harness ONLY: new AWECRAFT_LOGIC=sphere probe arm (see gates). Nothing else moves. Remember the AC-0139 invocation lesson: any arm with script_errors_seen must be invoked with AWECRAFT_STDERR_FILE=$f … 2>$f or it false-fails.
