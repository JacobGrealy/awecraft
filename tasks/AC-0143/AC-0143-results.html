1. Face convention (sphere_math.gd header — defined once)

12 faces = 6 axes × 2 sectors; face index = axis×2 + sector. Axes: 0=+Y, 1=−Y, 2=+X, 3=−X, 4=+Z, 5=−Z. Each face (u,v) ∈ [0,1]² maps AFFINELY to a rectangle on the unit cube; uv_to_world = normalize(C)·R.

faceC(u,v)note
0(u, 1, 2v−1)home pair A — +Y top face, x≥0 half → flat 1m grid, x=R·u ∈ [0,R]
1(u−1, 1, 2v−1)home pair B — +Y top face, x<0 half → flat 1m grid, x=R(u−1) ∈ [−R,0]
2(u, −1, 2v−1)−Y bottom, x≥0 half (2:1 cell ratio vs +Y at cube edges)
3(u−1, −1, 2v−1)−Y bottom, x<0 half
4(1, 2u−1, v)+X, z≥0 half
5(1, 2u−1, v−1)+X, z<0 half
6(−1, 2u−1, v)−X, z≥0 half
7(−1, 2u−1, v−1)−X, z<0 half
8(u, 2v−1, 1)+Z, x≥0 half
9(u−1, 2v−1, 1)+Z, x<0 half
10(u, 2v−1, −1)−Z, x≥0 half
11(u−1, 2v−1, −1)−Z, x<0 half

Gapless invariant: on every shared edge both faces evaluate the SAME arithmetic ⇒ bitwise-identical pre-normalize cube point (verified 884/884 edge samples, max_d 0.0). Tie-breaks: dominant axis = largest |component|, sign order +X,−X,+Y,−Y,+Z,−Z (corner (1,1,1)→+X). CELLS_PER_FACE = 1024; 2:1 cell ratio across cube edges, 1:1 midlines. The flat home world = the faces 0+1 pair (the +Y top face split on the x=0 midline; midline columns belong to face 0 at 1:1).

5. P1a boundary list (deliberately NOT in this task)

  • No render at all (headless-only; curved-mesh rendering = AC-0144+).
  • Player stays on the flat home pair (faces 0/1); curved-ground physics/play = AC-0144.
  • No cross-face block sharing: each face owns its edge columns (per-face storage); block reads across a face border resolve via the single resolver key_for_sphere_pos (the across-edge gate = resolver-determinism round-trip, 240/240). Cross-face block reads at flat positions = AC-0144.
  • Non-home faces (2–11): data level only — no meshing, no lighting, no fluid marking, collision disabled; sparse on-demand (FIFO cap 512), never a fully-resident 45k-chunk set.
  • 2D per-face noise only (3D sphere noise = later upgrade); face-border terrain seams acceptable.
  • Non-home edit persistence: the save key form addresses them (planet_id:face:cx:cz:local) but P1a never records them (player can't reach them); load drops/validates strictly. Player edits to non-home faces land with AC-0144+.
  • Only the home planet is stored (id=0, R=4000 exact, orbit=null); other planets = AC-0147. R∈[2000,8000] clamp lives in the parser NOW.
