2. Deviations

AC-0482 deviations (builder record)

1. TEMPORARY MEASUREMENT ARM (harness.gd, removed at closeout). The plan's file table names no instrument, but §3.1 (measure ≥2 non-home faces before any edit) needs one that can reach non-home faces. A temporary `aimface` arm was added to harness.gd (dispatch branch + trailing functions), the AC-0479 `aimslide` precedent, measuring the AC-0479 quantities — box centre offset, 8-corner nearest-corner split radial/tangential, box-up vs block-up — at the home regression pair (spawn, D~153) plus face4_edge (3 cells inside the +x home edge), face4_mid (+x midline) and face2_pole (-Y pole). REMOVED before the final gate; `git diff --stat` confirmed harness.gd byte-identical to HEAD (only godot/player/player.gd modified). Logs: .scratch/AC-0482-gates/aimface-r1.log (BEFORE, gate a), aimface-r2.log (AFTER, gate b+c), plus the iteration trail (r1a first attempt, r2-affine-iteration intermediate fix).

2. PROBE PLACEMENT: fly-mode teleport + straight-down aim. The player is teleported (Debug.fly) 2.0 m above each column's top with pitch -1.55 (≈ straight down) instead of walking/standing: the measured quantities (the highlight transform vs the block's true warped frame, the aimed cell, the chart warp) are footing- independent, and a multi-km teleport onto unstreamed terrain is not safe in walk mode (the home-lane sync build does not guarantee the landing column; the face lane sync-builds on the DDA query, so aiming works either way). The home spawn site is still a natural standing spawn (the AC-0479 contract).

3. PROBE BUGS FOUND AND FIXED DURING THE RUN (trail, not results): (a) the first home_far attempt placed the player on the column-centre integer flat coord, putting the DDA origin on a cell boundary — the aim bled into the neighbour cell (aim_not_stable); fixed by placing at the cell centre (+0.5) and deriving the want cell from the eye's actual flat position. (b) the first AFTER run measured block corners with the legacy LSQ affine (face_chunk_transform), but the shipped default (AWECRAFT_WARP on) face mesh is the per-vertex chart warp with the chunk node identity (chunk.gd build_mesh_face) — the probe now reads the block corners through the chunk's own _warp_cell_point (the mesh construction itself, no second placement invented; the faceedit convention), legacy node transform when the flag is off.

4. FIX REFINEMENT BEYOND THE LITERAL SEAM (documented, measured): the seam fix (stop feeding cell-frame coords into the home-chart world_pos_of_flat) was first landed through the chunk's LSQ affine (face_chunk_transform — the legacy placement). Measurement showed that leaves 32-172 mm of corner error because the SHIPPED default face placement is the per-vertex warp, not the affine fit, and the orthonormalized frame of that warp is off by the chart's in-plane shear (~26 deg at chunk corners) vs the block's own frame. The landed fix therefore rides the EXACT per-vertex warp (the _warp_cell_point construction — the AC-0479 ground truth, face edition) with the RAW (sheared) Jacobian basis: a node basis may carry the shear (the indicator is unshaded; the sheared transform is exactly what the block mesh rides). The AC-0479 home branch is untouched (its ~D/R ~ 3 deg shear made orthonormalization harmless there; that contract is settled). Result: face corner residual 11-14 mm — the same class as the home face's own 10.4-15.0 mm (the 1.02 overhang + second-order warp curvature). Mid-iteration bug (found by the probe, fixed): dropping the orthonormalization exposed a missing /(2e) normalization in the central difference (the home twin hides it inside orthonormalized()) — the box briefly rendered at 20% scale (residual 397.9-398.1 mm = exactly 0.5 - 0.51*0.2).

5. LATENT RELATED BUG OBSERVED, NOT FIXED (out of scope): _sim_cell_center (player.gd:~3342) places a face>1 drop with the ANCHOR chunk's ccx/ccz — mining a cell in a NEIGHBOURING face chunk (the 6 m DDA can cross a 16-cell boundary) would compute the local slot with the wrong chunk origin and misplace the drop. Same family as the fixed defect (anchor/other-chunk frame used where the cell's own chunk frame is needed) but a different conversion; the faceedit arm's break/place flows exercise it only within the anchor chunk. Flag for a follow-up ticket.
