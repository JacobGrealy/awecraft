3. Satellite LOD not opaque (MOST SERIOUS) "When above clouds I can see all of the clouds on the other side of the planet through the satellite lod. The satellite lod should be opaque, we should not be able to see through it." Two mechanisms, one visible defect. (i) Body: satellite_body.gdshader's fragment-stage world reconstruction p_w = (INV_VIEW_MATRIX·vec4(VERTEX,1)).xyz (from AC-0384) does NOT yield the per-fragment position in Godot 4.7.1 — the fragment-stage VERTEX builtin degenerates to a constant, so d/op/haz/cosv all computed against ONE fixed point (the flat pale half + broken limb haze). (ii) Clouds: the cloud layer is ONE outer-shell mesh; the near-side fragment marched BOTH the near (sg1) AND far (sg2) annulus into one optical depth, so the far-side clouds accumulated into the near-side fragment's alpha and drew over the opaque body's disc (the far-side sheet). CLOUDS=0 removes it — the sheet IS the clouds. (i) Vertex-stage varyings v_world = (MODEL_MATRIX·vec4(VERTEX,1)).xyz + v_nrm = normalize(VERTEX) (the exact radial normal); the fragment uses them for d/op/haz/cosv/sun_l. (ii) Silhouette gate in cloud_layer.gdshader: b_hit = length(cross(w, rd)) (impact parameter); body_blocks = (rc > u_vol_rmax) && (b_hit < u_vol_r + 384) → skip the sg2 (far annulus) march when the ray passes through the body's opaque extent; around the limb (ray misses the body) sg2 still marches (far side legitimately visible). Both unswitched defect fixes. Body coverage (inner disc) 100.00%, LEAK (sky-like flat) 0.00%. Visual: nadir900-base.png = flat pale left half WITH the mottled far-side sheet showing through; nadir900-fixed-clouds.png = solid terrain across the WHOLE disc, symmetric radial limb haze, near-side cloud masses only, NO far-side sheet. 0 SCRIPT/SHADER ERROR both.

Cloud cover should vary across the planet "we need some kind of noise or something around the planet that determines where groups of clouds are, it should not be uniformly cloudy across the entire planet." No such field existed — the deck was one uniform sheet. New u_gate uniform + vgate(q) in cloud_layer.gdshader = u_gate < 0.5 ? 1.0 : smoothstep(0.40, 0.52, anv(q·3.0 + offset)) — a single low-frequency octave in the drift-rotated planetary space q, applied in BOTH vdens and vdens_coarse (the volume path, the default).
