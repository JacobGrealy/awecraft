AC-0030 — HTTPS server as self-healing daemon (serve_web.py)

Problem

The https server (python3 serve_web.py --ssl, port 8443, serving web/) dies on every opencode restart: background processes started with plain nohup & live in opencode's process group, which is killed on session end. Not subagents — subagents must never kill it. The server must survive arbitrary opencode restarts and be the single canonical launcher.

Requirements

  • serve_web.py stays a single stdlib-only file at repo root (AweCraft/serve_web.py).
  • New flag --daemon: fully detach — double os.fork() + os.setsid(), stdio from /dev/null to the log file. Parent prints the daemon pid and exits.
  • Pidfile .scratch/serve_web.pid (create .scratch/ if missing). Write it in the daemon after re-parent.
  • Port guard (all modes): if the target port is already bound by a live serve_web.py process → print already running (pid X, port Y) and exit 0. New flag --replace: kill that pid first (only that pid), then start.
  • Log: .scratch/awecraft-web-https.log (https) / .scratch/awecraft-web-http.log (plain) — append, with a start marker line.
  • Keep existing behavior unchanged: serves web/, gzip for known types, --ssl → 0.0.0.0:8443 with web/ssl/ cert; no --ssl → 0.0.0.0:8140.

Canonical command (after this task)

python3 serve_web.py --ssl --daemon

Verify (hard gates, zero errors)

  1. Daemon starts: python3 serve_web.py --ssl --daemon --replace → prints pid; curl -sk https://127.0.0.1:8443/ → 200; curl -sk https://127.0.0.1:8443/index.js → 200.
  2. Detached: ps -o pid,sid,pgid,cmd -p <pid> → SID equals PID's own (own session, NOT the calling shell's session); cat .scratch/serve_web.pid matches.
  3. Guard: run python3 serve_web.py --ssl again → "already running" + exit 0, only ONE listener on 8443.
  4. Clean stop: kill $(cat .scratch/serve_web.pid) → port freed, pidfile stale-detection works (next --daemon starts cleanly or --replace handles it).
  5. Restart daemon as the final state (server MUST be running when the task ends, via --ssl --daemon).

Constraints

  • NO systemd/cron. Subagents may kill ONLY the identified serve_web pid.
  • Do not touch godot/ or web/.
  • Scratch files → .scratch/.

Deliverables

  • Updated serve_web.py.
  • Running daemon on 8443 (https).
  • tasks/AC-0030/AC-0030-results.html — summary with the ps/curl evidence as <pre> blocks (no visual screenshots needed; state that).
