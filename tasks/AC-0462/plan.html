3. The probe

Pick sample face chunks on a mirror face (5) and a non-mirror face (11) at R = 4000: the boundary chunks the faceedit arm lands on (63:63) plus a spread of others (e.g. ccx/ccz in {0, 1, 31, 63}).

  • Ground truth definition — state it in the RESULT. For a cell (iu, iv), the chunk transform B = face_chunk_transform(face, ccx, ccz, R) maps the cell's own local square, so the cell's world centre is B * Vector3(local_x + 0.5, 0, local_z + 0.5) where local_x = face_local_x(face, iu, ccx) and local_z = iv & 15. Sample a point inside that cell (e.g. local centre plus a small in-cell offset) and use the cell it came from as the truth.
  • Candidate conversions — evaluate each on the same world point and report the cell it yields, so the probe can say right/wrong and by how many cells:
    1. as shipped by AC-0462: o = world - anchor.origin, then (o·bx/sc.x, o·bn, o·bz/sc.y) with bx = B.basis.x/sc.x (the anchor's pre-divided basis).
    2. no second division: (o·bx, o·bn, o·bz).
    3. normalised-basis division: (o·B.basis.x / |B.basis.x|², o·bn, o·B.basis.z / |B.basis.z|²).
    4. nominal-scale division on the RAW basis: (o·B.basis.x / sc.x, o·bn, o·B.basis.z / sc.y).
    Add ccx*16/ccz*16 and the mirror form from the AC-0462 fix before comparing to the true absolute column.
  • Report per candidate: worst cell error (in cells), mean, and the fraction of samples that land in the TRUE cell. The correct formula is the one that lands in the true cell for every sample; report all four so the choice is visible, not asserted.
  • Also report, per sample chunk, the three length scales that matter: |B.basis.x|, sc.x, and the distance between adjacent cell centres along u — so the numbers that disagreed are on the record.

RESULT keys (JSON): ok, R, samples, candidates {name: {worst_cells, mean_cells, exact_frac}}, scales {chunk: {basis_x_len, sc_x, spacing_u}}, fails.
