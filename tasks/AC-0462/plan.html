AC-0462c — convert face points with the inverse matrix, not per-axis dots

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Round 20 measured the answer: no per-axis projection is exact on a face chunk because the LSQ basis is non-orthogonal at corner chunks (cos ≈ 0.49), and the conversion needs the full 3×3 inverse. This applies it.

3.2 _flat_ray face branch: replace the per-axis projection with the inverse transform, then keep the ABSOLUTE-column + mirror conversion exactly as it is today (that part is proven):

var inv: Transform3D = _anchor["inv"]
var lo: Vector3 = inv * camera.global_position      # cells in x/z, metres in y
var dl: Vector3 = inv.basis * aim_dir()             # direction, same units
# then, as today:
mirror = SphereMath.face_mirror_x(face)
abs_x  = ccx*16 + (16.0 - lo.x if mirror else lo.x)
abs_z  = ccz*16 + lo.z
d_x    = -dl.x if mirror else dl.x
return {"o": Vector3(abs_x, lo.y, abs_z), "d": Vector3(d_x, dl.y, dl.z).normalized(),
        "reach": REACH / dl.length()}

Keep the non-face branch and the home path byte-identical. If inv is absent (an anchor built before this change), fall back to the current per-axis code rather than crashing — one guard line.
