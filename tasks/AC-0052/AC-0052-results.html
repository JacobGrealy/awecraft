Documented simplification (vs MC)

MC stores the 3x3 grid per crafting table; AweCraft uses one shared table_grid on the player (player.gd:50-52). Opening a different table reuses the same grid; closing returns its contents to the inventory or drops them. Behavior matches the wiki's close semantics ("if space allows"), state persistence between tables does not — accepted per spec.
