What the page documents

A dark "strata atlas" technical document (10 sections, TOC, inline-SVG figures) covering the full generation pipeline of the frozen web spec (index.html, build 20260816-r12):

  • 02 Noise primitives & seeding — hash2i/hash3i (32-bit imul mixer), quintic fade, value noise, fbm (amp ×0.5 / freq ×2 / +101 per octave, normalized); seed string hashing ("awecraft" → −1520868207); a complete noise-layer registry table (15 fields with scale, octaves, seed key, range, usage).

Method

Because subagents were unavailable this session, the coordinator researched directly. Ore/cave frequencies: 120,000 samples each with the same real code. Scratch: .scratch/AC-0086/ (calc.py, build_svgs.py, splice.py, crosscheck.py, JSON/SVG/PNG).
