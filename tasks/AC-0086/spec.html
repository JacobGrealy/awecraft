What the page must document

Goal: a technically literate reader understands, end-to-end, how one world coordinate (x,z) becomes a column of blocks. Focus (per the user) on the layers of noise — but the full pipeline is needed to make sense of them.

  1. Overview / pipeline diagram — the stages from seed → noise fields → biome choice → surface blocks → vegetation → (caves/ores if present). A visual (inline SVG or styled HTML) is strongly encouraged.
  2. Noise primitives & seeding — which noise family (value/perlin/simplex/ fBm/hash), the RNG or hash functions used, how the world seed enters, any lattice/grid resolution, and any coordinate scaling (e.g. noise sampled at x/SCALE).
  3. Each noise layer, one by one — for every field that influences generation (e.g. continental/height, hill/mountain, moisture/humidity, temperature, cave, ore, tree scatter…): its purpose, exact parameters from the code (frequency/wavelength, octaves, amplitude, persistence, gain, offset/shift, any remapping/curves), and its range. Use the real constant values and the real function names with line references.
  4. Biome determination — the exact decision logic (thresholds/branches) that maps noise values → biome. A table: biome name → conditions (ranges) → surface block(s) → underground → vegetation.
  5. Sea level & water — how ocean/water columns are decided, water height, sand/shore handling.
  6. Trees & vegetation (the star of the show) — per-biome species, how placement is decided (per-column hash? probability? minimum spacing?), trunk height, canopy shape code, leaves, plus flowers/grass/other scatter. Quote the actual selection logic.
  7. Caves & ores — if present in the web spec: how they're generated and which layers/thresholds control them.
  8. Worked example — walk through a couple of concrete (x,z) points (or a small seeded table) showing the noise values → biome → column. Helps readers verify understanding.

Include short verbatim code snippets (with file + line numbers) for the key functions: the noise primitive(s), the biome selector, the tree placer. Snippets should be short and trimmed — the page is an explanation, not a code dump.
