Implement: two-stage hysteresis

  1. States — add to the chunk node: candidate := false, cand_since := 0 (count of recenter events the chunk has been at Chebyshev ≥ r+2). (State fields in chunk.gd only.)
  2. In recenter() (replace/augment the to_free logic), after last_pcx/last_pcz update, for every live chunk compute cheby = maxi(absi(cx-pcx), absi(cz-pcz)):
    • cheby ≤ r: if candidate → clear it (candidate=false; cand_since=0) — the player came back; _build_queue_for_center already re-queues it for rebuild (data survived, edits re-apply on mesh). Mesh/collision come back via the normal drain — this is the re-entry path.
    • cheby == r+1: if not already candidate → become candidate NOW: kill the expensive parts (below), keep node+data+fl+edits; cand_since = 0. If already candidate: stay, cand_since = 0 (jitter guard — a hop back to r+1 never progresses toward free).
    • cheby ≥ r+2: if candidate → cand_since += 1; if cand_since ≥ 2 → FREE (the existing to_free path: chunks.erase, queued_keys.erase, light_pending_set/light_pending.erase, + NEW: fluid_dirty.erase(key), tex_refresh.remove(key), queue_free). If NOT yet candidate (it can't happen — r+2 is only reached via r+1 — but guard anyway): treat as candidate first, then count.

What "kill the expensive parts" means at candidacy: find the minimal, safe way in chunk.gd — KEEP the nodes (the rebuild paths in build_mesh/build_collision assume the MeshInstance3D/StaticBody3D children exist), drop what's expensive: each MeshInstance3D → .mesh = null (drops the ArrayMesh → GC) and/or .visible = false; the StaticBody3D → disable it (set the CollisionShape3D's shape = null or body.disabled = true — pick what the rebuild path tolerates and is cleanest) so a candidate has no collision at all.
