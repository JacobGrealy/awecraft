AC-0425 — audit remaining flat-world assumptions

Verdict. No new confirmed flat-world defects beyond what is already known. The one candidate the static sweep rated STRONG (C4 — flat-frame cull boxes in the manual frustum lane) is a real code shape and is fixed in godot/world/world.gd, but its live effect is measured below the cull margin in every state the render harness can produce (flat↔placed box offset ≤ 4.5 m vs the 32 m margin; pre-fix manual-lane frame is pixel-identical to the engine-cull frame) and its only over-margin state (a live player recentered 3+ km from spawn, face chunks resident, dev-lane manual cull) is not renderable by any snapshot-capable arm on this box. Per the ticket's method a candidate you cannot show in a frame is not a confirmed defect, so C4 is listed in the unconfirmed table below with its measured bound, and the fix is kept as a bounded, genhash-neutral removal of a flat assumption in a dev lane. All four AC-0423 residuals were re-measured with frames (§4). The f1 "black blob" is a lighting-floor look property (a grassland tree rendered as a black silhouette), confirmed by frame, fingerprint and A/B — it is not a flat-world defect; it deserves its own look ticket (recommended, not filed — TASKS.yaml is fenced for this run).

Render caveat: frames are llvmpipe Vulkan (proxy) — geometry/layout evidence only, per HARNESS.md §2. One godot at a time; every render run SCRIPT ERROR 0 / SHADER ERROR 0 and the boot line Vulkan … - Forward+ - … llvmpipe (LLVM 20.1.8, 256 bits).

2. C4 — the one real candidate: measured, fixed, not frame-confirmable

Shape. The manual frustum-cull lane (_frustum_cull_pass + the dead _gen_skip_flag tail) tested each column against a flat-frame box ((cx*16+8, H/2, cz*16+8), identity basis, flat span) against the world-space camera frustum. For home columns the box only coincides with the placed content near the patch pole (measured ≤ 4.5 m out across the whole 81-chunk resident set, worst at chunk "1,5"); for a face chunk the flat formula maps the face-chunk index through the home grid, so a face chunk adjacent to the 3141 m patch edge sits ~3.1 km from its flat box — far over the 32 m margin. The manual lane is a dev/AB lane (AWECRAFT_FRUSTUM=manual); the product default is engine cull (real node AABBs), which the fix does not touch.

Fix (kept). Placed-box slab test in world.gd: column center T·(8, H/2, 8), exact transformed-box support 8|n·B.x| + (H/2)|n·B.y| + 8|n·B.z| (exact for the rigid column transform and the LSQ face fit alike), per-slab 8(|n·B.x| + |n·B.y| + |n·B.z|); the dead tail uses SphereMath.column_transform. No switch (cull/data correctness, not a look change). Genhash 25/25 byte-identical (the cull lane touches no data); boundary r4 in-band (§6); frame-neutral in every renderable state (§ below).
