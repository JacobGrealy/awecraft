AC-0469 stage D — the far tier still thinks a face is 64 chunks wide

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. The far tier is what draws everything past the near field, and at 1 m cells the near field reaches only ~200 m — so this is not cosmetic. Measured: it covers about a sixth of each chart face.

1. The defect (measured by the coordinator, round 47)

godot/world/satellite_body.gd:131 — const FACE_GRID := 64 # faces 2-11: face chunks per axis. A chart face is 6,283 m across and a chunk is 16 cells × 1.000 m = 16 m, so a face is 393 chunks per axis (CHUNKS_PER_FACE, already a constant since AC-0469 stage A). At the OLD grid 1,024 cells / 16 = 64 chunks, so 64 was the whole face; at the new grid it is 64/393 ≈ 16% of it. The bake worker indexes far records as f * face_grid + ccx over a face_grid × face_grid square (satellite_bake_worker.gd:236-248, 328, 359), so chunk indices above 63 have no far record at all.

HOME_N := 394 is correct and must not move: the home grid is unchanged at 1 m (6,283 cells / 16 = 392.9 → 393-394).

3. Edit shape

  • 3.1 One source of truth. FACE_GRID must come from the grid (SphereMath.CHUNKS_PER_FACE or the equivalent), never a literal. If the bake worker's state dict needs it, pass it through the same field.
  • 3.2 Budget the rebuild. 393² = 154,449 chunks per face × 8 faces vs 64² = 4,096 × 8 — a 37.7× increase in far records. Measure the bake time and the memory before declaring this shippable; if a full bake is impractical, say so with numbers and propose the LOD/texture-resolution trade rather than silently shipping a partial cover.
  • 3.3 Texture resolution is a separate decision. NPIX = 1024 against a 394-chunk home grid is ~2.6 texels/chunk; the same 1,024 against 393 chart chunks is ~2.6 as well, so leaving NPIX alone is coherent — but STATE that reasoning, and report what the far field looks like at the new texel density.
  • 3.4 Nothing else moves. No changes to payload records, near-field streaming, or the shader unless a grid constant is genuinely baked into it.

5. Acceptance

6. Risks

The 37.7× record increase may make a full bake impractical; the honest response is to measure it and report the trade (fewer texels, coarser far LOD), not to ship a quarter-covered face and call it done. If a partial cover is unavoidable this stage, say exactly which regions are missing.
