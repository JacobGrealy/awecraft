1. Mining time formula (replaces player.gd progress = dt*mult/max(0.15,hard))

Compute break time T for the targeted block id + held item:

  • speed = held item's mining multiplier (.speed, tiers 2/4/6/8 — fix diamond 7→8) iff held tool type == block's best tool (Data.block_tool(id)), else 1.
  • T = 1.5 × hard / speed.
  • Wrong-tool penalty: for pick-required blocks (stone 3, coal ore 14, iron ore 15, diamond ore 16, obsidian 25): if held tool type ≠ pick (including empty hand) → T = 1.5 × hard × 5 (5× bare-hand).
  • Instant break: if computed T < 0.15 s → breaks on the next progress tick with no accumulated timer (no progress bar in UI).
  • Progress accumulates dt / T while mining; release/reset cancels (existing start_mine/release_mine semantics).

4. Attack cooldown + damage ramp (G7)

  • Player tracks last_attack_time. One attack per LMB press (current behavior; hold-loop stays animation-only = MC desktop behavior). Cooldown period = 1/aspeed.
  • Charge p = clamp(elapsed / period, 0, 1). Multiplier = 1.0 if p ≥ 0.75 else 0.5 + 0.5 × p / 0.75 (50% at p=0 → 100% at p=0.75). Damage = dmg × multiplier (float).
  • Expose the pure function (e.g. attack_damage(item, elapsed)) so the headless harness can assert it without real mobs.
