3. The executable port spec (the finishing run's checklist)

The substitution is centralized: every field build goes through five builder functions in gen.cpp (build_field / build_field_vn / build_field_c / build_field_vn_c / build_field_eval_c, lines 645–738). Applying the (d, δ) substitution there moves all 16 lattice fields at once — it is not scattered across 16 call sites. The only scattered sites are the per-cell hashes (§3.6), the dense sources (§3.4), and the aquifer cell grid (§3.5). The carvers have no field (§3.7).

3.1 The (d, δ) precompute — one table per chunk, shared by all 16 fields

For a chunk with face-local flat corner (bx, bz) = (cx·16, cz·16), precompute per C48 lattice point (ix, iy, iz) (the 2,401-pt grid, GFN_C) at flat (px, py, pz) = (bx+ix·4, iy·ystep_cave, bz+iz·4):

// home (face 0): the column's placed facet frame (sphere_math.gd column_transform, :332)
P_world = column_transform(cx, cz, R) * (px - cx*16, py, pz - cz*16)      // world frame
P_planet = P_world + (0, R, 0)                                            // planet frame
d  = normalize(P_planet);  delta = |P_planet| - R
// face N (2..11): face_chunk_transform(face, ccx, ccz, R) (:508) in place of column_transform
dx[N] = d.x;  dz[N] = d.z;  delta[N] = delta     // 2,401 × (dx, dz, delta), one vector per axis
  • The coarse 441-pt points sit on the C48 rows (coarse y rows = C48 rows × 6, since 48-block = 6×8-block): coarse (ix, iy, iz) → C48 (ix, iy·6, iz). So the 2,401-point table covers all 16 fields (10 C48 + 6 coarse). Piece 1's "+1.5% / 29.7 ns per point" is exactly this table (2 chart evals + a normalise per point).
  • δ ≈ local y: over a 16-m facet the radial offset differs from the facet-local height by ≤ the sagitta d²/2R ≈ 0.02 m (piece 1 §1.1) — far below the 4/8-block lattice quantisation. The substitution's y → δ is therefore y → (local y) to lattice precision; store the exact |P|−R for the dense H twin if bit-parity with the prototype is wanted, but the lattice may use local y.
  • Validate the C++ transform against the GD one (the genprobe-lockstep pattern): a scratch probe that samples home_point/column_transform/face_chunk_transform on a grid and compares to the C++ (dx, dz, delta) must agree to <1e-6 before the flip-on. This is the guard against a silently-wrong re-implementation.
  • Cost fallback: if re-implementing the Transform3D in C++ proves fiddly, compute the table in GD (generator.gd, where SphereMath is available) and pass a PackedFloat64Array (2,401×3) into generate_flat. Correct, but a few× the C++ precompute cost — the C++ form is preferred to hold the +1.5% budget.

3.5 The aquifer cell grid re-tile (the biggest structural move — piece 1 §1.3.4)

The Voronoi cell grid is currently keyed on flat-frame cell indices (16×12×16, centre = corner + (5,5,1) + jitter hash3i +316/317/318 at :1580-1582). A per-face lattice would re-introduce exactly the seam this ticket removes, so it re-tiles per face with GLOBAL hash keys:

  1. Cell keys go global. A cell is keyed by the global sphere integers at its centre: (⌊R·dx⌋, ⌊δ⌋, ⌊R·dz⌋) — identical for the same physical cell read from either face (d is identical at the boundary). The jitter hashes hash3i(ix, iy, iz, seed+316/317/318) (:1580-1582) re-key on those global integers.
  2. Cell-centre noise inputs take the substitution. aquifer_floodedness vn3(x, y·0.67, z) → vn3(R·dx, δ·0.67, R·dz) (same for spread/+312, barrier/+313, lava/+314); erosion is 2-D: vn3(x·0.25, 0, z·0.25) → vn3((R·0.25)·dx, 0, (R·0.25)·dz) (call sites :1487-1501).
  3. The 13-sample dense-H window re-keys from the 7×5 flat-chunk window to a 7×5 global-key window (SphereMath.neighbor_key, sphere_math.gd :230), so an edge cell's H window legitimately includes the neighbour face's columns (sampled :1695).
  4. The quantisation regions re-key on the same global cell coordinates (partial level 40·⌊cy/40⌋+20+spread, the 64×40×64 lava region, the 16×40×16 spread region).
  5. The per-block 12-candidate / 4-nearest / 25-squared-distance barrier search is untouched math (local frame, integer d²) — except an edge cell's candidate window now crosses the neighbour face's cell grid; the chart's gapless edge arithmetic supplies those centres. Cell status stays a single function of (d, δ, seed) → adjacent faces share edge-cell status.

Preserve the AC-0291 census (lakes, rims, waterfalls, land open water 0) and the AC-0342 land-dry rule + the oceansurface arm's dry_zero_water 0 — re-measure after the flip-on (the water contracts, §7).
