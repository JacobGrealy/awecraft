AC-0473 M1 deviations (measurement only — no code change)

1. GAP — the voxelcost arm (the instrument that produced the old ~13.4 ms gen /
   ~19.2 ms mesh per-chunk figures) is STALE on the current tree: it references
   `world._face_order`, which no longer exists in godot/world/world.gd
   (SCRIPT ERROR at harness.gd:39071, `.scratch/AC-0473-gates/voxelcost-r2.log`).
   Per plan §3 (harness.gd READ ONLY) the arm was not fixed and the gap is
   reported. Consequence: per-chunk gen_data_ms and mesh_build_ms are NOT
   re-measured. Substitutes measured on the current tree (perf R24,
   `perf_r24-r2.log`): worker-side build cost per landed build unit
   build_worker p50/p95/max = 4/8/9 ms (145 units), and the generation fill
   wall-clock = 1401 chunks generated by t≈30 s (PERFPROG series) with
   THREADGEN cap=2.

2. GAP — the perf arm's own `gen_ms` counter reports 0 on the R24 path
   (the counter exists at world.gd:7262 but does not accumulate on this
   dispatch path), so per-chunk generation ms is not obtainable from any
   currently-working arm. Reported as a gap, not estimated.

3. GAP — the cause of the post-burst mesh stall is not instrumented at R24 by
   any existing arm: the starlight pending-queue depth is not reported by the
   perf arm, the settlewait arm exits `{"ok": false, "error": "world not
   settled"}` by design at R24 (its 7200-frame settle wait cannot pass), and
   voxelcost is broken (item 1). The MEASURED fact stands on its own: after
   the first 145 chunks (t≈10 s) the pipeline completes 0 chunks for 194 s,
   with 16,484 build-unit dispatch attempts vs 145 completions (perf
   RESULT). That the settled-light defer at the mesh dispatch
   (world.gd:9783 comment: "or defers before the entry exists") is the likely
   gate is a code reading, not a measurement — labelled as such.

4. GAP (labelled derivation) — no existing arm measures the fill at altitude.
   The residency/streaming policy is provably altitude-independent:
   in_stream_set/band_of take only (dx, dz) (world.gd:7027-7079), so the
   required set and the fill at the mid-flight vantage equal the standing
   numbers at the same ground point. Stated as a code fact, not a measurement.
