Desktop multiplier assumed: 2× (this box is an i5-9400F, 2019 mid-range 6-core; a plausible 2020s Windows desktop ≈ 2× single-thread; sensitivity 1.5–3×). At 2×: the average rate gives ≈16.5 min; the steady 0.0 stays 0.0. Only the 10 s loading-window burst (14.2 → 28 c/s at 2×) would fill the set in ≈50 s — and the measurement shows that burst does not persist. Plain answer: the R24 set is NOT reachable in under a minute on a desktop. It is not an order-of-magnitude rate problem at all — the measured steady-state rate is 0 (a stall), and the only sustained positive rate (0.71 c/s) needs 33 min here / ≈16.5 min at 2×.
