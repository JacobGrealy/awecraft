What changed

The C++ world gen (gdext/src/gen.cpp) now derives everything from ONE coarse 3D density field, per cell:

d(x,y,z) = S_ramp((H(x,z) - y + 0.5)/R_BAND) + A(y) * (C(x,y,z) - 0.5)
solid where d > 0, air where d < 0
  • S_ramp — quintic spline surface density (the AweNoise._fade polynomial, C2, clamped ±1), R_BAND = 10: the zero crossing IS the surface.
  • C — trilinear of the coarse 4x8x4 3D CAVE field (fbm3(x/16, y/10, z/16, seed+301, 2), 7x9x7 lattice/field incl. margin, same AC-0188 field). The per-column carve and the 2D heightmap are GONE; caves are where d < 0, at ANY depth.
  • A(y) = 1.8·(1 + max(0, H−y−R)/DEEP_GROW), DEEP_GROW = 8 — caves widen with depth (the C field is tight, mean 0.506 / std 0.105, so fast growth widens the pockets into the deep — MC 1.18 deepslate cheese).
  • H(x,z) — surface height from the coarse 3D SURFACE field (3 new fields c/h/r, fbm3 at X/220·Y/64·Z/220, X/70+333, X/300+500, 3/4/3 octaves), read at the sea-level slice y=126 (trilinear). The slice's statistics differ from the old 2D fbm's, so the remap is affine-calibrated per field onto the OLD 2D distribution (constants in surface_h, measured over a 640×640 block area, seed 44) — the AC-0091 ocean/land/mountain balance (sea 126) is preserved. Spawn pad stays EXACT (d≤6 → 136, 6<d≤10 smoothstep).
  • Kept: ore fields + old bands/thresholds, obsidian hash, 2D biome texture, trees/flowers (now rooted at the field's effective surface), aquifer fill (water to SEA=126 where the effective surface is below sea), deep pockets at y<8 fill LAVA.

7 fields per chunk (cave, ore1–3, sc/sh/sr) = 3087 fbm3 lattice points — still one generate_flat C++ call, ~36 ms/25-chunk set (GENMS 36–39). Gen is still 100% C++ (nofallback: gen_cpp_works=88, gd fallback counters 0).
