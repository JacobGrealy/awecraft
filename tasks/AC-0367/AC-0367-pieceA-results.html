What was ported (Piece A deliverable)

Four dense sources — the 1.21.4 worldgen/density_function/overworld/caves/*.json expressions as-is — each a pure f(x, y, z, world_seed) in vanilla O(1) centered-noise units (2·(vn3−0.5), the AC-0347 convention):

  • spag2d (caves_spaghetti_2d.json) — the weird_scaled_sampler family: a type-2 rarity mapper over the centered modulator picks a scale d ∈ {0.5, 0.75, 1.0, 2.0, 3.0}; the main noise is sampled at pos/d, absolute, multiplied by d; thickness tm = −0.95 + (−0.35000000000000003·nt); elevation ev (y-scale 0.0 — a y-constant field) + the +64-shifted y-gradient g: 8.0 → −40.0 over y 0..384; r = clamp(±1, wv + 0.083·tm + cube(|8·ev + g| + tm)).
  • spag3d (caves_entrances.json — the spaghetti_3d family) — the type-1 rarity selector d1 ∈ {0.75, 1.0, 1.5, 2.0} over the centered spaghetti_3d_rarity; two main noises sampled at pos/d1 (each d1·|…|); thickness th = −0.0765 + (c2·nt) with c2 = −0.011499999999999996 (exact form, §6.1); r = clamp(−1..1, max(w1, w2) + th). This selector replaces AweCraft's f_gate in Piece B — the ticket's rationale for deleting the stand-in.
  • spagrough (caves_spaghetti_roughness_function.json) — (−0.05 + (−0.05·rm)) · |rs|, a small signed roughness term.
  • noodle (caves_noodle.json) — the all-depth cap: in-band 4 ≤ y < 385 (the +64-shifted vanilla −60 ≤ y < 321), base noise nv < 0 → 64.0 (the "no carve / far solid" sentinel, nv ≥ −10⁶ ∧ nv < 0), else ot + 1.5·max(|ra|, |rb|) with the 8/3-scaled ridge noises and ot = −0.07500000000000001 + (−0.025·nt); out-of-band → 64.0 (the outer min in vanilla's final_density caps it — informational for Piece B).

6 — Findings (deviations + engine traps, all resolved in-lane)

6.1 GDScript's float-literal parser is not correctly rounded (the spag3d 1-ulp hunt)

The first lockstep run: spag2d/spagrough/noodle 300/300, spag3d 292/300 (8× 1-ulp). Trace: a temporary step-by-step arm (tunndx) showed every spag3d intermediate agreeing — the divergence was in the constant, not the op order. A standalone C++ repro at the project's exact flags (-O2 -ffp-contract=off) matched CPython bit-for-bit, so C++ was correct; a literal audit (every constant in the four sources, its exact bits as parsed by the GDScript compiler via f64_exact) isolated the culprit: 0.011499999999999996 parses 4 ulp low in GDScript — for EVERY decimal string in that double's rounding basin, including the double's full 52-digit exact expansion (Godot's literal parser is not a correctly-rounded strtod for long mantissas; a second 17-digit literal, 0.07649999999999999, parses 1 ulp off too). All other AC-0367 literals parse identically in every lane. Fix: that one constant is spelled in all three lanes as the exact division −6629298651489368.0 / 576460752303423488.0 (= mantissa < 2⁵³ over 2⁵⁹ — both literals exact f64, the quotient representable, IEEE division exact), i.e. the correctly-rounded double of the 1.21.4 JSON text, with no decimal parsing in the hot path. This is a project-wide hazard: any new multi-digit float literal must be literal-audited (bits in every lane) before it enters a lockstep surface — candidate for godot/OPS.md at closeout.

6.2 The 1.21.4 cache nodes are value-identity (they vanish from the port)

The interpolated / cache_once / flat_cache / cache_2d wrappers in the noodle/spaghetti JSON are VALUE-IDENTITY in the 1.21.4 dense evaluation (decompiled: the l cache class's apply delegates straight to the inner function — no resampling). The port evaluates the inner expression directly; nothing is lost.

6.3 Constants are the vanilla JSON text as-is, except §6.1's one exact-form spelling

−0.0765, −0.95, −0.35000000000000003, 0.083, −0.025, 1.5, −0.07500000000000001, −0.05, −0.4, 2.6666666666666665 — all audited bit-identical across lanes. The 8/3 ridge scale is the literal 2.6666666666666665 (the JSON text), not a computed 8.0/3.0 (which is a different double).

6.4 Noodle is an ALL-DEPTH cap, unlike the deep-only spaghetti (informational for Piece B)

Vanilla's final_density applies the outer min with the noodle at every depth (its band is the whole world minus the bottom 4 levels), while the spaghetti families are deep-branch only. Piece A ports the noise only; the cap placement is Piece B's wiring.
