AC-0110 — occlusion-culling-caves-interior

Two stages: A render-only VisualServer occlusion (occluder boxes + camera culling setting); B software interior-face skip in the chunk mesher. Plus a headless measure arm and an in-cave render.

0. Findings that shaped the design (read the mesher first)

  • A greedy mesher already exists (AC-0106, as-delivered): opaque faces are emitted per-face into recs (_faces instance / _s_faces static), then the merged-atlas path (_emit_ro_merged/_s_emit_ro_merged) greedily unions coplanar same-shade faces into quads; fallback _emit_faces keeps one quad per face. So Stage B only has to be recs-compatible (it is — it filters recs at the source; both greedy and fallback paths see the same recs). No new mesher is built (that would be out of scope).
  • Face-level interior culling already exists. _s_faces skips a face iff nb == id or stab[nb] > 0 (out-of-range y reads 0). A solid voxel with 6 solid neighbours therefore already contributes 0 faces. Stage B is NOT a geometry change — it is the explicit voxel pre-pass: one 6-neighbour solid test that skips the whole per-voxel face loop for interior voxels (the large underground majority), keeping the emitted geometry byte-identical (MINFO must match .scratch/AC-0143-gates/minfo_new.txt exactly). Proof: the pre-pass fires only when all 6 neighbours have stab[nb] > 0 and y ∈ [1, h-2]; under exactly that condition the face loop would append zero recs, so nothing that was emitted is removed.
  • Cross-chunk reads are already handled: the mesher works on a padded snap (18×18×H, SNAP_W=18), margin ring filled from the 4 ortho neighbour chunks (_build_snap sync / _build_snap_data worker, nbs). The 6-neighbour test reads only ortho margin cells — always populated (worker dispatch guarantees nbs present; sync path treats missing as air, same as today's face loop). No new lookup surface.
  • Slab structure (AC-0108): chunks are 24 vertical 16×16×16 slabs (H=384). This drives the Stage A box placement: a fully-solid slab is a provably-opaque 16³ region.
  • Solid set: ids 1,2,3,4,6,8,9,17,20,21,11,12,14,15,16,23,25 (stab); fluids 5/24 and cross/cutout blocks are non-solid. No block is both solid and cross/cutout, so the pre-pass condition stab[id] > 0 touches only the opaque branch behaviour.

1. Stage B — interior pre-pass (godot/world/chunk.gd)

  • New static _s_is_interior(lx,y,lz,snap,stab,h): y∈[1,h-2] and all 6 neighbours stab[snap[…]] > 0 via the padded snap (±1 x, ±SNAP_W z, row±SNAP_ROW y).
  • In BOTH voxel loops (build_accs worker, build_mesh sync), after the oktab check, before the xtab/ktab/else branch: if stab[id] > 0 and _s_is_interior(...): continue. Cross/cutout/other paths are untouched.
  • Worker purity: uses only snap/stab (per-call copies) — thread-safe, no node access. No world-data, collision, or lighting change.
  • Perf: interior voxels (the underground bulk) pay one 6-read test instead of the 6-face loop; boundary voxels pay the test + loop. Net neutral-to-positive in the face phase; geometry unchanged by construction.

2. Stage A — occluder boxes + camera culling (render-only)

  • Box placement = per fully-solid slab. In both mesh loops a per-slab counter marks cells that are NOT solid blocks; a slab with zero non-solid cells (all 4096 solid) gets one OccluderInstance3D with a BoxOccluder3D of size 15³ (0.5 inset per side) centred on the slab. (Godot 4.7.1: the occluder property is typed Occluder3D; BoxShape3D is not an Occluder3D in this engine, so the dedicated BoxOccluder3D resource with its size property is used.) The inset is deliberate: the slab's own boundary faces (emitted against non-solid neighbours) then lie outside the occluder AABB, so Godot's AABB-containment cull test can never cull the slab's own mesh; the inset only makes edge-on culling marginally less aggressive. A fully-solid slab can contain no air, fluid, cross or cutout cell, so:
    • the camera can never be inside an occluder (no air in it) — "camera chunk never culled" holds by construction;
    • every sky-facing chunk has air in its top slab → never fully solid → never an occluder — "no chunk with visible sky" holds by construction;
    • water/leaves/torch slabs are non-solid → no occluder (nothing opaque to hide).
  • Lifecycle rides the slab mesh lifecycle: created in _assemble_slab (flag carried from the mesh loop; worker path adds it as the 7th slabs_out row element), freed at the top of build_mesh/apply_accs and in _enter_candidate_slabs (candidate slabs at r+1 kill mesh and occluder, else an unrendered slab would cull the world behind it).
  • project.godot [rendering]: occlusion_culling/camera/cull_3d=true + cull_2d=true (section-relative keys) + the master toggle occlusion_culling/use_occlusion_culling=true — camera culling is inert without it (default false; verified by ProjectSettings read-back in the occlude RESULT).
  • Headless = literal no-op: creation is gated by a cached DisplayServer.get_name() != "headless" check — under --headless zero OccluderInstance3D nodes are created, zero VisualServer work, no RESULT value touched.

3. Verification (headless harness + one xvfb render)

  • G0 clean; genhash 25/25 run1==run2 == .scratch/AC-0143-gates/genhash_new.txt (data layer untouched); SMOKE 5 exact per tasks/HARNESS.md §3; MINFO byte-identical to .scratch/AC-0143-gates/minfo_new.txt (mesh fingerprint — the Stage B identity proof, empirically).
  • New arm AWECRAFT_LOGIC=occlude (main.gd, r4, headless):
    • settle r4 (81 built in |cx|,|cz|≤4, bounded 2400 frames, report count) — the full radius, so the cave flood can never read an unbuilt chunk as air (a 64-chunk early break let the flood escape into the 17 still-queued chunks on the first run);
    • per-chunk interior mark: solid cell with 6 solid neighbours (in-chunk data, margin via world.get_block — the same cross-chunk query the mesher uses);
    • quad audit of every surface of every built r4 chunk: every 4 consecutive verts = 1 quad (all emitters write 4 verts per quad in index order; merged-atlas quads are the same, just >1 m wide). Constant-axis detection finds the face plane; the emitter cell is the non-zero side (per row cell for merged quads);
    • leaking_interior = quads whose emitter cell (any row cell) is an interior solid → must be 0 (the "indoors not leaking faces" numeric assert);
    • underground: column surface = highest solid y in the column; a quad counts when ALL its row cells have emitter y < column surface (merged quads straddling a surface edge are excluded — conservative, documented);
    • cave pocket: first enclosed air cell in chunk order — candidate = air, y∈[80,260] band first (full range fallback), ≥4 solid neighbours, roofed (a solid in the column above), and its 6-connected air flood (cap 20000, bounded to the r4 region) is fully below ground (open==false) → cave.aabb + cell count + seed. (Earlier picks at chunk (-4,-4) y=80 / (2,0) y=90 were skylit/coastal air masses, not enclosed caves.)
    • RESULT: total_verts / total_faces / underground_verts / underground_faces / interior_voxels / leaking_interior / full_solid_slabs / occluders (0 headless) / cave{…} / ok.
  • Node-graph assert (non-headless): same arm under xvfb-run (gl_compatibility): occluder node count == full_solid_slabs (built r4), sampled box size 15³, and cull_3d setting read-back true. This is what is verifiable here.
  • Enclosure test (both arms): the air flood reports open = any cell at/above its column's WorldGen.terrain_height (column-heights cached per flood). A roofed seed is not enough — the r4 region's biggest air masses are skylit/coastal systems, so "cave" means the flood is fully below ground.
  • In-cave render (gate 5 record): new AWECRAFT_CAM=cave preset in _snapshot_finish: over all r4 chunks flood every roofed seed (aabb-deduped), keep enclosed (open==false) regions with a clear eye-line (cell above seed is air), pick the largest → recenter → await build → player eye inside the seed cell → torch in every air axis-neighbour at distance 1 and 2 (12 candidate cells; the eye block at +y·1 is kept clear; a big cave needs light from all sides or the far walls stay pitch black) → aim at the thickest wall (solid neighbour with a solid cell 2 away; tie → first of x±,z±,y±) → settle 300 physics frames (the edit flush remeshes only EDIT_FLUSH_MAX_PER_FRAME=1 chunk/frame and each torch dirties a 3×3 neighbourhood, so a 40-frame settle snapshots a half-lit, partially-remeshed cave — the inverse "more torches → darker" symptom) → snapshot .scratch/AC-0110-gates/cave_interior.png (absolute path — save_png resolves relative paths against the godot/ project dir, so a repo-root-relative path silently fails). Fallback when no enclosed cave exists: largest open region, so the gate still records a PNG.
