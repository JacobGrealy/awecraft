1. Where P1 left it (read these, do not re-derive)

  • Every near material discards at d >= u_fog_far (AC-0401), and now through the predicate: if (d >= u_fog_far && !ac0451_covered(d)) { discard; }.
  • ac0451_covered() is a stub returning false in every near shader: return u_coverage > 0.5 && false; — so P1 is byte-identical to the pre-ticket build, which was its whole acceptance proof.
  • The switch exists and is pushed: AWECRAFT_COVERAGE=0|1 → u_coverage, change-gated, to the chunk material cache, the fluid animation materials and _lod_avg_material (world.gd:5444-5462). OFF is today's build.
  • The body's own coverage (core/satellite_body.gdshader:177-179): op = smoothstep(u_fog_far, u_render_edge, d), solid only at d >= u_render_edge, where u_render_edge = (render_radius+1)*16 (main.gd:1478), 400 m at radius 24 against fog_far 332 m.

2. The change

2.1 The predicate answers the truth: ac0451_covered(d) becomes u_coverage > 0.5 && d >= u_render_edge — "the body is already drawing here" — so the near field keeps drawing through the fog_far..render_edge annulus instead of leaving it to nobody. Beyond render_edge the body is solid and the near field discards exactly as today.

2.2 u_render_edge must be pushed, not hardcoded. Add the uniform to the same near materials and push it from the same place the fog value is pushed (_ac0401_push), from the same source main.gd:1478 uses, change-gated the same way. One source of truth for the number — if main.gd and world.gd cannot share it, say so rather than duplicating a literal.

2.3 Expected appearance, stated before the edit: in that annulus the near fragments are already beyond fog_depth_end (= fog_far), so they render fully fogged. The ring should become fog rather than a hole — not terrain. If you instead see terrain appear there, the fog window moved and that is a bug in your change, not a bonus.

2.4 Deterministic ownership (the ticket's requirement): where both surfaces coexist the finer one must win by GEOMETRY, not draw order — the body already pulls its displaced surface 2 m radially inward for exactly this reason. Overlapping is the intended state; verify no flicker.
