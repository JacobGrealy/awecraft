AC-0459 — flip the chunk-key format and bump the save version

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. AC-0465 already routed every chunk-dict key through world.chunk_key/chunk_key_face (41 inline builders → 0, 12 literals → 0, genhash identical). This ticket changes the format in those two wrappers and handles the readers.

1. Goal

One key shape, face:ccx:ccz, for the home pair (0:…) and chart faces alike; the world provably unchanged; a save carrying the old shape rejected cleanly.

2. The one-line change, and why the risk is elsewhere

The format itself is trivial now. The risk is in READERS: anything that parses a key back into coordinates, or that iterates chunks.keys() and splits them. AC-0465 fixed the PRODUCERS; nobody has yet audited the READERS for the colon form. That audit is this ticket's first deliverable.

4. Edit shape

  • 4.1 THE AUDIT FIRST (do this before changing anything). Grep for every place a chunk key is READ back: .split(":"), .split(","), chunks.keys(), edits.keys(), chunk_origin iteration — in world.gd, main.gd and harness.gd. For each hit record file:line and state whether the value it parses is a CHUNK key, a CELL key (gx,gy,gz) or an EDIT key (planet:face:ccx:ccz:local). That table is the deliverable; the builder that stopped AC-0459 previously found three of five listed parsers were cell keys, and this audit is how that mistake stops repeating.
  • 4.2 Flip the producer in _key only. chunk_key_face/_key_f already emit the canonical form.
  • 4.3 Fix only the chunk-key readers the audit identified, and for each state what it now expects. A reader that cannot parse a key must return an invalid result and be reported — never silently mean chunk 0.
  • 4.4 Bump the save version and update ARCHITECTURE.md §5/§6.
  • 4.5 Identical resolution: the same (cx,cz) must reach the same node before and after. This is a relabel, so genhash 25/25 and the light set are the evidence.

7. Risks

A reader missed by the audit fails quietly (a lookup returning null reads as "chunk not built"), so §5's simband check and §4.1's table are the guards. If the audit finds a reader whose intent you cannot determine, STOP and report it rather than choosing an interpretation.
