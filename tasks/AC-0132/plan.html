Verdict: the skip test is r.grid > grid_size — a "grid": 2 recipe is skipped ONLY when grid_size < 2, which never happens (callers pass gs ∈ {2, 3}). Therefore the torch entry with "grid": 2 is craftable in BOTH the 2×2 E grid (gs = 2, player.gd:1417) AND the 3×3 table (gs = 3). "grid": 3 recipes are table-only (skipped in the E grid). The data.gd:95 comment ("grid: 2 = craftable in the E-inventory 2x2 grid; grid: 3 = crafting-table 3x3 only") reads ambiguously, but the code at :367/:386 is unambiguous. This behavior is ALREADY gate-proven both directions by the existing AC-0052 arms in _craft_test: grid-2 planks works in E (main.gd:2458-2464, C_out == [8, 4]) and grid-3 iron sword is [0, 0] in E but [109, 1] in the table (main.gd:2465-2479, D_out_inv/D_out_table).

Placement semantics: match_shapeless is placement-INDEPENDENT (it counts items across the cell array — data.gd:358-365), so any arrangement of exactly 1 coal + 1 stick (vertical, horizontal, diagonal) yields 4 torches — the required vertical C-over-S placement works trivially. Extras break the match (exact-count, data.gd:370-378; web :296-297 — faithful). The 2×2 UI is row-major: cell (i % 2, i / 2) (inventory.gd:987-989) ⇒ left column = cells 0 (top) and 2 (bottom). The 3×3 UI is row-major: cell (i % 3, i / 3) (inventory.gd:980-982) ⇒ left column rows 0-1 = cells 0 (top) and 3 (middle). Chosen form: shapeless, grid 2 — no shaped 2-wide variant needed (a shaped entry would be table-only, grid 3, and would fail in the E grid).
