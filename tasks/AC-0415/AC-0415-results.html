The engine ramp, measured (the curve finding)

The A/B at 120 m showed a real (subtle) difference the "same factor as band A" premise did not predict. Resolution, three independent pieces of evidence:

// Godot 4.7 Forward+ — scene_forward_clustered.glsl fog_process() (fetched from the // godotengine/godot 4.7 tag), FOG_MODE_DEPTH branch: float fog_z = smoothstep(scene_data_block.data.fog_depth_begin, scene_data_block.data.fog_depth_end, length(vertex)); // length(view_position) = slant range float fog_quad_amount = pow(fog_z, scene_data_block.data.fog_depth_curve) * scene_data_block.data.fog_density; ... return vec4(fog_color, fog_amount); // mix(albedo, fog_color, fog_amount)
  • Metric: slant range (length(view_position)) — identical to the manual ramp's length(CAMERA_POSITION_WORLD - v_world_pos). Not view-space z.
  • Curve: smoothstep (t²(3-2t), fog_depth_curve = 1.0 default) — not the linear (d−100)/232 the project's comments assume (daynight.gd: "factor 0 at fog_depth_begin, 1 at fog_depth_end" describes the endpoints only).
  • Density: 1.0, auto-set. The Environment resource default is 0.01 (docs), but Environment::set_fog_mode() auto-sets fog_density = 1.0 for every mode except FOG_MODE_EXPONENTIAL (environment.cpp) — main.gd's env.fog_mode = FOG_MODE_DEPTH push therefore carries density 1.0. (The 4.7 enum is {EXPONENTIAL = 0, DEPTH = 1} — probe fog_mode=1 = DEPTH.)

Live probe (AFTER tree, f=1…642, identical state to the BEFORE probe run): mode=play fog_on=true env_begin=100.0 env_end=332.0 env_color=(0.6308, 0.8796, 0.9647) fog_mode=1 fog_density=1.0 fog_curve=1.0, material u_far=332.0 (the undeclared u_near/u_air reads return the stored no-op push values — the 4 dead main.gd pushes are inert; the u_fog_far push at main.gd:1477 stays live).

Consequence: smoothstep < linear for d < 216 (near annulus less hazy in AFTER, 77% of the differing pixels) and smoothstep > linear for d > 216 (far annulus more hazy, 23%, up to +7–9% haze weight approaching the wall). Equal at both endpoints — which is why the wall band is byte-stable at 300 m and stable within the mid-annulus bleed at 120 m. (The per-pixel k-ratio was checked as a discriminator and rejected: the before-vs-before-control pair shows the same k spread from run-to-run surface noise alone; the collinearity test still holds — 92.6% of differing pixels lie on the same air-colour line, proving same surface + same air + different factor — and the source + probe fix the curve.)
