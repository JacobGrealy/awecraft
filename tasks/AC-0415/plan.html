AC-0415 — plan: the far tier takes the engine fog; the duplicate goes

Goal

Delete the far tier's hand-rolled copy of the engine depth fog from godot/core/lod_avg.gdshader so the whole render ladder runs on the one environment fog. The fog_enabled setting (and AWECRAFT_NO_FOG) then govern the far tiers too — the user's "fog disabled" frame stops showing flat pale-blue plateaus where the annulus should show terrain. The AC-0401 partition discard (d >= u_fog_far) is NOT fog; it stays. The far tier's fog-ON look is VERIFIED and must not move (the wall band where the near tiers hand over to the satellite body stays matching: both sides take their colour from the single-source air value, and the engine fog factor is 1.0 at d == fog_depth_end — exactly where the manual ramp already reached u_air).

What the duplicate currently computes (godot/core/lod_avg.gdshader)

render_mode fog_disabled            // engine fog OFF for this material only
uniform vec3  u_air         // main.gd push = env.fog_light_color = Aero.fog_display
uniform float u_fog_near    // main.gd push = env.fog_depth_begin
uniform float u_fog_far     // main.gd push = env.fog_depth_end   (also the partition)
uniform vec3  u_render_edge // main.gd push — declared, NEVER read (dead, AC-0404 residue)
uniform vec3  u_center      // main.gd push — declared, NEVER read (dead, AC-0404 residue)
...
float d      = length(CAMERA_POSITION_WORLD - v_world_pos);
if (d >= u_fog_far) discard;                          // AC-0401 partition (KEEP)
float fog_f  = clamp((d - u_fog_near)/max(u_fog_far-u_fog_near, 1.0), 0.0, 1.0);
float haz    = fog_f;                                  // the AC-0399/AC-0400/AC-0404-patched copy
ALBEDO = mix(ALBEDO, u_air, haz);                      // the duplicate fog (DELETE)

fog_f is the engine's own depth-fog ramp reimplemented — the engine fog gives this material the same factor and the same colour (env.fog_light_color is u_air by construction, AC-0384 r8). The manual copy exists only to ignore the switch: with env.fog_enabled = false the engine stops and this keeps fading to u_air.

What replaces it

  • Remove render_mode fog_disabled — the environment fog applies to the material through the standard path, exactly like the four chunk_lit_*.gdshader kinds and the two fluid materials already run. One fog model for the whole ladder; the fog_enabled switch governs all of it.
  • Delete the manual haze: the u_air/u_fog_near uniforms, the fog_f/haz computation and the mix(ALBEDO, u_air, haz) line.
  • Delete the two dead uniforms (u_render_edge, u_center — declared and pushed, never read).
  • Keep u_fog_far + the d >= u_fog_far discard (the AC-0401 partition: the annulus ends where the body's existence ramp begins; the body's haz_d rim at the wall is the seam, single-source air colour — unchanged by this ticket).
  • Keep the static per-fragment hash breakup (the med/low flat-wall treatment) and the AC-0283 P3 lit floor — not fog.

main.gd is fence-locked (another session's uncommitted work): its _update_sky push block (main.gd:1474-1479) keeps running, but the u_air/u_fog_near/u_render_edge/u_center pushes become harmless no-ops on a material that no longer declares those uniforms (Godot 4 set_shader_parameter stores without name validation; G0's zero-SCRIPT-ERROR census is the live check). The u_fog_far push (line 1477) stays LIVE — the partition needs it. Per the ticket's fence note, the four dead pushes land in the coordinator's commit once the fence lifts; this run leaves main.gd byte-identical.
