Registry notes (verbatim, quoted):

1) User Story: As a player near water, I want bouncy bananas on special banana trees that spawn in dirt right where dirt meets the sand ring around water, so bananas are a beach-edge food source I can find by following shore.

2) Technical Details: Spawn banana trees only in dirt at the dirt<->sand transition surrounding water (generator.gd tree pass checks y~SEA=126: if base is B_DIRT/B_GRASS and within 2-3 blocks of B_SAND and water nearby, roll low banana-tree chance (density << forest TREE_D_FOREST 0.14, ~0.02-0.03) — not forest/jungle). Fruit B_BANANA placed hanging; when player within 10 blocks, chance to fall as RigidBody3D bouncing until rest, pickup via interact, eat restores health+stamina + gorilla SFX via AC-0039. Verify G0+SMOKE, trees only on shore dirt edge, not inland forest.

Goal

Task-specific requirements

  • Shore-only spawn (godot/world/generator.gd): a GDScript post-pass apply_banana_trees() / apply_banana_resl() — deliberately NOT inside WorldGen.generate() (the genhash arm hashes its output directly; the AC-0215 baseline must hold). Gates per column: base ∈ {B_GRASS, B_DIRT} at y ∈ [SEA+1, SEA+4] (127–130, the dirt↔sand transition band), biome_at ≠ "forest", a B_SAND cell within Chebyshev 3 in the shore band [SEA−8, SEA+4], a water column (topmost cell B_WATER) within Chebyshev 4, and a 0.025 roll (hash2i(seed+919) — ≪ forest 0.14). Trees use the exact C++ tree-pass shape (trunk B_LOG 4–6 tall, seed+66 roll; B_LEAVES canopy rad-2/rad-1) with 2 B_BANANA fruit cells replacing canopy leaves (the MC-apples pattern — the rad-2 canopy fills every air cell, so empty-cell-only writes can never land).
  • Block 28 / item 126 (godot/autoload/data.gd): B_BANANA = non-solid cross block (light-passing, pre-wired in lighting.gd + atlas), drop: 126; item 126 "Banana" food: 4 + sfx: "gorilla". The chunk mesher auto-derives the block-28 tables from Data.blocks (C++ AweMesh cross-quad) — no C++ change.
  • Fall + bounce (godot/world/world.gd, godot/entities/banana.gd): the pass runs on all five world-build landing sites (sync gen, _materialize_chunk_data, threadgen handoff, startup-gen apply, face gen — face chunks get trees visually, no fruit registration); a _banana_fruits registry ("x,y,z" → chunk) with disk-load scan + eviction cleanup; a 0.5 s roll: each registered fruit within 10 blocks of the player has a 6% chance to be plucked (re-verified via get_block == 28), clearing the cell and spawning a RigidBody3D (entities/banana.gd: PhysicsMaterial.bounce 0.45 — Godot 4.7 API linear_velocity/is_sleeping() — that bounces until rest, then the drop-magnet pickup <2.5 m → <1.1 m → inv_add(126) + Audio.play("pickup"); 120 s lifetime).
  • Eat + SFX hook (godot/player/player.gd): eat_selected plays the item's sfx field (banana → "gorilla", the AC-0039 lane; AC-0039 itself is still OPEN — hook only); restore is the existing food path (+4 hp, +4 stamina).
  • Art (godot/assets/blocks_atlas.png): a banana crescent (yellow, brown tips, transparent) painted into the 32×32 tile at offset (32,32) — the tile reserved by blocks_atlas.json for block 28.
