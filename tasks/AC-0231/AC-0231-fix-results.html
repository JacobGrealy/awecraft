AC-0231 — FIX — far-LOD low-res placeholder is now 16 tall (1 chunk height), not 384

status: PASS · engine: Godot 4.7.1 · files: godot/world/world.gd (the fix), godot/world/chunk.gd (comment), godot/scenes/main.gd (R16 arm probe) · GDScript-only (no C++ touched, no .so rebuild) · logs: .scratch/AC-0231-fix-gates/

The bug (user-reported)

SYMPTOM — "The LOD meshes extend what appears to be the entire height of the chunk column. The air chunks should not get lods, and every other chunk's lod mesh should still be the same size as the chunk not taller." User clarification: "chunks should be 16 tall" — i.e. the LOD mesh must be 16 blocks tall (1 chunk height / 1 slab), not 384 tall (the whole column).

Root cause

The far-LOD placeholder was built at the FULL column height instead of one slab:

  • Textured low — LOW_GRID_Y = 8: a 4×8×4 grid of 8 bands × 48 blocks = 384 tall. _low_emit() placed vertices in [0, 384] on Y (the y grid unit was 48).
  • Fog box — _low_fog_for() instanced one 16³ box per non-air slab (up to 24 slabs × 16 = 384 tall), stacked to the whole column.

The fix: the LOD represents ONE slab (16 blocks) — the TOP slab (the visible top of the terrain), not the whole 384 column. And an air column (top slab all-air) gets no placeholder.

What changed

  • LOW_GRID_Y = 1 (was 8) — the low grid is now 4×1×4 = 16 cells, 1 band of 16 blocks (was 4×8×4 = 128 cells, 8 bands of 48).
  • _low_grid() — samples only the top slab's center row (row_bytes(16*slab_top + 8), where slab_top = c.top / 16), not 8 band centers. An air column (top < 0) samples an all-air row → dominant id 0 → all-air grid → null mesh.
  • _low_emit(g, y_off) — the y grid unit is now 16 (was 48) and every vertex is offset by y_off = slab_top * 16 (the top slab's world y). Vertices are in [slab_top*16, slab_top*16 + 16] on Y — 16 tall, at the top of the terrain (not [0, 384]).
    Also fixed a latent y/z index-layout mismatch in the three g[…] reads (they used x + y*GX + z*GX*GZ but _low_grid writes x + z*GX + y*GX*GZ — invisible at 8 uniform bands, but at 1 band it overflowed the 16-cell grid → Out of bounds get index '16'; the reads now match the layout).
  • _low_build() — computes slab_top/y_off and passes y_off to _low_emit; records low_max_h (the cumulative max textured-low AABB height) so a transient low (upgraded to high before a point-sample) is still captured.
  • _low_fog_for() — instances ONE 16³ box at the top slab (was one per non-air slab). Returns early (no placeholder) when the column is air (top < 0) or the top slab is null.
  • chunk.gd — comment updated to describe the 16-tall top-slab placeholder (no behavior change).
  • main.gd (R16 arm probe) — new _r16_lod_height() (per-LOD-mesh AABB size.y = world height; the air-chunk count) and _r16_air_chunk_test() (takes a real far chunk, clears it to all-air, and asserts the fog first-pass AND the textured-low build both create nothing — a non-vacuous air-chunk proof, since the R16 terrain has no natural air columns). Reported in the lod RESULT block as height0/height1/air_chunk_test/height_ok/air_ok.
