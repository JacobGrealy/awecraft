1. Goal

1.1 Diagnosis (evidence, all measured this session)

The steady-state forward wall (r4: 0.85–1.0 s/crossing) is 100% build-dispatch pacing, not generation. Speed-4 probe stream (4.0 s/crossing windows, AWECRAFT_TGDEBUG/TMDEBUG/RECSLICE/RECPROBE): the lead column (column k+r at crossing k) DATA lands in the PREVIOUS crossing's window (leadPre = 8 of 9 GENHANDs before the crossing; the 9th, the (k+r, 0) center chunk, is a 40 ms main-thread sync gen — _gen_unit sync rule absi(cx)>0 and absi(cz)>0, world.gd:412). But its 9-chunk BUILD dispatch starts ~190 ms AFTER the crossing and spans ~650 ms (≈72 ms/chunk) (leadBd = 9 in [t+190, t+830]). 72 ms/dispatch = the AC-0077 batch light inflating main frames (17–34 ms/chunk) so last_build_us ≥ BUILD_FAST_US (15 ms) and the budget collapses to 1 build unit/frame. Worker mesh is ~44 ms/chunk off-main (wms_sum ≈ 354–428 ms/window) and is NOT on the critical path.

Cold start (crossings 1–6) = the in-radius fill backlog from the 3×3 spawn core. The +X walk starts with 3×3 built and 72 in-radius unbuilt (r4). Forward wall crossing 1 = 36-chunk fill of columns pcx+1..pcx+r: gen 36×~220 ms/3 (TG3) ≈ 2.9 s + main-light-paced build ≈ 0.9 s → measured 4908 ms baseline (4319/4293 on the gate runs). TG6 probe: 3445 ms. Trailing walls crossings 1–4 are −1 (NEVER built, even with TG6): the scored (forward-first) data pick generates backward columns LAST — column −3 data ready ~2.2 s even at TG6 — after the hysteresis release (cheby > r+1; column −3 released at t=2.0 s at speed 16). The web spec's own ring-order gen (3/frame, updateWorldStreaming) would have built them; the port's scored order does not. Consequence: tr_p95 is pinned at the check floor (42–43 ms, n=16 resolved-only).

Dead hypotheses (proven by A/B, r4): drain budget cap (DRAIN_MS=100 → 4251, neutral, walk max 73→144 harmful); mesh-pool saturation (THREADMESH_N=6 → 5127, WORSE); collision staging (COLSTAGE=0 → 4871, WORSE; collision = 313 ms total, max 3 ms); recenter slice (0–1 ms/crossing, new_n=20 in 1 frame). The only knob that helps today: THREADGEN_N=6 → 3321 (−23%), but it only cuts the COLD wall; the steady wall survives it (main-light paced).
