AC-0465 — one producer for chunk keys (format unchanged)

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Pure refactor: no format change, no behaviour change, every standing value must stay identical. Its purpose is to make AC-0459's format flip safe by making the producer count knowable.

1. Goal

Every place that builds the dictionary key for a chunk asks the world for it, so a later format change cannot miss one.

2. Why this exists (measured, 2026-10-20)

AC-0459 tried to change the key format in one producer and a builder proved that wrong: main.gd 1704/1827/1873/1908 build keys by hand, and _await_sim_band/_await_spawn_floor are in the game-start flow the save/load arms use — a missed site would show up as a 3000-frame wait and a "SIMBAND not fully built" line, not a crash. harness.gd has 145 "%d,%d" literals but MOST ARE NOT KEYS (RESULT labels, coordinate formatting) — so this ticket converts key CONSTRUCTION only, and must not touch the rest.
