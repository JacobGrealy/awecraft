## Implementation note (one shape drift, forced by the type system)
`world` is untyped in both harness.gd and main.gd, so `var x := world.chunk_key(...)` fails to
parse ("Cannot infer the type"). The 9 converted sites that used `:=` (7339, 9098, 9466, 10786,
25091, 25107, 27534, 27559, 28259) were changed to the explicit `var x: String = world.chunk_key(...)`
— same String type the old `:=` inferred, byte-identical runtime values. First gate run (g0-r1/
genhash-r1) caught this; fixed before any gate value was recorded (all recorded values are from
the post-fix tree: g0-r2, genhash-r2, light-r1, ac0423probe-r1).
