2. Breaking rules (Mining / Breaking)

  • Time to break (s) = 1.5 × hardness / speed, where speed = held tool's tier multiplier if it's the correct tool type, else 1 (bare-hand rate). Block with computed time < 0.15 s breaks instantly (no progress bar).
  • Wrong-tool penalty: if the block requires a specific tool (stone family, ores) and you don't have the right type, it still breaks but at 5× bare-hand time (speed treated as 1).
  • Drop gating: without the required tool, the block breaks but drops nothing. Obsidian adds a tier gate: iron pick (tier ≥ 3) or better required, else no drop.
  • Stone (3) drops cobblestone (9) only with a pick. Ores drop with any pick. Wood/soil blocks drop with anything (only speed differs).

3. Crafting: 2×2 (inventory) vs 3×3 (crafting table)

  • Inventory (E) = 2×2 grid only. Using the crafting table block opens a 3×3 grid ("gives access to many recipes not available from the inventory's 2×2"). Shape matching is by bounding box (recipes can sit in any corner); shapeless anywhere.
  • Repair via grid: two items of the same material/type side-by-side → 1 item with sum of durabilities + 5% of max (capped at max); no XP; works in 2×2 and 3×3 alike (anvil = +12%, keeps enchantments — out of scope, AweCraft has no enchantments).
  • Shift-click output = max craft (beta 1.6 re-added); closing the table returns grid items to inventory "if space allows".

4. Durability / repair (scope for AweCraft)

  • Use cost: axe/pick/shovel — break a non-instant block = 1, hit mob = 2; sword — hit mob = 1, break other block = 2; hoe — till soil = 1, mob hit = 1 (JE). Instant-break blocks cost 0. Item breaks at 0 (last block still breaks).
  • Durability bar renders under the icon (green→red, hidden when full). Repair = 2-of-same-in-grid combine (+5%, cap at max) — that's the entire repair surface AweCraft needs (no grindstone/anvil/elytra).
