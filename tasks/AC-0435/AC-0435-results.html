AC-0435 — audit every switch; flip the ones whose OFF state IS the defect

Date: 2026-10-16  ·  Verdict: 46 settings keys (28 bool switches) + every AWECRAFT_* env override + every shader-uniform default + every flag-gated code path audited. Exactly two switches ship their requested fix OFF — both flipped ON: cloud_gate (AC-0428) and viewmodel_occlude (AC-0394). Every other switch's default is either the user-requested state, a user-reported-defect fix that is already in the requested state, a debug tool that must not be left on, or an un-asked taste/perf path where OFF is genuinely conservative. ambient_sky (AC-0426) is the worked precedent — it was re-ruled ON by AC-0432; it is cited, not re-flipped.

What was deliberately not done

  • No third flip. Every remaining OFF bool is a debug tool (must stay off), a user-reported-defect fix that is already in the requested state (ambient_enabled off is the request), or un-asked taste (smooth_ramps). Flipping any of them would fail the “survives the user reading it” test.
  • No world/, data.gd, or C++ change — the two flips are render-side defaults only; genhash 25/25 vs the current-tree reference proves it. No SCons rebuild owed; the working tree stays in the state the served godot/bin/libchunkio.so was built from (no C++ touched).
  • No re-baseline of standing heavy values — the light set is this ticket's; farab/ladder/meshprobe/halo/ lightstate/r16/boundary are the coordinator's. None of them is expected to move (nothing generation-side changed).
  • The wallshot arm was not run — it writes into fenced tasks/AC-0067/.
  • The held arm's pre-existing box_ok false was not fixed — it is data-side and pre-existing (A/B-proven above); fixing a held-box tint is not this ticket's scope. Recorded for the coordinator.
  • The ambient_sky row comment in menu.gd was corrected (it still said “default OFF” after AC-0432's flip) — a documentation-truth fix found in the sweep, same for the ARCHITECTURE.md/HARNESS.md env rows for both flipped switches.
