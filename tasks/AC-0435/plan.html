AC-0435 — plan: audit switch defaults for shipped-off fixes

Goal

Enumerate every switch (settings rows, env overrides, shader uniforms with a default, flag-gated code paths). For each: what it does, what defect or request it exists to serve, whether its OFF state is genuinely conservative or whether the OFF state IS the defect, and what depends on it. Flip exactly the switches whose off state is a defect the user reported or asked about, with before/after frames and a regression check (standing gates, night look, scene contrast). Leave everything else alone.

The deciding line (per the spec): the test is not "is this feature good" but "does the absence of this feature reproduce a problem the user has reported or asked about". A switch that disables an expensive effect for performance is fine; a taste switch stays off unless the user asked; a switch whose OFF state is the defect gets flipped with evidence that would survive the user reading it.
