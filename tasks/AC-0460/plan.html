AC-0460 stage 2b — restore occluder coverage for mesh-less solid slabs

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Closes the regression recorded at stage 2a: 89 warp occluders against 335 legacy. Small and bounded.

1. Goal

Under the warp, a fully-solid slab that emitted no mesh still gets an occluder, derived from its cell footprint, so warp mode does not silently lose ~three quarters of its occlusion coverage.

2. The measured problem (stage 2a)

Legacy gives every full_solid slab an occluder whether or not it has a mesh (a fully buried slab is invisible but still occludes). Stage 2a can only derive the box FROM a mesh, so buried slabs fall to the guard and lose theirs: 89 warp occluders vs 335 legacy under the live renderer. That is the gap this ticket closes.

4. Edit shape

In the warp branch, when the mesh AABB is missing or degenerate, fall back to a box derived from the slab's own cell footprint instead of leaving s.occluder = null:

  • Take the chunk's 16×16 cell-corner lattice at two heights, h = y0 and h = y0 + 16 (the slab's own vertical extent — use the slab's real height constants if the file defines them; do not hardcode 16 if a named constant exists), warped by the SAME construction the mesh uses: (R + h) · normalize(SM.uv_to_world(face, u, v, R)) − (0, R, 0) with the mirror-aware chart inverse already implemented in _warp_face_slabs. Reuse that code path rather than writing a second copy of the mapping — extract a small helper if that is the clean way, but do not change what the existing callers compute.
  • The box is the AABB of those 34 points (512 corners is unnecessary: the 16 edge samples per side plus the 4 corners are enough; if that is awkward, all 256 cell centres are acceptable but say which you used).
  • Same degenerate guard as stage 2a applies to the result.
  • Flag off: no change at all.

5. Probe additions (tasks/AC-0460/occ_probe.gd)

  • For a full-solid slab with NO mesh, the fallback box must (a) have its centre inside the chunk's corner-cloud bounds, and (b) have horizontal sizes in the same documented [16, 110] m band and vertical in [1, 128] m.
  • Assert the fallback box and the mesh-derived box for the same chunk agree in CENTRE within half the chunk footprint (say 60 m) — they describe the same slab, so a wild disagreement means the fallback is wrong.
  • Keep the negative control firing.

7. Acceptance

Warp mode recovers occluder coverage close to legacy, the fallback box describes the same slab as the mesh-derived one, and the flag-off path is untouched.

8. Risks

The fallback uses the chunk footprint, so for a partially filled slab it is looser than the mesh box — acceptable (the legacy box is a constant 15 m for a 98 m chunk, i.e. far looser). Never let an occluder sit so far out that it hides visible geometry: the probe's centre-inside-cloud assertion is the guard.
