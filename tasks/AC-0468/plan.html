AC-0468 — make the seam instruments able to see the new world

Coordinator contract. Medium builder applies it with tasks/templates/implement.md. Test-tooling only: no game or native behaviour change. AC-0467 stage B made the canonical placement the default and deleted the seam extension; two instruments still assume the old model and one of them now fails itself rather than the world.

1. Goal

`seamcensus` measures the default tree correctly, and `ac0423probe`'s warp-mode degeneracy is either fixed or retired with a reason — so the seam checks are evidence again before the lane merge (AC-0463) starts.

2. The two problems, as measured

  • seamcensus self-fails on the default tree. Its reverse map assumes CHUNK-LOCAL vertices — the old model, where a chunk's mesh sat in local space under a per-column transform. On the canonical placement vertices are already world-space, so the map no longer describes the meshes it measures. Flag-off is still clean (0/64 seams, 393,216 rows), which is how we know the instrument is sound but the assumption is not.
  • ac0423probe's warp-on mode degenerates: its nine overlaps read as raw cracks / n=0 under the warp, while its flagon counterpart is faithful on the new placement.

4. Edit shape

  • 4.1 seamcensus. Make the reverse map placement-aware: on the canonical (default) placement the vertices are world-space, so the instrument must derive cells from world positions the way the game does (the AC-0462 lesson applies — a non-orthogonal basis needs the full 3×3 inverse, never per-axis dots; per-axis measured 44% exact, affine_inverse 100%). Keep the flag-off path working exactly as today.
  • 4.2 The assertion must still be able to fail. After the fix, seamcensus must be green on the default tree without having been taught to accept whatever it sees. State in the deviations what it asserts now and why that is correct for world-space vertices. If you cannot state that, the fix is a re-recording and must be reported as such, not as a repair.
  • 4.3 ac0423probe. Either fix the warp-on path or retire it in favour of flagon. Say which and why. If retired, keep its flag-off behaviour byte-identical so the standing nine values stay reproducible on the flag-off tree, and note in the arm's documentation that flagon is the instrument on the default placement.
  • 4.4 Alignment. Where seamcensus and seam_band_probe measure overlapping quantities, make them agree or state why they measure different things. Two seam numbers that disagree without an explanation is the situation that produced AC-0423/AC-0427's irreconcilable ranges in the first place.
