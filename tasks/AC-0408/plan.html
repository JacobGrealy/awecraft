Reading of the counter (code, before any change)

  • perf_staged_dropped (world.gd:3628) counts entries in the staged collision queue (_col_pending) that lost validity before the ≤2-columns/frame drain could serve them. The queue holds column key strings, not object references (_col_pending.append(key), world.gd:10064). Staging = a meshed, collision-dirty chunk OUTSIDE the immediate footprint (Chebyshev >1) owes a body build that the per-frame budget defers (AC-0077/AC-0340).
  • Two drop sites in _col_drain_step (world.gd): site 1 (10101–10106) — chunks.get(key) == null: the chunk was freed while the entry was pending (stale). site 2 (10115–10119) — the chunk is alive but ok is false: not meshed / collision disabled (band excursion, _reband 10068) / no longer dirty (the body was built by the immediate path after the player re-entered) / outside render_radius while still resident (candidacy keeps nodes at r+1).
  • The ceiling (HARNESS.md §3 standing row, set at AC-0337, 2026-09-20, from a 1845 reading on the pre-AC-0387-carve tree): "a sustained reading above that means the drain is oversubscribed again … or the lane has stalled". Health is separately fenced: staged_pending_final (the queue fully drains), col_deferred_in_footprint (0 — no body deferred under the player), the arm-side footprint scan (0), unbodied_built_final (0). A drop is by design "work no longer owed", not lost work — so the counter is a churn census, and the ceiling's meaning is a proxy on a moving target (world content + box load both move it; documented 2679/2950 readings under box load, AC-0384/AC-0113).

How the lifetime link is tested

  1. Static (done): the queue holds keys, not references — a dropped stage frees nothing and references nothing. The free path (_free_chunk_key 10293–10343, _enter_candidate 10238–10262) erases the chunk's entry from every key-indexed holder (star bookkeeping, _eff_cache, _face_blk, _bl_want, queued_keys, fluid/tex, _col_pending*); the node is reset + pooled (_col_checkin 1405–1426: high MIs to the MI pool, StaticBody3D collision bodies queue_free()'d, _pool_reset() drops the slab data). So "a dropped stage leaves a live reference" is false at the staging layer by construction; the only residual reference class is a raw pointer into slab PBA buffers (AC-0214 wrapper semantics) — which is the AC-0403 C6 class, independent of staging. Runtime confirmation is owed for both directions (see 2).
  2. Runtime — cause split (permanent counters): split staged_dropped by cause — stale (site 1), done / radius / disabled / unmeshed (site 2) — in both the boundary and perf arm RESULTS. If stale dominates, the drain is losing the race to streaming (drain fix owed); if done/radius/disabled dominate, the counter is the churn census the row's own note describes, and 2663 is content+load, not a stall.
  3. Runtime — holder-residue census (permanent counter, print env-gated AWECRAFT_STGPROBE=1, off by default = zero behaviour change): at the moment a chunk dies (_free_chunk_key, after its own erase block) and at the moment a stale entry is dropped (drain site 1), scan the key-indexed holder maps the free path is supposed to empty. A non-zero residue = a holder that was NOT told = the lifetime bug, caught directly. Must read 0 in every gate.
  4. ASan soak (the decisive instrument, per AC-0403's recommendation): rebuild libchunkio.so with -fsanitize=address (manual g++, the SConstruct's exact flags + ASan; SCons is not on this box — AC-0403 precedent). The crash read (slab_cell → slab_getbits i[bo]) executes inside the instrumented .so, so a freed slab buffer re-read there faults with a clean ASan report. Scope stated honestly: only faulting accesses inside the extension are caught (godot-cpp static lib + the engine are uninstrumented — an engine-internal refcount edge would not be caught). Soak = the exact AC-0402/AC-0403 crash recipe (lightstate LS_RADIUS=16, 12 GB cap, ×4) + the player arm (the other crash caller) ×1. No ulimit -v on ASan runs (ASan reserves ~20 TB of VA — a virtual-memory cap kills it at startup; physical memory on the box is 61 GB, 44 GB free). The production .so is backed up before the swap and restored + sha256-verified after.
