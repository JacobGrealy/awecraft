AC-0446 plan — close the far LOD tier seam

Goal

Make the far average band's shading RESULT equal the near tier's, face class by face class, so the tier boundary in a daytime frame shows no step — without washing out the far terrain's depth cue, without touching the day-gated lift's night behaviour, the fog wall, or the body's relief.

The shape of the difference (measured first, before the approach)

Method: read both shaders and the data that feeds them (no render needed to establish the shape — the prior renders, AC-0443/AC-0444, supply the pixel anchors).

Near tier — chunk_lit_*Far band — lod_avg
pipelinerender_mode unshaded: ALBEDO = tex · shade · L; L is the WHOLE light shaded (default): ALBEDO = COLOR · day-gray · jit · lit, then the ENGINE multiplies by (sun·lambert + sky·ambient)
light modelL = 0.20 + 0.80·m_direct + 0.35·u_day·step(m_direct, 0.08) + u_moon·lambert, m_direct = max(u_day·s, blocklight); s = baked sky scalar ∈ {20/255 floor, 1.0} lit = mix(0.2, 1.0, COLOR.a) + 0.35·day.r·(1−COLOR.a); COLOR.a = binary heightmap sky (1.0 top / 0.0 side — mesh.cpp: alpha = skyp/15, skyp ∈ {0,15})
effective at noon, unlit side face (the defect face)0.20 + 0.8·(20/255) + 0.35·1.0 = 0.613 × tex (0.2 + 0.35·0.753) · 0.753 (day-gray tint) · ≈0.58 (engine sky ambient) = ≈0.20 × COLOR → 3.0× darker
effective at noon, sky top face0.20 + 0.80·1.0 = 1.00 × tex1.0 · 0.753 · (0.97 direct + 0.58 ambient) = ≈1.17 × COLOR → slightly OVER-bright

Verdict — the difference is NOT a constant factor: a=0 faces are ≈3× too dark (dominated by the shaded pipeline's engine-ambient multiplication — a term the band's model does not account for at all — plus the day-gray tint the near tier has no), while a=1 faces are ≈17% too bright. A single multiplier cannot fix both; the ticket's warning is confirmed by the models themselves. The observed pixels agree: (50,40,31) vs (135,116,103) ≈ 2.7–3.3× on the a=0 flank (the residual vs 3.0× is the 8×8 averaged COLOR vs per-vertex tex, ±6% jitter, 4% fog, ACES).

Why the approach follows: the band can represent exactly the two face classes the near tier has at the seam — sky-exposed tops (a=1 ↔ s=1) and unlit sides (a=0 ↔ s=floor 20/255). So the fix is structural, not a dial: make the band UNSHADED and run the near tier's L model on that data (m_direct = mix(20/255, u_day, COLOR.a)), dropping the day-gray tint the near tier lacks. Every face class then computes the same L the near tier does, by construction. Depth cue: the engine environment fog still applies to the unshaded material (fog is not the shader's) — the wide shot verifies the gradient survives. Night: the lift term is ×u_day → 0 at night (day-gating intact); the band's night becomes the near tier's own night (0.2 floor + moon lambert) instead of near-black — documented as the parity consequence, with the conservative switch OFF path keeping the old night bit-identical.
