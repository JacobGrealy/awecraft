3. Deviations (of record)

  • "All 32 frames equal" is unsatisfiable by design: the base water strip genuinely animates (3 distinct per-frame noise values, raw f0 ≠ f16 — the pre-fix "raw" centers were grey (194,194,194)/(174,174,174)). The real invariant is per-frame baked == raw × TINT_WATER (no grey anywhere), which the probes assert pixel-wise.
  • Render frame index is not set by AWECRAFT_TIME: that env sets Game.time_of_day (day/night); the shader frame = elapsed TIME + AWECRAFT_ANIM_PHASE (0.3 s/frame, confirmed in data.gd:274 + fluid_anim.gdshader). Immaterial post-fix: the pixel probe proves every frame is identically tinted, so blue at any frame.
  • First builder render attempt used a relative snapshot path (PNG save denied by session sandbox); re-run with absolute path succeeded. (Coordinator runs use workspace-relative fine — different sandbox surface.)
