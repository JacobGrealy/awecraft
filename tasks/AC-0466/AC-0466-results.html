# AC-0466 deviations

1. **Documented subset (plan §4 Coverage):** the arm crosses TWO of the twelve chart boundaries — the +x edge seam (the 4/5 pair) and the -z edge seam (the 10/11 pair) — in one run, covering both edge classes (an x-face pair and a z-face pair). A full twelve-chart lap in one arm run would risk the 600 s budget (world boot + up to two bounded 1200-frame settles per seam); the plan sanctions a documented subset and the RESULT carries `waivers` stating exactly this.

2. **The plan's named body predicate is structurally unsatisfiable on this tree (FINDING — the headline).** `has_all_slab_bodies()` requires ALL 24 slabs to hold a collision body. Measured (temp probe, since removed): a fully built HOME chunk (194,-2) holds bodies on 8 slabs — exactly its 8 meshed slabs — and face chunks the same (4:63:0: 13 bodies / 11 meshed; 10:0:63: 12 / 12). An empty slab (air above the surface) never gets a mesh instance, `_build_slab_collision` early-returns without a body, and `col_dirty` is cleared — so "all 24 slabs hold bodies" cannot hold for any surface below HEIGHT, on EITHER lane. The plan's gate ("destination chunk has BOTH mesh and body") cannot ride on the named predicate, and the crossface arm's wait (harness.gd ~34154-34162, which requires `has_all_slab_bodies()` on home chunks) is probably stale on this tree now (it should burn its 6000-frame timeout) — flagged for the coordinator to confirm by running crossface. Resolution (documented, not silent): `body_present` is the AC-0145 HAZARD condition composed IN THE ARM from existing slab state — mesh_built, no slab `col_dirty`, every slab that carries a mesh holds its collision body (no new game predicate added to chunk.gd/world.gd) — and the literal predicate is still reported as `body_all` / `cross_body_all` as the evidence. If the coordinator prefers the literal as the gate field, it is one line to flip.

3. **Negative-control teeth: the pre-stream beats the walk on a healthy tree (FINDING, plan §7 — the opposite of the risk clause).** Measured: at the crossing frame the destination chunk is ALREADY resident+meshed+bodied in BOTH modes (cross_resident true, settle_ms ~0 ms) — the `_face_stream` 64 m pre-window (sim_dist*16) starts ~30 frames before the walk and the 3-chunk crossing row is first in its 12 ms/frame budget, while the 8 m/step walk needs ~12 frames to reach the seam. So skipping the waits does not expose an unbuilt CROSSING frame on this tree — there is no streaming gap, and the arm's waits do no work on a healthy tree (they bound the AC-0463-class stall, which they would catch as `src_settle_timeout` / `dest_no_mesh` / `dest_no_body`). To keep the plan's gate (`negctrl.saw_unbuilt` true) meaningful, the arm takes one extra read-only snapshot: `stand_dest_built`, the destination chart's chunk at the walk's end read BEFORE the stand recenter, when the face lane cannot have streamed it (the spawn is kilometres from every edge). It is always false on a healthy tree, and it is the proof the same read path that reports the crossing boundary built can see an unbuilt one — the AC-0145 teeth, at the one instant the walk cannot outrun the stream. `negctrl.saw_unbuilt` scans all recorded state fields including this one.

4. **Two extra per-crossing fields beyond the plan's minimum RESULT keys:** `cross_resident` / `stand_dest_built` (finding evidence, see 3) and `cross_body_all` / `body_all` (the literal predicate as evidence, see 2); plus the carried `aabb_delta_m` (warpcensus's seam-census field on the destination chunk — plan §4 "the seam census fields ... if they are cheap to read"; only the one cheap field was taken, not the ac0423probe's full vertex census), `src_*` walk-start state, `dest_chunk`, `settle_ms`, `src_wait_ms`.

5. **The walk is position sets, not on-foot physics:** each 8 m step sets the player position directly (the crossface teleport discipline) in fly mode (the faceedit footing shape — no footing needed). The instrument measures the chunk state at the crossing and the face change, not the gait; on-foot seam traversability is the crossface arm's standing gate.
