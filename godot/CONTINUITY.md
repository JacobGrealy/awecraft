## 25. CHECKPOINT 2026-10-04 (r25) - **FOUR SHADER DEFECTS STACKED BEHIND ONE SILENT DROP, AND THE CHECK THAT LIED ABOUT IT.**
**THE CHAIN, in the order it surfaced, all in `godot/core/satellite_body.gdshader`:** (1) the file's **first line began with `#`**, and a `.gdshader` whose first line begins with `#` is **dropped by Godot with NO ERROR** - the material silently falls back to a default **white** Lambert sphere, which is the pale-cyan planet the user reported for two days; it also meant the file had **never been parsed at all**, so every error inside it was a first-time discovery. (2) `render_mode ... transparent` is **invalid in 4.7.1 on both renderers** (the same defect in `cloud_layer.gdshader` meant the cloud shell had never rendered either, while printing its error into gate logs for days). (3) **`hint_color`** - Godot 3 syntax, renamed `source_color` in Godot 4; the only occurrence in the project. (4) **`COLOR = vec4(...)`** - `COLOR` is the canvas_item (2D) output, so in a `spatial` shader it is a read-only vertex input and the parser says "constants cannot be modified"; this was **2D-style shader code in a 3D shader** and is now `ALBEDO` + `ALPHA`. Because Godot stops at the first parse error, **fixing any three would still have left the user looking at a white ball.**
**THE FALSE PASS, which is the most expensive single mistake of this session:** the coordinator claimed this fixed on 2026-10-03 on the strength of a "zero `SHADER ERROR` on the Forward+ path" check - and **shaders compile LAZILY, when a material is first built**, so that run never reached `_build_face` and reported success on a shader it had never compiled. A check that cannot reach the defect is **worse than none**, because it converts an open question into a false conclusion. The instrument that DID catch all four is **`meshprobe`**, because it builds meshes and therefore compiles the shader - and its gate only reads its own mismatch count, so **the error line had been printed on every run for days, unread**. This is the SECOND time in two days that the defect was sitting in plain text in our own logs (the cloud shader was the first), and the rule harvested from the first - **an unexplained line in a gate log is not noise** - paid for itself within a day.
