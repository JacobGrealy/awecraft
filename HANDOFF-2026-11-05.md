   also uses. **Building chunks cannot fix that**, and fog was masking a *colour identity*, not a hole.
3. **`AC-0438` has a strong lead it did not have before.** It is blocked on a hardware check, but `AC-0512`
   independently measured an **8× luminance step at the body-chart seam** plus an untested **−1 m chart bias**.
   Start there rather than re-deriving the layer (wrap, mip, anisotropy, UV overshoot and per-face clamp are all
   already eliminated).

   without new evidence — both blockers are API-level and were each tested across every available configuration.

## 5. HOW TO WORK THIS REPO (hard-won, non-obvious)

### Delegation
- **The standing rule from the user: the coordinator writes `plan.html`; a MEDIUM subagent implements; escalate
  to `xhigh` only if medium fails.** In this session medium began failing with `subagent run failed`, and the
  user then directed **xhigh for implementation** — so use `xhigh` while that stands.
- **A builder returning `PLAN-INSUFFICIENT` is the system working.** It happened **six times** this session and
  each time saved a bad landing. Never treat it as failure; repair the plan and re-launch.
- **Builders that verified instead of complying were right every time.** They corrected my `0.19` area-mean
  (actually a chord value), proved my per-cell assertion impossible, refuted my per-chunk-quantization theory,
  and found my "swap the labels" instruction would have *created* the bug. **Design from measurement, not from
  code reading.**

### Verification discipline
- **Measure before believing a ticket.** `AC-0438` (gone?), `AC-0402` (already-removed?), `AC-0464` (cancelled
  with numbers — the defect was gone) and `AC-0483` (filing's premise false) all turned on this.
- **Negative controls are mandatory** and got demanded seven times: a gate never shown to fail is decoration.
- **Never judge a defect from a blurred frame.** User ruling: `dof_enabled` now defaults **false** and blur must
  not be used in test renders — it destroys 1–2 px seams, faceting, parity ratios and streak direction.
- **State what you did NOT run.** Several closes explicitly say "I did not re-run the heavy set" — that honesty
  is expected, not optional.

### Traps that cost real time
- **`gate_run.py`'s slot test is `pgrep -f "[g]odot"`**, which matches **any** command line containing that word
  — including your own shell string when it mentions a `godot/…` path. Run engine work from a **script file
  invoked by name**. This bit four separate runs.
- **Anchors go stale fast** — a parallel session edits the same files. **Locate by symbol, not by line.** Three
  of my plans carried dead anchors; `lod_avg.gdshader` has been haze-free since `AC-0404` yet I pointed at it.
- **`tasks.py note --append-file <(…)` fails** — process substitution is not resolvable. Write a real temp file.
- **Never `git add -A`.** Long-lived untracked dirs (`.scratch/`, `references/`, many `tasks/AC-0*/`,
  `godot/fixtures/`) must never be swept in.
- Coarse `grep -c 'rc='` counters match your own summary lines — **check what a counter is counting** (this
  produced a false "106 runs").
