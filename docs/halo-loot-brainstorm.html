1. What Makes Halo Feel Like Halo

Single-player weapon feel — not CoD comparison.

Golden Triangle

Guns + Grenades + Melee are equally viable. Every fight uses all three.

  • Shield/Health split: Recharging shields + health. Two-stage duel: strip shields (any damage) → headshot for kill. Shield crack is loud/visual and resets recharge timer (~4s).
  • Long TTK: 1.2–1.8s perfect (4-shot BR, 3-shot CE Magnum). Allows strafe, turn, and outplay.
  • Weapon sandbox by role, not stats: Precision / Plasma / Spread / Power. No attachments; each gun has a hard job.
  • No ADS, full move speed: Hipfire at 100% strafe. Floaty jump, strong strafe accel — duels are tracking, not recoil control.
  • Two-weapon limit + scarce ammo: Forces rotation through sandbox (drop empty BR for Needler).
  • Damage types: kinetic / plasma / explosive / hardlight with per-target shield_mult vs health_mult. Plasma 1.5–2.0× vs shields, 0.6× vs health.

Feedback > Recoil

  • Sound is bass-heavy and distinct per weapon; shield pop, flesh hit, and headshot ping are different cues.
  • Enemies flinch/stagger on shield break — weapon feels strong because target reacts.
  • Campaign feel: distinct faction weapons (hitscan human vs slow projectile Covenant) force leading and varied rhythm.

2. The Halo Pistol — CE M6D as Reference

The defining weapon: pocket sniper, not sidearm.

CE M6D Stat Block

  • 12 round mag, ~2.4 RPS, hitscan, 3-shot kill (3 headshots)
  • 2× scope, zero bloom/spread, perfect accuracy
  • Almost no view kick — see §3

Feel Breakdown

  • Shot: Loud THWACK-CRACK with long tracer, sharp pad kick
  • Accuracy: Deterministic; if dot on head, it hits. Large magnetism cone (~6–8°)
  • Cadence: Deliberate pop…pop…pop → ping → drop
  • Power fantasy: AR feels weak/sprayy, then Magnum 3-taps Elites across the map

Evolution (why other pistols feel different)

GameFeel
Halo 2 M6CNo scope, dual-wield, 6–7 shot, high spread — tinny pat-pat, backup only
Halo 3/ODST M6G8 mag, 5-shot (3 head), chunky BOOM, 0.5–1° view kick
Reach M6GAdds bloom — spam punished, must pace to ~85% RPS
Infinite MK50Fast 7-shot Sidekick, burst-like braap, tracking not tapping

3. Systems — What To Implement

Programming checklist for Halo shooting. CE has almost zero camera kick — kick is viewmodel + reticle.

Weapon Definition (data-driven)

WeaponDef:
  fire_mode: semi | auto | burst | charge | overheat
  rps, burst_count, mag_size, reload_time, overheat_threshold
  damage: { shield_mult, health_mult, headshot_mult }
  projectile: hitscan | projectile(speed, gravity, lifetime)
  accuracy: { error_angle, bloom_per_shot, bloom_decay_rate, min_error }
  magnetism_angle, friction_scale
  range_falloff: curve

Firing Pipeline

  • State machine: Ready → Firing → Recovery → Reload/Overheat → Ready. Enforce fire_interval = 1.0 / RPS and require button release for semi.
  • Raycast from camera.forward, spawn tracer from muzzle — avoids shooting around corners.
  • Heat: heat += per_shot; heat -= cool_rate*delta; if heat>1.0 → lockout.

Accuracy: Error + Bloom, Not Recoil Pattern

  • error_angle += bloom_per_shot on fire; lerp(error, min_error, decay*delta) at rest. CE Magnum bloom = 0.
  • View kick is visual only — camera rotation never changes (except tiny scoped punch). Decouple camera punch from bullet_dir.
on_fire():
  play_muzzle_flash()
  animate_viewmodel(kick 3deg, 80ms) // viewmodel mesh only
  // camera.rotation unchanged
  bullet_dir = camera.forward + random_cone(error_angle)
User observation confirmed: CE screen flash is muzzle flash + shield flash, not camera move. Later Halos add viewmodel + reticle bloom only; camera stays 1:1 with input. Zoomed BR is the exception — adds ~0.3–0.5° scope punch + idle sway, plus FOV 70→40 and 0.6× sensitivity.

Aim Assist (non-negotiable for pad feel)

  • Friction: scale look_input * 0.4–0.6 when reticle over target.
  • Magnetism (bullet bend): if ray missed and angle_to_target < magnetism_angle, bend hit to head. CE ~6–8°, sniper ~2°.

Damage: Shield/Health State Machine

on_damage(amount, type, is_headshot):
  if shields > 0:
    amount *= type.shield_mult
    shields -= amount
    if shields < 0: health += shields * type.health_mult; shields = 0
    recharge_timer = 4.0
  else:
    if is_headshot: amount *= headshot_mult # 2.0–3.0×, only when shields down
    amount *= type.health_mult
    health -= amount

Melee + Grenades (same priority as guns)

  • Melee lunge if dist < 2.5m & in reticle, 2-hit vs shields, 1-hit vs flesh.
  • Grenades: arc preview, bounce, plasma stick via raycast. 2 types differ in fuse, radius, shield_mult.

4. Procedural Halo Weapons — Infinite Variations Without Losing Feel

Generate within archetype envelopes, not pure random.

Archetypes (fixed roles)

  • Precision (BR/DMR/Magnum): semi/burst, hitscan, 4–5 shot, low bloom, high magnetism
  • Plasma (Rifle/Carbine): projectile, high shield_mult, overheat
  • Spread (Shotgun): pellets, falloff, close range
  • Power (Rocket/Sniper/Laser): low ROF, high damage

Modules (mutate within bounds)

  • Receiver / barrel / mag-core / sight / stock — each mutates stats ± bounded range
  • Precision barrel never gives shotgun spread
  • Seed drives mesh kitbash + audio + VFX + stats together

Example Roll — Precision Envelope

damage_per_shot = rand(12–16) # so burst*headshot = 3–4 shot kill
rps = rand(2.0–3.5); burst = choice([1,3])
error_min = rand(0.0–0.3°); bloom_per_shot = rand(0.2–0.6°)
magnetism = rand(3–7°) # never 0
damage_type = kinetic | plasma  # plasma → shield_mult 1.5–2.0
projectile = 90% hitscan, 10% fast projectile (250 m/s)
validate: TTK at-level must be 1.2–1.8s perfect, else re-roll

Constants — Do Not Proceduralize

  • Viewmodel+reticle kick only, magnetism+friction always present, shield/health split and headshot-only-when-shields-down.
  • Readability: long barrel+scope = precision; glowing core+vents = plasma/overheat; wide muzzle = spread. Color/sound tied to damage type (kinetic=crack/grey, plasma=whine/purple, hardlight=zap/orange).

5. Infinite Levels + Planet Scaling (WoW-like)

New planet locks to your level at discovery; returning you stomp. TTK varies with level delta.

Power Curve

level_mult = pow(1.08, level) # ~8%/level; 10 lvls = 2.15×
actual_damage  = base_damage  * level_mult(weapon_level)
actual_shields = base_shields * level_mult(enemy_level)
actual_health  = base_health  * level_mult(enemy_level)
# at-level: mults cancel → TTK stays 1.2–1.8s by definition
  • Soft diminish after 100: pow(1.08,100) * pow(1.02, lvl-100) or periodic squish to avoid 1.08^200 = 3.8M× float blowup.
  • Preserve integer breakpoints: shots = ceil((shields+health)/(dmg*headshot_mult)). Validate at-level shots in [4,5] for precision, else re-roll weapon.
  • Headshot mult never scales — stays 1.8–2.5× only when shields down.

Planet & Loot Rules

planet.level = player_level_at_discovery  # locked forever
enemy.level  = planet.level + rand(-1..+2) # elites +2
loot.level   = planet.level + rand(0..+2)  # slightly above, progression
  • New planet: everything at your current level — fresh Halo TTK.
  • Old planet: never re-scales. Returning at +15 you 1–2 tap.
  • Store planet.level in save; version the curve (curve_v1) so patch doesn't retroactively retune saves.

Upgradability (bridge gaps, keep god rolls)

upgrade_cost = base_cost * pow(1.25, weapon_level)
max_upgrade  = weapon_level ≤ player_level + 5
on_upgrade: level +=1, keep seed/parts, optionally re-roll one stat in envelope
  • Keep a favorite viable ~10–15 levels, then new planet drop wins. Cap at base_level+10 to force eventual re-loot.
  • Require planet-specific mats so you must visit new planets to upgrade.

6. Destiny-Style Smooth Scaling (Reference)

Bungie's solution to the same problem — same Halo team.

  • Uses delta = your Power − enemy Power with piecewise curve, not pure pow.
  • At-level = 1.0× (tuned Halo TTK). +20 delta → 1.25× capped (+50 still 1.25×). Being +40 doesn't give 5×.
  • Underleveled hurts more than overleveled helps: -10 → ~0.6× effective DPS.
  • Clamp keeps 4-shot staying 4-shot; stair-step breakpoints rarely crossed because scalar only 1.0–1.25×.
  • PvE vs PvP scalars separated — Crucible ignores Power.
Takeaway: Destiny keeps Halo feel by capping advantage at ~25% faster kill. Stomping old content feels strong but still 3–4 shots. That's the conservative choice; AweCraft can choose to let it break (next section).

7. Allowing Halo Feel To Break When Vastly Overleveled

Decision: outside the Halo window, let TTK collapse — power fantasy is intentional.

delta = weapon_level - enemy_level
if abs(delta) ≤ 7:  # Halo window
  mult = pow(1.06, delta) # 1.06^7=1.5× → 0.8–2.5s
else: # power fantasy
  mult = pow(1.06,7) * pow(1.10, abs(delta)-7) # steeper outside
# +15 → 2.6× (2-tap/1-tap), -15 → 0.25× (10+ shots)
  • Inside window: preserve breakpoints, magnetism, shield→headshot loop.
  • Outside: let it break. 1-tap on old planet is the reward.
  • Still keep: hit feedback (shield pop + ping), weapon identity (burst/heat), reload — don't make every gun same 1-shot.

Underleveled Floor — Why Cap?

WoW uses hit-table RNG (5%→17% miss vs +3 skull), not a damage scalar. FPS can't use RNG miss — perfect aim must hit. So FPS converts WoW's miss chance into a damage scalar.

  • .2× floor is arbitrary — just an example "5× weaker, 4-shot→20 shots, punishing but killable with skill" soft gate.
  • No cap / .05× = hard gate: -30 → 0.09× → 44 shots, effectively immune. Use if you want level = hard wall, go away.
  • Cap at .2–.3× = soft gate: skilled player can chip it down. Use if you want level = strong hint but possible.

8. Death & Grave — Minecraft + Dark Souls Hybrid

Drop until touched, then timer; second death deletes old grave.

  • Rule: Die → death_bag at death pos with inventory snapshot. Persists forever until interacted. On interact/open, start 5 min despawn for leftovers. Die again before retrieval → old bag deleted, new bag at new spot. Only one grave exists (Souls-like).
  • What drops: Decide hotbar+equipped vs full inventory vs currency-only. Full drop with infinite-level purples is harsh — consider vault/prime slot that never drops.
  • Persistence: Store DeathGrave{planet_id, chunk_pos, world_pos, items[], touch_time} in save, not just scene node. On planet load, respawn entity if grave matches that planet. One global grave means dying on Planet 5 while grave on 4 permanently deletes 4's loot.
  • Edge cases: Death in void/lava → spawn at last safe ground (raycast to floor). Full inventory on pickup → leftovers stay, timer ticks — must make space. Owner-locked, no co-op steal. Die empty → no grave.
# save.gd sketch
var death_grave: Dictionary = {}
func on_death(player):
  if death_grave.size()>0: remove_grave_entity(death_grave)
  death_grave = {planet_id=current_planet, pos=player.pos, items=player.inventory.snapshot(), touch_time=null}
  player.inventory.clear(); spawn_grave(death_grave)
func on_grave_touched():
  if death_grave.touch_time==null: death_grave.touch_time = Time.get_unix_time_from_system()
func _process():
  if death_grave.touch_time and Time.get_unix_time_from_system()-death_grave.touch_time > 300: erase_grave()
Risk: Losing a level 85 god-roll to a second lava death with no recovery = uninstall moment. Needs insurance/buyback (next).

9. Insurance — Borrowed From Extraction Shooters

Pre-pay to protect god rolls; not everything.

Tiers (Tarkov-like)

  • Base (cheap): Still drops to grave, but if grave is lost it returns via Base Mailbox after 20–30 min. You play without it until return.
  • Prime (expensive): Doesn't drop at all — stays in inventory. For 1–2 favorites only.

Cost & Limits

cost = base_fee * pow(1.06, level) * rarity_mult
# common 1.0, legendary 3.0, god-roll 5.0
# ~15–20% of weapon value for Base, ~50% for Prime
# limited slots: Base 3–5, Prime 1–2
  • Pay in planet-specific mats — must farm at level, not old planet.
  • Expires on time (24h) or death count (3 deaths), consumed on use.
  • Can't insure while grave exists.
on_insure(weapon, tier): weapon.insurance={tier, expires_at}; deduct_cost()
on_grave_lost():
  for item in lost_grave:
    if item.insurance.tier==BASE: mailbox.queue(item, now+30min)

10. Traveling Merchant — Buyback For Uninsured Losses

Post-pay safety net: Lost & Found tab sells your actual lost items back.

  • Flow: Grave lost → uninsured items go to merchant_pool not void. Insured items go to mailbox (cheaper).
  • Price: buyback = insurable_value * 2.5 (no insurance = expensive). Old-planet junk *0.7.
  • Merchants: Base merchant always has Lost & Found (reliable, expensive). Traveling merchant (random planet, 30 min window) same pool at ~30% discount + 1 random roll.
  • Pool: Capped 10–15 items FIFO, 7-day expiry, then gone. Once bought/expired, permanently deleted — death still has consequence.
  • Anti-dupe: Only is_death_drop items go to pool, not manual drops.
Economy: Insurance = pre-pay, cheap if you plan vs Merchant = post-pay, 2.5×, works even if you forgot. Run both: skill retrieves grave, preparation uses mailbox, forgetfulness pays merchant tax.

11. Anti-Softlock — Going Back To Planet 4 After Losing Everything On 5

Problem: 45 purples lost on 5, now on 4 with fists → can't kill 37s to get 37 drops.

Three-Layer Net

  1. Base Fabricator — Craftable Baseline (Diamond Tier): Always craftable weapon at player_level for common mats. Like Minecraft diamond — deterministic, viable 4-shot, not god-roll. Enchanted procedural loot from planets can beat it but isn't required to farm. First kit after death is free.
  2. Player Level ≠ Gear Level: Player level gives +2% health/shields even naked. Level 45 player with Tier 8 grey on planet 37 is slightly over, not under — TTK stays ~4-shot.
  3. Vault / Prime Slot: Base vault (3–5 guns) or Prime insurance slot (1 gun) never drops — stash vs loadout split, extraction-style.

Fabricator Gating

  • Gate on cost + quality, not cooldown. Cooldown punishes chain deaths when you need it now.
  • Craftable = guaranteed 4-shot diamond baseline; loot = same level but can roll 3.2 RPS / better magnetism / plasma bonus — higher ceiling, RNG.
  • Upgrade path: Lvl1 random archetype → Lvl2 choose archetype → Lvl3 choose rarity. Still needs right Tier+Rarity ore (see §12).
Loop: Die on 5 → respawn base with craftable 45s + vault → stomp 4 → get 37–38 drops or farm Tier 8 mats to craft 45s → retry 5 or rebuy 45s from merchant at 2.5× tax. Never hits no guns → can't kill → can't get guns.

12. Tiered Resources & Upgrading — Two Axes

Planet Tier (level bracket) × Ore Rarity (copper/iron/diamond). Added 2026-08-27.

Axis 1 — Tier.Sublevel (5 sublevels per tier)

T1 L1 .. T1 L5  → Tier 1 planets  (old 1–5)
T2 L1 .. T2 L5  → Tier 2 planets  (old 6–10)
T3 L1 .. T3 L5  → Tier 3 planets  (old 11–15)
...
Global = (tier-1)*5 + sublevel  # for damage: pow(1.06, global)
Display as T2 L1 rifle, cost uses T2 ore
  • Craft T1 L1 with T1 ore, upgrade T1 L1→L5 with T1 ore, break to T2 L1 requires T2 ore.
  • Hard gate — can't farm T1 planet to reach T3 L1. Must visit T3 planet.
  • If player is T1 L5 but hasn't found a T2 planet, they stall at T1 L5 until they explore — forces planet progression in order.

Axis 2 — Rarity = Ore Type Per Planet

Each planet (each Tier) spawns all three rarities with different abundance:

OreAbundanceCrafts/Upgrades
CopperCommonCommon weapons only
IronUncommonUncommon weapons
DiamondRareRare / Legendary weapons

So a T2 planet has T2 Copper, T2 Iron, T2 Diamond as separate stacks. Rare gun needs diamond even if tier matches.

can_upgrade(weapon): # T1 L5 → T2 L1 needs T2 ore
  tier   = weapon.tier + (1 if weapon.sublevel==5 else 0)
  rarity = weapon.rarity                    # rare → needs diamond
  return has(ore[tier][rarity] >= cost)     # e.g. 20× T2 Diamond for T1 L5→T2 L1
Matrix: 16 tiers × 3 rarities = 48 theoretical stacks, but you only carry 3 per current tier. Store as {tier, rarity, qty} not 80 per-level diamonds — compressed vs per-level ore.

Conversion — Both Directions, Different Rates (Discovery-Gated)

Higher tier ore subs for lower at 2:1 (efficient catch-up). Lower tier can combine to higher at 10:1 (inefficient grind fallback) — only after you've found that ore type at the target tier.

# Downgrade 2:1 — higher subs for lower, fewer needed
T3 diamond = 2× T2 diamond = 4× T1 diamond
T1 L4→L5 (rare): 20× T1 diamond OR 10× T2 diamond OR 5× T3 diamond
cost_higher = ceil(qty / pow(2, tier_diff))

# Upgrade 10:1 — lower combines to higher, many needed
1× T2 diamond = 10× T1 diamond
T2 L1 craft (rare, 20× T2): pay 20× T2 OR 200× T1
cost_lower = qty * pow(10, tier_diff)
# 10:1 is intentionally wasteful — exploring T2 is 10× more efficient than farming T1
  • Downgrade (high→low) 2:1: T3→T2, T2→T1 — always allowed, cheap catch-up.
  • Upgrade (low→high) 10:1: T1→T2, T2→T3 — only after you've found that ore type at target tier (e.g. mined one T2 Diamond unlocks 10× T1 Diamond → 1× T2 Diamond), and grindy. Farm old planet 10× longer vs just going to new tier.
  • Both require same rarity — copper can't become diamond, only tier converts.
  • Discovery gate closes the stay-forever loophole: Can't sit on T1 and trade up to T16 — you must have mined each tier's ore once, sequentially.
if has(ore[tier][rarity]): pay it
elif has_higher(tier, rarity): pay ceil(qty / pow(2, diff))
elif has_lower(tier, rarity): pay qty * pow(10, diff)  # 10:1 fallback
Result: You always need the right rarity (copper can't become diamond) but higher tier can cover lower. Never stuck going back to Planet 1 just because T1 copper ran out — spend T2 copper at 5:1 instead.

Consideration — Named Early Tiers, Numeric After

First X tiers (e.g. X=5) get distinct names/icons — T1 Verdant, T2 Ember, T3 Void, T4 Ancient, T5 Stellar — with unique ore textures and weapon skins. Creates memorable milestones like Minecraft's iron → diamond → netherite and attachment to my first T3 Void rifle.

  • T1–T5: handcrafted names/images, hand-tuned balance.
  • T6+: numeric only — Stellar T6, T7… recolor of T5, infinite scaling. Less memorable, but workload stays bounded.
Early named tiers drive identity/attachment; infinite numeric tiers after are just number goes up for endgame.

Terraform — Re-Tier Any Planet (Discovery-Gated)

Can be applied to any planet, not just home. Same planet, higher tier enemies/ores. Expensive — exploring a new planet is still more efficient.

# Cost to raise any Planet: T1 → T2
cost = 50× T2 Diamond + 100× T2 Iron  # ≈ one full T2 farm run
# General: +1 tier costs mats from target tier, not current
# Can't jump T1→T3 — one tier at a time, max +2 over original tier to force eventual exploration
  • Effect: planet.tier +=1, ore nodes re-roll to new tier, enemies scale to new tier. Biome/seed/builds preserved. Works on any discovered planet.
  • Gate: Must have discovered at least one planet of target tier before you can terraform any planet to that tier, plus pay target-tier mats. So T1→T2 requires you've visited a T2 planet at least once.
  • Tradeoff: Cheap terraform → one planet forever, discovery dies. Expensive (≈2× new planet farm) → nomad exploring stays efficient, terraform is luxury to keep a liked planet relevant.
  • Multiple planets per tier still allowed: You can have 4–5 T2 planets discovered at T2 L1–L5; terraform just lets any favorite keep up instead of moving.
Loop with terraform: Explore T2 planets → farm mats → either settle new T3 planet or spend mats to terraform any existing planet to T3. Keeps attachment to builds without killing exploration.

14. Planet Loop — Land, Clear, Build

Plain language — how a planet plays. Fixed positions, no orbits.

You fly to a new planet and land anywhere that isn't guarded by enemy anti-air guns. Those guns create no-fly zones — you can try to fly through them but you'll get shot up, so it's safer to land outside and walk in.

On foot you clear the outposts, and once they're gone you can fly freely over that area. You can always explore on foot, even before clearing — clearing just unlocks the sky. Scouting from the ship is allowed.

Each planet looks different — different ground, plants and creatures, and different ores to find. After you mine what you need, you fly to the next planet, which is a bit harder, and do it again. Planets stay in fixed positions and spin for day and night; they don't orbit.

  • 3–5 AA bubbles per planet (~500m), everything else landable (pads optional; crash outside = 20% hull, repairable).
  • Variance per planet: biome, wildlife, ore concentration at same tier.
  • Loop: land → clear on foot → mine/build → next tier.

15. Lore — Rogue AI

Light lore, mechanics-first.

Enemies are robotic. A rogue AI is expanding planet by planet, taking over the system — each tier is how long the AI has held that planet (T1 fresh, T10 entrenched).

  • AA outposts = AI defense network (clear to unlock air).
  • Mats = salvaged AI parts (T2 Diamond = AI core) — mining is salvaging.
  • Restore theme (Pokopia / BotW Malice): Malice coats higher-T planets (metal/corruption); clear outposts → malice recedes, biome restores (grey → grass/wildlife). Tier stays — visual heal, not T3→T2.
  • Post-clear activity: AI drops reinforcement pods every 10–15m on cleared planets so they stay farmable but less dense than inside AA bubbles.
  • Solar system = 9 planets (8 spheres + 1 ring world), progressively harder with distance from home; final ring world is AI hoard — entire ring made of stolen ore (all tiers, malice core).
  • Beating final planet unlocks mass relay → new solar system (NG+) — same 9-planet loop at higher tier offset (T10+), keep mats/guns, malice resets; original system remains accessible (return via relay).

13. Pitfalls Checklist

Combat Feel

  • Breakpoint cliffs every 1–2 levels if mult=1.08 — use 1.04–1.06 so cliffs every 4–5.
  • At-level Halo window is narrow; uncapped overlevel collapses strafe duels — intentional, but define window (±7).
  • Don't scale magnetism/bloom/error or headshot_mult with level.

Progression

  • Exponential blowup after 100 — soft diminish or squish.
  • Loot treadmill: favorite obsolete in 30 min — upgrade keeps it 10–15 levels, capped at +10.
  • Planet discovery gaming (scout 20 at lvl 10) — consider lock on first clear or soft re-level max(planet.lvl, player-10).
  • Old planets boring after stomp — need cosmetics/mats or heroic re-level toggle.

Economy & Tech

  • Insurance too cheap → never farm; too expensive → never use. Tune Base ~15%, Prime ~50% of value.
  • Save bloat: procedural + level + insurance per gun; version curve, bake level_mult at drop.
  • Readability: show level_diff color (blue trivial / white at-level / red dangerous) + shots_to_kill in inspect.
  • Test matrix: automate TTK sim gate on every generated gun (95%/80%/60% hit rate at 10/30/60m).
Core tension to hold: WoW numbers + Halo guns works only if at-level duels stay in 1.2–1.8s window. Let overlevel break it for power fantasy, but keep underlevel bounded so skill still matters.
