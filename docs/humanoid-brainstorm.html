01 Baseline Today

What already exists — the launchpad.

Logic only, no mesh

entities/mob.gd:1 — Mob extends Node3D with hp/tamed/vel, hurt() knockback, try_kill() drops. No visual child. autoload/data.gd:140 defines 8 mobs: pig/sheep/cow/zombie/skeleton/chicken/wolf/spider with hp/w/h/speed/body/head colors. The architecture at ARCHITECTURE.md:31 promises models/*.tscn with hip-pivoted limbs — not yet built.

Player is first-person only

player/player.gd:1 — CharacterBody3D, EYE 1.62 / P_H 1.8. Viewmodel is hand_root → held_box / held_sprite / held_tool inside Camera3D. Procedural walk sway via _update_sway (sin bob). No third-person mesh.

Mesh precedent

core/held_mesh.gd:1 code-generates boxes/crosses with PackedVector3Array + ArrayMesh, caches by atlas identity, shades via VoxelMath.FACES.sh. Same pattern can generate limbs. Fluid anim mats + daynight light already modulate albedo — humanoid mats must join that pipeline.

Palette + tint already solved

data.gd:15 C_* colors + atlas bake (_bake_atlas_tints) multiplies tints into pixels. Humanoid skin can be Color.html("f2a29c") style from mobs.body/head or sample atlas — keep one path.

Constraint: headless tests drive Debug.spawn_mob() and xvfb-run --rendering-method gl_compatibility. Anything we add must pass that probe and not require a GPU import step on CI.

02 Goals & Constraints

Must have

  • Player / zombie / skeleton share one rig — different sizes, same bones.
  • Limbs pivot at hip/shoulder (M10 AC) — not center.
  • States: idle / walk / sprint / sneak / jump / fall / swim / swing / bow-draw / eat / hurt / death.
  • Held item + armor visible in third-person.
  • 50 mobs at 60fps on gl_compatibility / llvmpipe.
  • First-person stays (viewmodel), third-person (F5) added.

Constraints

  • Godot 4.7.1: Skeleton3D, AnimationPlayer/Tree, SkeletonIK3D, LookAtModifier3D exist — but verify before assuming (perf APIs renamed, etc.).
  • Mesh + collision: mobs stay CharacterBody3D with capsule; mesh never drives physics.
  • No Blender required to iterate on day one.
  • Windows-only export; no mobile LOD yet.

03 Shape Language

Keep Minecraft's read — cubes, but intentionally proportioned.

Classic Steve

Head 8×8×8, torso 8×12×4, arm 4×12×4, leg 4×12×4 (pixels). 1 pixel = 1/16 block. Ratios read instantly as "human". Best for instant Minecraft legibility. Recommended V1

Slim Alex

Arm 3×12×4. Same height, reads slimmer/faster. Good for player variant, not for zombie bulk. Add later as 1-param switch.

Stylized

Bigger head (1.2×), shorter legs. Cute / Halo-loot vibe but breaks armor fit. Save for pets or NPCs, not hostile humanoids.

Steve @ h=1.8:  head 0.5×0.5×0.5  torso 0.5×0.75×0.25  arm 0.25×0.75×0.25  leg 0.25×0.75×0.25
Pixel = 0.0625 block.  Pivot: arm top face center, leg top face center → matches M10.

05 Rig — One Skeleton, Many Bodies (Deep Dive)

7 bones, hip-pivoted, no weight paint. How a single Skeleton3D drives boxes, holds guns, and scales from Grunt 0.9m to Elite 1.9m without new art.

Skeleton3D (root)              bone idx  parent  rest pos
 ├─ hips        [0]  —           -1      (0, 0.62, 0)
 │   ├─ leg.l   [1]  hip         0       (-0.11, 0, 0)  pivot = hip top face
 │   └─ leg.r   [2]  hip         0       (+0.11, 0, 0)
 ├─ spine       [3]  hips        0       (0, 0.42, 0)   torso 0.5×0.75×0.25
 │   ├─ head    [4]  spine       3       (0, 0.58, 0)   neck
 │   ├─ arm.l   [5]  spine       3       (-0.31, 0.48, 0) shoulder top face
 │   └─ arm.r   [6]  spine       3       (+0.31, 0.48, 0) + BoneAttachment3D → gun
rest = T-pose. pose = rest + anim.  Godot 4.7: set_bone_pose_rotation(idx, quat) is pose, not rest.
Why BoneAttachment3D not skinning: Box limbs are rigid — no elbow bend. Parenting a MeshInstance3D under BoneAttachment3D is 1 node, 0 weights, 0 import. Skinning (vertex weights) only needed if you add bent elbows/knees. Start rigid, skin later behind flag.

Attachment points

  • arm.r / BoneAttachment3D "grip" → held_tool (reuses player.gd:406 held_tool voxel mesh builder). Grip offset Vector3(0, -0.22, 0.06) — palm center.
  • arm.l / BoneAttachment3D "shield" → Jackal shield BoxMesh 0.5×0.7×0.05 (only Jackal enables it).
  • Armor = second MeshInstance3D per limb at scale 1.02 (Minecraft outer layer trick), material from Data.items[armor_id].mat — toggle visible per player.armor[].
  • Head overlay = 1.05× box for helmet, same pivot as head.
  • Future: head / BoneAttachment3D "hat" for Elite mandibles / Grunt mask (just a mesh swap).

Transforms — the one thing to get right

skeleton.set_bone_rest(1, Transform3D(Basis.IDENTITY, Vector3(-0.11,0,0)))

Hip-pivot — proof it works

Mesh origin = top-face center (0, len/2, 0) in local, bone origin = same world point. Rotate leg 45°: thigh stays stuck at hip, foot arcs 0.52m. Fail mode (center pivot) slides hip 0.26m — screenshot from side fails M10 gate.

# Mesh build — pivot at top (not center):
var half = Vector3(w/2, len/2, d/2)
# vertices centered at (0,0,0) then shifted down by len/2 so top = 0
for v in box_verts: v.y -= len/2
# Bone rest at hip top face: rest_pos = Vector3(-0.11, 0, 0)
Godot 4.7 quirks: No reorder_child (use scan+move_child), no get_index on bone. Skeleton3D.get_bone_count() is 7; find_bone("arm.r") returns idx or -1 — cache at _ready, don't string-lookup per frame.

When to switch to skinning

Only when you need bent elbows/knees (sprint, crouch) or capes. Then: one ArrayMesh with ARRAY_BONES + ARRAY_WEIGHTS, 1 bone per vertex (weight 1.0), import via glTF or code-gen. Keep V1 rigid — you can skin-ify the same 7 bones later with no scene change.

06 Animation — Three Layers, Ship One at a Time (Deep Dive)

V1 is 40 lines of math. V2 bakes the same math into clips. V3 adds aim IK. Same bones, same rig — no rework.

V1 Procedural (math) — ship this

# tick(delta, vel, on_ground, swing_t, aim_yaw, aim_pitch)
phase += vel.length() * delta * 1.35 # 1.35 = steps per meter
var s = sin(phase), c = cos(phase)
arm_l.x =  s * 0.62          # ±35°
arm_r.x = -s * 0.62 + swing  # swing = -1.2 * swing_frac
leg_l.x = -s * 0.65
leg_r.x =  s * 0.65
# vertical bob + breathe
spine.y = abs(s)*0.02 + sin(phase*2)*0.008
head.y  = clamp(aim_yaw, -1.0, 1.0)
head.x  = clamp(aim_pitch, -0.6, 0.6)
# on_ground false → freeze legs, arms slight out

Cost: ~14 floats + 2 sin per frame. States covered: idle/walk/sprint/jump/fall/swim all from same 6 lines.

V2 Clips + Blend Tree — bake V1

# Record V1 poses at 30fps into AnimationPlayer:
"walk" 0..0.8s  arm/leg keys from math
"run"   faster 1.35×, amp 1.2×
Tree:
  BlendSpace1D (speed 0..5.6) → idle..walk..run
  + OneShot (swing, shoot)
  + Additive (hurt tint, flinch)
# Drive:
tree["parameters/blend_position"] = vel.length()
tree["parameters/OneShot/active"] = swing_frac>0

Benefit: scrub in editor, retarget to Grunt (short legs auto), add mocap later. Cost: clips must be re-baked when math changes — keep V1 math as source of truth.

V3 IK / Physics — aim + feet

# Aim IK (spine + head + arm):
spine.yaw = lerp(spine.yaw, aim_yaw*0.6, 8*dt)
head.yaw  = aim_yaw - spine.yaw
arm_r.yaw/pitch = aim → BoneAttachment grip

# Foot IK: raycast down 1.2m per leg
var hit = raycast_blocks(foot+up, -up, 1.2, get_block)
leg.y = lerp(leg.y, hit.hit? foot.y-hit.y : 0, 12*dt)

# Cape spring:
vel += (target-pos)*18*dt - vel*6*dt
pos += vel*dt

Full V1 tick — copy-paste ready shape

func anim_tick(skel: Skeleton3D, dt: float, vel: Vector3, on_ground: bool,
               swing_frac: float, aim_yaw: float, aim_pitch: float) -> void:
    phase += vel.length() * dt * 1.35
    var s := sin(phase)
    var swing := -1.2 * swing_frac # swing_frac 0..1 over 0.2s
    # legs
    if on_ground:
        skel.set_bone_pose_rotation(leg_l, Quaternion.from_euler(Vector3(-s*0.65,0,0)))
        skel.set_bone_pose_rotation(leg_r, Quaternion.from_euler(Vector3( s*0.65,0,0)))
    else:
        skel.set_bone_pose_rotation(leg_l, Quaternion.from_euler(Vector3(-0.25,0,0)))
        skel.set_bone_pose_rotation(leg_r, Quaternion.from_euler(Vector3( 0.25,0,0)))
    # arms + aim
    var aim_y := clampf(aim_yaw, -1.0, 1.0)
    var aim_x := clampf(aim_pitch, -0.6, 0.6)
    skel.set_bone_pose_rotation(spine, Quaternion.from_euler(Vector3(0, aim_y*0.6, 0)))
    skel.set_bone_pose_rotation(head,  Quaternion.from_euler(Vector3(aim_x, aim_y*0.4, 0)))
    skel.set_bone_pose_rotation(arm_l, Quaternion.from_euler(Vector3( s*0.62, 0, 0)))
    skel.set_bone_pose_rotation(arm_r, Quaternion.from_euler(Vector3(-s*0.62 + swing + aim_x, 0, aim_y*0.15)))
    # breathe when idle
    if vel.length() < 0.05:
        skel.set_bone_pose_position(spine, Vector3(0, sin(Time.get_ticks_msec()*0.002)*0.015, 0))

Model side — building the boxes

# HumanoidMeshes.box(size, color) — like held_mesh.gd:82
func box(size: Vector3, col: Color) -> ArrayMesh:
  var v:=PackedVector3Array(); var n:=PackedVector3Array()
  var c:=PackedColorArray(); var uv:=PackedVector2Array(); var idx:=PackedInt32Array()
  for fi in 6:
    var f=VoxelMath.FACES[fi]; var shade=float(f.sh)
    var face_col = col * shade # or sample atlas via corner_uv
    var base=v.size()
    for corner in f.c: # 4 corners of face
      v.append(Vector3(corner)-Vector3(0,size.y/2,0)) # shift so top=0 (hip pivot!)
      n.append(Vector3(f.n)); c.append(face_col * Color(shade,shade,shade))
      uv.append(corner_uv(...))
    idx.append_array([base,base+2,base+1, base,base+3,base+2])
  return _to_mesh(v,n,c,uv,idx) # one material per body color, unshaded, light via albedo L

Per-face shade f.sh (0.6..1.0) bakes Minecraft AO without light. Atlas tint already baked at load (data.gd:_bake_atlas_tints) — don't double-tint.

Gotchas & perf

  • Don't call find_bone per frame — cache idx at _ready.
  • Quaternion vs Euler: set_bone_pose_rotation takes Quaternion, not Vector3. Use Quaternion.from_euler.
  • Tree vs manual: If AnimationTree.active, don't set_bone_pose_ — drive tree[parameters/...] instead. V1 keeps tree off.
  • Cache meshes: box_cache[(size,color)] — 4 variants, not 50 builds. Share StandardMaterial3D per body color bucket.
Godot note: AnimationTree needs AnimationPlayer sibling + active=true. Drive via tree.set("parameters/blend_position", speed) — not bone directly when tree active. For V1 procedural, keep tree inactive and drive bones directly.

07 Procedural Generation — Two Independent Axes

A. Variation (do first) — cheap, high value

  • Seeded scale: scale = 0.92 + hash(seed ^ x ^ z) * 0.16 — same zombie species, not clones.
  • Hue jitter: body = base.body * (0.95 + rand*0.1) on HSV.
  • Species param: zombie taller, skeleton leaner — stays in Data.mobs.

Cost: one float per spawn. No extra mesh builds — reuses template + duplicate().

B. Generation (later) — mesh synthesis

  • Limb factory: HumanoidMeshes.box(size, color, uv) with size params [head_w, torso_h, arm_len].
  • Topology: noise picks nose/ear protrusion, armor trim width.
  • Spider 8 legs: same rig + extra bones — proof the rig is extensible.

Don't build per-instance at runtime for 50 mobs — generate templates, instance. Save palette index, not vertices.

Not procedural: hitbox w/h and speed/dmg — keep in Data.mobs. Visual procgen must not desync combat.

08 Recommended Architecture Pick This

Staged — each stage shippable, none blocks the next.

V1 — code-gen + procedural V2 — clips + blend V3 — IK / generation

Now (V1)

  • HumanoidMeshes (like HeldMeshes) generates 6 boxes with hip pivot, per-face shade, optional atlas tint.
  • Humanoid extends Mob owns Skeleton3D, ticks anim_procedural.gd.
  • Player third-person: same prefab under player.tscn, F5 toggles Camera3D offset behind player.global_position + Vector3(0,1.2,-3).
  • Fix lighting: humanoid mats join player.gd:502 vm_refresh L-modulation (or share world.light_at).

Later

  • Replace tick with AnimationPlayer + AnimationTree — keep procedural as fallback for head/held.
  • Add SkeletonIK3D for feet on stair voxels; raycast already exists at core/math.gd:raycast_blocks.
  • Minecraft outer armor layer: expanded box mesh per limb.
  • Optional Blender import path behind feature flag.
Why this order: V1 proves the game is readable on gl_compatibility without waiting on art. V2/V3 are additive — same skeleton, same prefab — so no rework.

10 Perf & LOD

Draw cost

6 MeshInstance3D × 50 mobs = 300 draws if naïve. Mitigate: MultiMeshInstance3D per limb type, or at minimum merge torso+head, share material per body color bucket (reduce to ~4 mats). llvmpipe cares more about draw count than verts.

LOD / cull

r > 64 blocks: tick anim at 15 Hz not 60; r > 96: freeze to idle; r > 128: hide. Physics (CharacterBody3D) already culls via world chunk radius.

  • Animate on CPU once per mob, push 7 bone poses — not per-vert.
  • Cache meshes by (key, armor_bits) — not per instance.
  • Keep mats unshaded initially (like held_mesh.gd:72 _base_mat), light via vertex/albedo L — no realtime shadow pass per mob.

14 Covenant Shooters — What Halo Gets Right New

Don't port Halo wholesale — steal the readable combat loop that lets blocky voxel enemies feel tactical.

Why Covenant reads instantly

  • Silhouette = role. Grunt hunched tiny, Jackal shield + gap, Elite tall/shoulders, Hunter wide block. You know who shoots vs who charges before they move — critical in voxels where textures are 32px.
  • Weapon = behavior. Needler strafes and super-combines, plasma rifle holds trigger and overheats, carbine taps. One gun, one rhythm — never "random gun on random mob".
  • Grenade + melee + gun triangle — enemies too. Grunts lob plasma, Elites lunge-melee when shields down, Jackals hold line. Enemies use the same verbs you do.
  • Shields are language. pop → crack → recharge whine tells you "push now". Covenant shields crack loud + visually dim — free callout.

Translate to AweCraft voxels

Gruntlette — swarm · 4 hp · w0.5 h0.9

Flees when alone, swarms in 3–5, plasma pistol taps. Cannon fodder that teaches leading.

Jackal — shield wall · 8 hp + 12 shield

Holds BoxMesh shield in arm.l, peeks to shoot. Flank to break. One voxel shield — readable at 30 blocks.

Elite — duelist · 16 hp + 20 shield · 1.9h

Strafes at 90%, uses cover, grenades, melee lunge <2.5m when your shields drop. Reuses humanoid rig directly.

Hunter / Brute — heavy · 40 hp · w1.2 h1.4

Wide blocky rig (2× torso), charges, fuel-rod slow projectile. Teaches "don't peek, reposition".

All four reuse §5's 7-bone rig: Grunt = short legs + big head, Jackal = shield attachment, Elite = 1:1, Hunter = double-wide torso. One skeleton, four silhouettes.

Rule of one: one enemy archetype = one gun + one movement pattern + one shield/health shape. Proceduralize inside that envelope (±RPS, ±shield), never across it. A Jackal never gets a fuel rod.

Hitscan vs projectile, error cones, leading, and what the player feels. Mirrors docs/halo-loot-brainstorm.html:3 firing pipeline — now from the mob's muzzle.

Firing pipeline (enemy side)

can_fire = has_LOS() && dist in [2, 28] && cooldown<=0 && !flinching
aim_dir  = (player.head - muzzle).normalized()
# lead for projectiles:
aim_dir  = lead(aim_dir, player.vel, proj_speed)  # t = dist/speed
# error cone — gun × enemy skill (both matter):
error    = (weapon.base_error + (moving? 1.2° : 0) + bloom*shots_in_burst) * mob.skill
# Grunt pistol: (3.5+0.5)*1.45=5.8°  vs  Elite rifle: (1.4+0.35)*1.05=1.8°
aim_dir  = aim_dir + random_cone(error)
# line of fire blocked by voxel?
if VoxelMath.raycast_blocks(muzzle, aim_dir, dist, world.get_block).hit:  hold_fire
else:      spawn_projectile(muzzle, aim_dir*speed) or raycast_hitscan

Feel knobs — tune these, not damage

  • RPS / burst: Grunt 1.8 RPS single, Elite 3-round burst 2.4 RPS with 0.9s pause, Hunter 0.6 RPS lob. Burst gap is the "push window".
  • Error cone: Grunt 3.5° (spray), Elite 0.6° standing / 1.8° strafing, Jackal 1.2° peek. Player can learn to bait strafe.
  • Wind-up tells: 0.25s arm raise + muzzle glow + audio whine before first shot. No instant peek-shoot.
  • Flinch / suppression: On taking ≥3 dmg, flinch_t=0.35s — cancel burst, play hurt, add 2° error. Your shots matter immediately.
  • Overheat (plasma): heat+=0.14/shot; if heat>1.0 → 1.4s lockout + vent VFX — free push window, no extra code.

Damage to player

enemy_dmg = base * level_mult(enemy.level) // same curve as §7 halo doc
player.take( amount * shield_mult vs health_mult )
# per halo doc: plasma 1.6× vs shields, 0.7× vs flesh
# headshot_mult only when shields == 0, same as player rule
  • Reuse player.gd:1299 damage_player() — pass src="plasma" for shield-mult hook.
  • TTK at-level: Grunt ~2.0s, Elite ~1.4s perfect, Hunter ~1.1s — inside halo 1.2–1.8s window when you strafe; longer if you dodge.

VFX on a budget

  • Muzzle flash = 1 emissive quad at arm.r/BoneAttachment3D end, 60ms, no light.
  • Tracer = MeshInstance3D thin box lerped 0→hit in 40–120ms, or ImmediateMesh line.
  • Plasma glow uses existing fluid_anim.gdshader tint trick — hue from weapon, not new shader.

16 Brain — AI, Cover & Squads

FSM is enough for V1. Behavior trees when squads need coordination. Runs at 10 Hz, not 60 — cheap.

States (tick 10 Hz)

Idle: wander 4m, scan 28m sphere, LOS via raycast_blocks
Alert: turn to player, 0.4s wind-up (tell)
Strafe: lateral move ±3m at 0.7× speed, fire burst, keep 8–16m band
Cover: raycast to nearest solid 1×2×1 voxel within 8m, move, peek
Flinch: cancel fire, strafe away 1.5m, 0.35s
Melee: if dist<2.2 && shields_down → lunge, 6 dmg (reuse player melee 2.5m)
Flee: Grunt only — if squad<2 → run 8m, call help within 16m
Dead: ragdoll-ish fall, try_kill() drops

Cover — voxels make it easy

  • Cover = any solid column 1×2×1 within 8m where raycast_blocks(cover+1, player, 28).hit == true (player blocked) but raycast_blocks(self, cover+1).hit == false (you can get there).
  • Score covers by dist_to_self + angle_to_player + already_occupied. No navmesh V1 — CharacterBody3D walks via move_and_slide + voxel raycast wall check.
  • Peek: step 0.8m sideways, fire 1 burst, step back. Jackal holds shield forward the whole time.

Sensing

  • LOS: VoxelMath.raycast_blocks(eye, dir, 28, world.get_block) — same DDA player uses for mining. No physics ray.
  • Hearing: player sprint/jump/mine within 12m → Alert even without LOS (turn to sound pos).
  • Memory: remember last_seen_pos + 3s, move there before Idle.

Squads (cheap, effective)

Squad = { leader: Elite, members: [Grunt, Grunt, Jackal] }
- spawn together within 6m, share alert (one sees → all Alert)
- leader picks cover, members offset ±2m (no stacking)
- Grunts flee toward leader; Jackals anchor
- Elite calls 1 grenade per squad per 12s (lobs via projectile arc)
- cap: 1 active squad per ~40m diamond (reuse world tick diamond)

Performance

  • Think 10 Hz (_brain_t += dt; if _brain_t <0.1: return), animate 60 Hz.
  • LOS only on tick, not per frame. Cache eye_cell + player_cell → LOS bool for 0.2s.
  • Far >48m: freeze brain, only wander. Far >80m: despawn (reuse mob despawn rules).
Godot path: NavigationAgent3D needs baked NavigationMesh — voxels have no mesh for it. Skip for V1. V2 bakes a flat heightmap navmesh per chunk at y = top_solid if needed; most Halo-style strafe/cover works without it.
